## 0. 结论速览（v2）

1. **50h 目标下，数值膨胀不是瑕疵而是内容拉伸器**——但必须是"**有出口的通胀**"：三阶段结构（线性钩子 → 分段墙 → 通胀长线），每一段通胀背后要有一个可见的翻墙收益（新兵种/新建筑/新档位/全局倍率）。
2. 借鉴清单扩为八项：**分段斜率成本、免维护带、资源转换阀、每日硬上限**（v1 四项）＋**离线 0.6×/24h**＋**通胀三件套**：喂料曲线（2.5^n 类）、10^n 长轨（时代进度条）、难度阶梯（末档 ×5000 类）——三件套均加装护栏（§3）。
3. 仍明确排除的与膨胀无关，是模式问题：广告 ×2/VIP ×8 倍率（商业化未确认）、本地 CDK（安全洞）、0.5s 全量 JSON 存盘（性能）。幸福度式"文案≠代码"的分段表若要上，必须 config 同源导出（02 C1）。
4. **SVG 动画判断不变：不必要，维持"静态像素 SVG data-URI + CSS keyframes"**（§4）。
5. "特别肝"口碑的成因是【广告日限 × 橡皮筋 × 高墙】三件叠加；我方为单机无广告形态，橡皮筋/高墙的体感会温和得多——可以放心借鉴机制本身。

## 3. 50h 目标：三阶段曲线骨架（v2 新增）

> 通胀不是"数字变大"，是**节奏**。50h 的分配建议【示例·待推演】：

| 阶段 | 时长预算 | 玩家体感 | 机制 | 通胀形态 |
|---|---|---|---|---|
| ① 序章 | 0~3h | **爽**（钩子） | 线性产出+免维护带+免费段；首胜引导 | 无通胀/近线性 |
| ② 墙期 | 3~15h | **卡→翻墙** | 分段斜率成本（每 10 级一墙）+转换阀+难度旋钮+首个 10^n 轨出现 | 成本分段 ×1.3→×3→×6；敌人每 10 关 HP ×2.2 / ATK ×1.5【示例】 |
| ③ 通胀期 | 15~50h | **膨胀+沉淀** | 喂料轨（觉醒/星级）+时代长轨+敌人数值阶梯+驻军/每日刷取封顶 + 离线 0.6× 兜底 | 成本 1.6^n~1.9^n 分段；末档难度 ×5000 类只在终局段 |

**护栏清单（通胀的五个必须）**：
1. **有出口**：每道通胀墙后紧跟可见收益跳变（新兵种/新建筑/新档位/全局倍率）——"墙后必须有门"（02 C2）。
2. **可读**：≥1 万显示"万"、≥1 亿显示"亿"，全展示走统一格式化函数——50h 流程后期必然 1e9+，数字可读性是留存的一部分。
3. **可预测**：下一个墙的位置与奖励在 UI 可见（"距下一个时代还差 3 级/12 万知识"）；《放置时代》的"10 级墙"之所以有效是因为玩家能预判。
4. **保底**：伤害 20% 破甲保底、离线断粮截断、战斗失败不清档、首通奖励不封顶——通胀越高，保底越重要（防"打不动"死局与绝望流失）。
5. **存档兼容**：曲线改动只影响"新产出/新成本"计算，不动存档字段语义（建筑 lv/defeated/merit/essence 照旧）；v1 存档在曲线改版后仍无迁移负担——现有 IE-001 存档框架已为此铺路。

**一条硬提醒**：膨胀是拉伸器，不是内容替代品。50h 里若只有膨胀没有新内容投放（兵种线/科技树/Boss/驻军变体），玩家感知的是"空转的 50 小时"。新内容按 `02` 主线（IE-002 科技闭环、IE-003 Boss/战斗、IE-004 时间/离线、IE-005 引导）投放，膨胀负责把每一段拉长并交错。

## 4. SVG 动画判断（维持 v1 结论）

**没有必要，维持现状**：
- 我方现状＝静态像素 SVG data-URI（sprites.js 字符网格→矩形合并→内联 SVG 背景）+ **61 处 CSS keyframes**（战斗 strike/shaken/die、城镇工人/守卫/入侵者、toast、pulse），已有 `prefers-reduced-motion` 开关（index.html@719-721）。**代码中无 SMIL/动画 SVG/JS 动画库**。
- 理由：① Android WebView 对 SMIL/动画 SVG 支持不一致；CSS transform/opacity 走合成器且省电；② 文字放置品类信息密度在数字与列表，动效是点缀；③ 静态 SVG data-URI 零请求、可被 CSS 变换动画高效驱动；④ 动效已被当作"可关闭增强"，不该依赖动画 SVG。
- 可选微调：strike/shaken 的 `box-shadow` 是低端 WebView 绘制热点，若卡顿改为纯 transform/opacity；想要更爽的反馈加 CSS-only 小件（资源 +N 飘字、伤害数字、Boss 血条抖动）即可，不引入新渲染通道。

## 5. 与本方案路线的关系（v2 更新）

- 通胀三件套**并入既有批次，不单开"通胀工作单"**：科技线（IE-002）=喂料轨与 10^n 长轨；战斗线（IE-003）=难度阶梯与首通不封顶规则；时间线（IE-004）=离线 0.6×与每日上限；引导（IE-005）=第一道墙的预告与翻墙教学。
- 立项顺序仍按 02 主线：先修断头路（P0，科技点无来源）→ 回访钩子（离线+日课）→ 时间税与自选深度（扫荡+难度旋钮）→ 溢出与收集（转换阀+图鉴）→ 节奏化投放（系统解锁表）。本文件的 A1-A4 建议排在 IE-004 之前或同批。
- 以上全部为建议，未实施；具体数值需先做一次 50h 时长-通胀配比推演（模拟脚本）。
