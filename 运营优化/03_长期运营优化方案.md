## 1. 断头路修复（P0，先于一切运营）

### 1.1 科技点来源（修 P0-1，方案=第四采集轨道+第二来源）
- **学者线**：`CFG.res.tech.basePerPop: 0 → 0.08`⊙，主页新增"学派"分配（复用 popAlloc/prodRate/buildingBuff 全链，≈40 行）；新增建筑 **学院**（buffRes:'tech'，buffBase .20/buffPerLv .25 同资源建筑，等级上限=城镇级×1，建造费 {wood:600,stone:600,food:400}，upBase {wood:8000…} 同档⊙）。
- **第二来源（C3 教训：稀缺源≥2）**：①关卡首杀一次性：`tech += ceil(id/10)*3`（全100关≈1650）；②驻军胜利转化：每胜 1 波可选"战功×2 → 科技点×15"日限 5 次⊙。
- 收支总表（全树 17,150 点）：100 关首杀 1,650 + 学者 30 天累积（20 人×0.08×城镇后期 buff≈2.6 ≈4.2/min≈12.6 万/30 天在线——上限远大于树，**科技点因此顺带成为常驻货币**）+ 驻军转化补充。节点定价不动（已存在），后续版本靠"量子武装式可重复研究节点"（见 §3.3）吸收余量。
- 验证指标：D3 "科技页有≥1 次成功研究"玩家占比 ≥60%（埋点 tech_unlock）。

### 1.2 Boss 战修复（修 P0-4）
- 现状：Boss 兵数 [1,1,1]，hp=人数 → 4 人总血（@initBattleState:936）。
- 方案：`CFG.enemies.boss 新增 bossHpMult`，initBattleState 一行 `hp: Math.ceil(counts[i]*(bm?e.bossHpMult:1))`。**分章 bossHpMult**⊙：C1=15、C2=25、C3=40、C4=60、C5=85、C6=115、C7=150、C8=190、C9=240、C10=300（对齐我方 D30 理论 DPS：T3 3团×80人×atk22×0.09×减伤 ≈ 3.5k/回合 → C10 Boss 总血≈300×4=1200 仍在 30 回合内——需推演把 mult 上调至 D30 玩家在 15~22 回合险胜带宽）。同时 Boss 编成从 [1,1,1] 改为章节主题混编（如万古之王 {infantry_fortress:[8],cavalry_teutonic:[6],mage_chrono:[4]} 走同一 mult 表），恢复"Boss=图鉴毕业考"的仪式感。
- Boss 战败保留零惩罚（不新增惩罚），但超时=败处理不变。
- 验证指标：Boss 关首通重试次数中位数从 ~0 升到 1~3（太低=没意义，>5=过难），埋点 boss_attempt。

### 1.3 后期敌人数值再平衡（数值成长曲线修正，H3）
- 现状错配：敌人普通关成长=兵数 8→36（×4.5），我方成长=atk ×6 ×兵力 ×4 ×槽位 ×4 ≈ ×100 → **L50 后普通关形同虚设**。
- 方案（不推翻配置结构，只换数值+编成）：①后半章节敌人改用 T2/T3 变体（章5+ 出现重盾/劲弩，章8+ 条顿/万古之瞳——与我方科技进度镜像）；②兵数上限保持 3 团，改"人数随章 ×1.15^n + tier 代差"双轴；③每章末加入 1 个"代差侦察关"预告下章兵种（教学缓冲）。
- 推演要求：以玩家 DPS 曲线（训练+科技解锁节奏表）为横轴重排 100 关需求曲线，产出 levels_rebalance.csv 评审后才动 levels.js（阶段4 门槛）。

## 2. 回访钩子（P0-2 / P1-6）

### 2.1 离线收益（对标 A1）
- save() 增 `ts: Date.now()`（+`v:1` 版本号，load 无 ts 走旧逻辑=天然向后兼容）。
- 结算=（Δt，封顶 28800s=8h⊙，起结线 300s）× 在线净速率 × 0.55⊙：资源只进仓库（溢出丢弃规则与在线一致）；训练队列离线照推（消耗资源照扣，不足即暂停——与在线同一 processQueue 复用）；**战功/精魄/首杀不产出**（防离线刷进度）。
- 回来弹"离线报告卡"（时长/收获/驻军战报），一键领取。
- 指标：启用后"当日第二个会话间隔 ≥4h"占比（回访钩子成立的直接证据）、D7 目标 +3pp（【假设初值】）。

### 2.2 日课与日界（对标 A2）
- 日界=本地 04:00。日课三件事（全可选）：①远征胜 1 场 ②驻军胜 1 波 ③一次研究或训练 20 兵 → 奖：战功×10 + 交易所代币×5 + 科技点×30⊙。
- 驻军改造：随机计时器保留，另加"每日首波必刷（奖励×2）"；波次模板从 5 扩到 8（含夜袭/佯攻变体），奖励随城镇级缩放（现固定 60~160 资源后期无感）。
- 指标：日课完成率 ≥45% 活跃日（活动参与率基线）；完成日次留差 ≥10pp（对照组=未完成日）。

## 3. 30/60/90 天成长与消耗主轴（修 P0-5 / P1-7）

### 3.1 生命周期主轴设计（数值成长曲线总纲·个人进度赛季制，对标 02-E2）
```
D0-D7   建国期：L1-30关 / 城镇Lv1-4 / 民兵游侠T1 / 学者线启动          → 目标：懂四循环(采-养-战-研)
D7-D30  扩张期：L31-70 / 城镇Lv5-7 / 首个T2专精 / 交易所开 / 图鉴30%   → 目标：选流派(盾/矛/剑 或 时/空)
D30-D60 王霸期：L71-100 / 城镇Lv8-10 / T3毕业 / 远征篇章v1(12关)      → 目标：Build优化+收集补全
D60-D90 永恒期：周挑战+可重复研究节点+图鉴90%+称号毕业                → 目标：自设目标(速通/收集/极限难度)
```
- 每阶段锚定 1 个"命名进程"里程碑（对标 A10）：公国→王国→帝国（城镇 Lv4/7/10 附加称号+边框）。

### 3.2 溢出与消耗口（对标 A7）
- **交易所**（城镇 Lv4 解锁）：木⇄石⇄食 100:1 互兑（日限 20 次⊙）+ 战功⇄科技点（§1.1 第二源共用界面）+ **遗物商店**（周刷新，代币购图鉴物/加速）。溢出资源自动折算提示（"仓库已满，×N 损失，去交易所？"）。
- **可重复研究节点**（"军团操典"型，对标放置时代量子武装的重复强化思想）：每线 1 个 +1% 属性可重复节点，成本 200×1.35^n⊙——科技点常驻化的消耗端，也是 90 天软上限成长轴。
- 军粮升级为主动玩法：军队规模 50% 以下/以上"军省制"±10% 维护费调节滑杆（玩家自选经济-军力杠杆，对标 A5 的自旋钮思想简化版）。

### 3.3 时间税减免（对标 A3/A4）
- 确定性战斗改造：battleTurn 内全部 Math.random 改 `rng()`（xorshift 种子=关卡id+日期+我方配置哈希；多通道：命中/伤害/掉落独立种子段）。
- **扫荡**：已首通关卡（defeated 即凭证）可直接结算奖励+日限 10 次⊙；扫荡不含首杀奖励/精魄。
- 倍速加 x8（一次性解锁，选项设置内，不做付费）。

## 4. 目标体系与新手/中期修复

### 4.1 成就五章 + 图鉴（对标 A9/A10）
- 成就五章（创始/征服/富国/博采/永恒）≈120 条，纯 `defeated/pool/res/essence` 可判定，奖励=称号+代币+头像框（零数值，防平衡污染）。
- 图鉴四类：兵种谱（25）、战役谱（100 关首通画面）、精魄/遗物（12）、称号（命名进程）——图标全部复用 sprites.js 现有资产。

### 4.2 新手引导（修 H1/H2，止血 48h 内可做）
- 前 10 分钟脚本化：分配村民→首胜→**学院落成+学者分配（科技点第一次跳动必须被看见）**→首次研究弹窗。全走现有 toast/log 机制，不动主循环。
- 军粮预警（H2）：食物净负时顶部红条常驻+点击展开解释（现有枯竭机制加前置提示，零新系统）。
- 内置 FAQ 6 条（对标 A8，含自嘲位）：科技点哪来/为什么饿死/Boss为什么强/怎么扫荡/克制表/存档保护。
- 卡关帮助：同关连败 3 次 → 弹"参谋部"卡（敌方构成弱点分析=现有克制表数据反查 + 建议训练/研究项）。

### 4.3 中期流失修复（修 H4/H5）
- 建筑触顶时（upgradeLockReason 命中率高的玩家）自动推荐替代目标（研究/图鉴/交易所/远征）——把"锁"变成"岔路"。
- **追赶包**：版本更新后回归玩家，已过章节扫荡奖励 ×1.5×缺天数（封顶 7）⊙；回归弹窗=离线报告卡的变体。
- 存档导出/导入（JSON 文本框，零依赖）+ save v 字段——丢档=100% 流失，这是最便宜的留存保险。
