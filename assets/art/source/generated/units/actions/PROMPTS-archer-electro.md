# Archer / electro trooper ImageGen source prompts

Built-in ImageGen was used with each existing 512 px portrait as the sole
identity/style reference. The six generated transparent three-pose masters are
saved next to this file. This is source-art work only; no runtime PNG or
`hd2d.js` path was changed for these two units.

Input image 1 is the EXACT identity and pixel-art style reference: one blonde elf-eared archer wearing a moss-green hood and cloak, cream tunic, brown boots, quiver on back, holding a small curved wooden recurve bow and a real arrow. Make one HORIZONTAL THREE-FRAME ATTACK ACTION STRIP of the SAME character facing SCREEN RIGHT throughout. Three distinct sequential full-body key poses in three separate equal-width cells: (1) bring arrow to bow and begin drawing string, (2) full draw with arrow aimed clearly to the RIGHT, (3) release and short recoil with bow still held. One character per cell, identical hood/face/ears/hair/cloak/quiver/bow; same body scale, boots on one bottom baseline; generous transparent gap between cells. Bowstring, arrow and hands must connect logically; do not swap the bow for a crossbow, gun, spear or staff. Crisp detailed pixel art matching reference, no scenery, ground, shadow, VFX/projectiles beyond the held arrow, text, border, divider or watermark. GENUINELY TRANSPARENT alpha background.
