## 2. 战斗系统（analysis-combat.md 逐字附录 + 父代理 adHurt/tHurt 全文亲验）

- **四类伤害**（hurtValue 分发 @2497451）：type1 物理(adHurt)/2 魔法(apHurt)/3 真伤(tHurt)/4 固定(fixHurt=原样返回)/5 复用 adHurt。**真伤/固定/type5 完全绕过双护盾**（hurtCalc 逐字 `0x3==type||0x4==type||0x5==type → hp直扣` @2498425）；双护盾 shield2 外层先扣、溢出进 shield1。
- **减法护甲**：`dmg=max(ATK−有效防, 0.2×ATK)`（@2499273 亲验）——无 def/(def+K) 曲线，堆防是线性阈值战；有效防=(pDef−穿透)×穿透效率×怪系 defPer，penFlag/冰冻可清零。
- **格挡**：dmg=(1.2×ATK[暴]−2.5×防)×(1−BlockEff∈[0.2,0.7])−(0.25×防+格挡值)，保底 10%ATK。受伤减免三重乘区、各自保底 30%。
- **确定性战斗**：命中/暴击/格挡=属性减法+**种子 LCG**（perSeed[3..9] 分通道 @1011987）——战斗可离线复算/录像回放的真实现基础。
- **怪物生成**：Stat=基表×品质%/100×(1+杀戮值加成×kv/100)×杀戮阶梯（getMonsterDataS/M/B/God 四套 @1384328~）；善恶三连怪（善良 HP0.6/攻0.8+杀戮+20 ↔ 罪恶 1.3/1.2+杀戮+5 @1180413——贪杀戮值就得挨更强怪）。
- **杀戮值橡皮筋**：怪物强度阶梯 ×1.2→**×180**（@1373493，超指数）而奖励侧封顶 **×8**（@1375671）——高杀戮段是"风险远大于收益"的软性封顶设计。
