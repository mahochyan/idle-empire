# 九时代主城三维制作流水线（独立候选）

这套工具把现有九张 1024×525 原画、中央清场候选和可编辑模型放在同一张 **360×200 CSS px** 对照页中。`manifest.json` 是制作清单；`audit.py` 只读取原文件、检查 GLB 与 PNG 并生成 `audit.json`、`review.html`。所有文件均未被游戏、Android 包或存档加载。

## 运行与当前基线

从仓库根目录：

```powershell
python tools/visual/era-model-pipeline/audit.py
```

本次用 Python 3.13.14、Pillow 与现有资产实跑，退出码 0：原画 9/9，中央合成清场 9/9，GLB 候选 2/9，具备七个命名拾取节点的模型 0/9，运行接入 0/9。九张清场合成在遮罩为零的像素处与原画完全一致。基线 `master` / `406bce4dc86a7d12f442ceebe5143ec9fa6f6e6d`；未覆盖工作区已有改动。

打开 `review.html` 可按实际手机地图尺寸逐时代检查。三维候选是独立镜头渲染，**尚未与清场原画合成**；页面并置不代表合成通过。基础时代候选约 33,474 三角面／6.78 MiB、青铜约 8,126 三角面／3.58 MiB。两者缺完整地图、七个命名拾取节点和一致镜头，青铜样板在 360×200 下仍丢失原画环境层次。当前模型均不应接入运行地图。

## 每个时代的一次制作循环

1. **锁定共同机位和范围。** 在基础与青铜现有模型重制前，先选一套最终正交镜头，将主城、林场、矿区、农田、军营、学院、防御塔的投影中心对准 `manifest.json` 中的七个归一化坐标。当前青铜机位 `(6.5,-10,9.6) → (0,-0.12,1.56)`、`orthographic_scale=11.6` 只是参考，基础候选与它不一致。地图保持 1024:525，默认 360×200 CSS px `cover` 裁切。
2. **制作干净分层。** 原 `town-*.png` 保留给二维回退。新三维合成需要本时代无中央建筑的底图、遮挡前景、深度对应的道路/桥与七处地标。现有九张中央清场仅解决主楼区域，不是全景三维背景。基础时代的新中央 ROI 与旧全幅清场候选为不同文件，旧文件保留给已有主楼样板。不要将完整原画放在新主楼后面，避免建筑重影。若要画新位图或修遮挡，使用本项目美术生成流程；脚本只负责裁切、贴图打包和 QA 计算。
3. **在 Blender 做独立结构。** 每时代至少有与原画同样可辨认的主楼屋脊、台阶、两侧翼楼、时代专有附属结构；同时做林场、矿区、农田、军营、学院、塔、桥、道路与地形。贴图保持明亮日间、原画的蓝色屋面和暖石颗粒尺度；材质图母图与运行图并存。共享树、河水、地面材质可以复用，但九时代中心轮廓不可只换屋顶颜色。源 `.blend` 中保留独立部件方便再编辑。
4. **添加七个拾取锚点。** 在最终导出 GLB 的节点树保留名为 `PICK_town`、`PICK_wood`、`PICK_stone`、`PICK_food`、`PICK_army`、`PICK_tech`、`PICK_defense` 的节点，投影中心须对应清单坐标。已有青铜脚本在导出时按材质合并几何，当前 15 个材质网格没有这些节点；新增锚点时要在合并后创建并选中导出。实际触控仍需由 UI 提供至少 48 CSS px 的入口，不能仅用一个细小模型命中盒。
5. **导出后重新导入审查。** 输出 `assets/art/models/candidates/era_town_<id>.glb`、`assets/art/source/models/era_town_<id>/era_town_<id>.blend`、源脚本、原生贴图母图、运行贴图、独立 GLB 重导入渲染和 360×200 对照。跑 `audit.py`，检查 PNG 尺寸、GLB 内嵌图、无外部 URI、三角面/文件大小、七个命名拾取节点和清场遮罩外像素完全一致。然后人工比较屋脊、入口、道路接缝、树冠遮挡与原画；自动数据不能代替画质判断。
6. **接入与实测门禁。** 只有基础与青铜两个完整场景在 320、360、390、430px 默认/展开视图均达到原画可读度，七入口与状态正确，且 WebGL 丢失时从当前状态回退二维图，才进入运行层。每个时代迭代同样门禁。建议起始预算为整场景 ≤30,000 三角面、≤32 绘制调用、当前时代 GLB ≤4 MiB；这只是计划预算，要用中端 Android 实体手机十分钟离线运行修订。用户暂无法提供实机，因此实体设备帧率、热状态、触控尚未验证。

## 已有素材与下一处优先模型

`manifest.json` 列出每个时代的独立中心轮廓和道具，不把九张颜色替换视为九个三维城镇。九张中央清场合成可供模型试装。**优先铁器时代**：原画中心是高石墙、蓝铁瓦双翼和有层次的中塔，门前为多级宽台阶；右上独立军营与左上学院必须保留。铁器样板的主要造型应从青铜的横向柱廊变为较高、较密的石与铁结构，再加炭炉和铁箍城门。青铜材质表不能仅换色复用作铁器成品。

当前 `review.html` 的检查结论：现有原画在树木、道路、河桥、七地标和远景密度上仍胜过两张独立模型。为了保持用户的原版明亮美术，在模型和分层场景达到同等可读度前继续使用原图。回退本工具只需移除本目录；运行资源、战斗数值、`S/B` 与 `rts_save` 没有变化。
