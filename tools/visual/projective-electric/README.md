# 电气时代市政大厅：独立实体投影样板

这是一处针对现有电气时代主城原画的三维技术样板，**没有接入游戏或 Android 包**。`model.js` 是可编辑几何母版，浏览器加载本地 Three.js、原画 `town-sci_electric_age.png` 和中央清场候选，以固定机位组合背景与实体。它没有 GLB 导出。游戏数值、战斗、`S/B`、`rts_save` 和已存在的未提交文件均未改动。

- [320、360、390 CSS px：原画／0°／−8°／＋8°](../../../hd2d-previews/qa-projective-electric-320-360-390.png)

主体几何单独重建成对称白石大厅、双蓝顶侧翼、前凸柱廊、八面钟塔、分段穹顶、两座角塔、宽阶梯及四处陶瓷电线圈；侧面和背面具备实际深度，蓝旗作为二维布片。主屋顶有前、后坡面，参考机位正面采样原画以对齐已有细节，侧面使用简化的石材、蓝顶和铜材。±8° 只是检查视差的有限转角，不代表任意角度可绕行。中央以外仍是二维原画，并非完整三维城镇。

## 本机验证

从仓库根目录运行：

```powershell
node --check tools/visual/projective-electric/model.js
node --check tools/visual/projective-electric/capture.js
node tools/visual/projective-electric/capture.js
```

2026-09-28 三项最终退出码均为 **0**。Edge 无头模式用仓库资源经本地 HTTP + SwiftShader 渲染；截图是真实浏览器输出，非纸上结构推断。C: 当时没有可用空间，捕获器把私有 Edge profile 和 TEMP/TMP 放在 E: 的本样板目录下，并在每次浏览器退出后核对路径及清理私有 profile。

## 画质判断与剩余工作

在 320–390px 对照中，默认镜头可辨识蓝顶钟楼和白石门廊，色调仍明亮。±8° 时侧翼的纹理和轮廓明显变扁，钟楼局部呈简化折面；四处电线圈在 320px 中辨识度不足，原图清场与模型仍有轻微接缝。**本轮美术验收未通过，不能替换运行中的原画。** 后续需要独立绘制屋顶与侧墙贴图、强化钟楼与线圈在手机尺寸下的轮廓、补真实地面阴影，并与其他三维地标一起做遮挡与运行性能验证。

Android 实体手机离线运行、温升、手指触控及 30 FPS 验收未运行；用户暂时不能提供实机。当前样板只保存在 `tools/visual/projective-electric` 与两张 `qa-projective-electric-*.png` 对照图中。撤回时移除这些候选即可；游戏仍继续使用原本的电气时代地图，存档不需迁移。
