# 铁时代中央议事厅：三维投影候选

这是按 `assets/art/scene/town-sci_iron_age.png` 中铁时代主楼重新建的独立实体样板；游戏、APK 和存档都没有引用此目录。可编辑源文件是 `model.js`，用仓库内的 Three.js、原图和已制作的中央清场候选直接在浏览器渲染。

## 形体与场景

- 主体是三栋相连的石砌体积、前后两面不同坡度的主屋顶、两翼蓝瓦斜顶、八面钟塔和分段穹顶、两座角塔、实体台阶及柱脚。二面蓝旗保留为贴在楼体上的平面布片。
- 各主要墙体和屋顶都有厚度与背面；参考视角的墙面、屋顶正面使用原画坐标投影，主墙侧面也沿用原图纹理，屋檐侧面采用蓝瓦与石材。动态斜向光照改变可见表面的明暗。
- 原画背景与中央清场候选根据主楼轮廓局部混合，周边地标、桥、道路不重绘。场景只允许 ±8° 观测，以核对实体视差，不声称可自由旋转。
- 运行时仅需本地静态服务；`file://` 的 WebGL 贴图不作验收依据。

## 复现

在仓库根目录运行 `node tools/visual/projective-iron/capture.js`。本次退出码 **0**，输出 `qa-metrics.json`、`hd2d-previews/qa-projective-iron-320-360-390.png` 和 `hd2d-previews/qa-projective-iron-clay-360x200.png`。

结构检查结果：**51** 个闭合实体，**582** 个三角面，深度 **−3..87** 个场景单位，**5** 批网格、**6** 次绘制；主屋顶前后坡面法向点积 **0.256**，证明不是同向平板。反向移动光源造成中央区域均值变化 **0.101/255**（0°）与 **0.130–0.136/255**（±8°）。从原图到场景的中央区域每通道平均像素差为 **4.07/255**（0°）和 **17.73–17.86/255**（±8°）；中央观察区以外为 **0.017/255**。这些数值是同一浏览器对同一原画的差异量，不代表美术质量分数。

## 美术审核

320、360、390 CSS px 的对照已在实际输出尺寸检查。0° 保留了原图的大体蓝顶石楼比例，但主屋顶和台阶的线条偏硬。±8° 时两翼墙面及屋顶侧边偏平，蓝瓦细节比原画明显少；中央主楼周围还有轻微接缝。**视觉验收未通过，保留为候选，不接入 `hd2d.js`、不打包 APK。**

后续需重绘真正可绕看的铁时代屋顶/侧墙纹理、细化钟塔轮廓和背景遮挡，再按 320–430px 逐档复检。此模型也未导出 GLB；JS 网格源码是当前可编辑母版。当前游戏仍使用原本的铁时代图；删除此目录和两张 QA 图就可丢弃样板，不涉及 `S/B` 或 `rts_save`。
