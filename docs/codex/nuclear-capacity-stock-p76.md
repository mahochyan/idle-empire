# P76 现存机巧图纸实付与核前知识仓条件边界（2026-09-24）

承接 P75 同一份第45关、126人口、v29 已付款档：电力科研知识仓15级、知识容量40,582,080、神战勋章804,284、守御之石13、机巧拓仓图纸Ⅰ累计使用68张。母本核能节点450023单笔需要知识100,000,000与勋章800,000；勋章库存已够，知识容量不足。文档目标继续借鉴《放置时代》的成长和难度骨干，保留我方像素风及前中段机巧／电力后神魔西幻命名；原创玩法仍后置。本批不改玩家代码、配置或存档格式，只沿真实档检验手头材料的图纸增长，并把两种仓容路线的**未付款边界**单独列出。

## 同档实付

`tools/verify/probe-stock-scroll-p76.js`加载`p75-electric15-paid.json`，固定 xorshift 种子9，按实际边贸行报价、库存与上架次数调用`exchangeWildMaterialForScrolls`、`useStorageScroll`和`refreshBeastExchange`。免费刷新次数用完后，只以`tick()`在线恢复；原有90粮工／36学者岗位继续生产，未注入材料、知识、人口、等级或胜利。买图纸花费蛇胆200、蛮牛角1400、铁甲龟壳520，共2120份现存郊野材料，取得并使用12张。边贸行刷新21次，等待19,141模拟在线秒（约5.32小时），图纸已用68→80，知识容量40,582,080→43,480,800，知识库存394→8,269,306；勋章804,284、守御石13、449名现存兵和第45关进度不变。当前距离知识单笔1亿仍差56,519,200容量。最终档`docs/codex/reports/data/p76-stock-scroll-paid.json`的SHA-256为`0046a6971082bfa77de84a0ae000a78c496e2d6138341db72b05f6bbb0d1160f`，独立v29重载通过。

这是一个固定随机、高频操作、即时刷新回放；19,141秒只计在线tick，不含玩家刷新点击、战斗、动画和先前获得材料的时间。因此不能把12张图纸的在线等待外推为后续数百张图纸的总时长或真实玩家效率。无输出文件的复跑在刷新次数、资源、tick和仓容上相同；`save()`中的`Date.now()`会改变新档时间戳，复跑的SHA不保证与上述归档快照相同。

## 未付款条件边界

`tools/verify/probe-capacity-sensitivity-p76.js`在不写回的独立VM副本中调用**当前**`resCap`与`upCost`，只为判断下一条路线的规模。保持图书馆715级、研究院300级、电力知识15级及其余科技不变，图纸累计需要达到**314张**才首次装得下1亿知识，即当前80张之后还要234张；这234张既没有库存，也没有付款。另一极端：条件设图书馆715→1000级、研究院300→1000级，保留现有80图纸，知识容量只有83,516,400；仍要图纸累计**116张**（额外36张）才达100,219,680。两座建筑额外985次升级的条件报价分别为木、石各116,485,200及各601,578,030，合计木、石**各718,063,230**，尚未计产能等待。研究院最后一次单笔木、石各1,430,640，当前木仓879,120、石仓586,080均不能装下；若始终保持80图纸，仅为承载这笔付款，条件还需石仓库35→89级，额外石料报价2,056,323。上述等级、图纸和报价全部是条件计算，**不是已达成进度或最优解**；两条路线也不能简单相加为实际通关时长。

本批决定继续保留核能1亿知识／80万勋章的母本单笔门，不能将核后星阵320004的知识仓加成前移。当前库存图纸扩容已验证但只推进约290万容量；后续应以现有郊野材料、建筑储存与守御石来源做可付款的混合路线比较，同时核对大量主动刷新／狩猎和建造操作对50小时以上内容目标的影响。当前玩家代码尚无核能研究入口，不能将容量条件式等同核能解锁。前中期「机巧拓仓图纸Ⅰ／边贸行／研究院」与电力后「守御之神／守御之石」继续按用户确定的主题分层。
