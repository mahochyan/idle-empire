# P273 复苏圣像受击技能与星核秘典第6级实付

## 文档目标、代码现状、本次决定

主线100关仍须在全部核心科技和军力成长后形成陡峭终局；「拓境远征」按《放置时代》承担区域材料与发展。P272只接通复苏圣域首战、圣愈叶与星核秘典1级，不能证明第6级材料能持续获取。P271则证明现有星际先遣兵在候选终局战中没有稳定优势。本批把复苏材料战的明确敌方技能接进真实战斗，再从P272同源已付款档连续胜利、逐笔支付秘典第2–6级。正式主线敌数、星际兵属性和UI美术均未调整。

母本源`210(1)_unpacked/_analysis/entities_table.json`的540041「自愈之神」技能1规定：受伤时若攻击者攻击力大于其当前防御三倍，回复攻击者40%攻击力的生命、防御+1，攻击者每有200攻击再+1防御。我方「复苏圣像」按**兵团单兵攻击属性**判断和取回复量，HP仍是此前映射的单体生命值；只在实际失血且目标存活时触发，回复不越过进场最大HP、不生成兵员。技能2的攻击降防/击杀增益和技能3的面板下限/首次防御效果尚未映射。因此这是母本技能1的本地模型适配，不声称完整复现母本战斗公式。

本次还纠正一项成长分类：母本370009的`GodSkill01/02/03`是受`GodGameLv`独立试炼星级影响的觉醒神技，现有我方`armsUp`兵装星级不等于它；`ArmySeaList.godTrialSkill`中的神炼技能是**第三条**养成轨。前者包括宇航兵破防和真实伤害，不能免费接到已有兵装；两轨的费用、胜负、激活和持久状态仍需另立接线。

## 本次战斗实现

在`CFG.units.revival_god.onHitRecovery`记录门槛和效果数值；远征与驻军均将实际攻击者传入共享的`applyCombatDamage`。普攻、蒸汽/电磁追击、溅射与时光回声若真实打到复苏圣像，会按同一规则检查技能。回复和叠甲只作用于`B`或驻军的临时敌体，不写入`S`，死亡单位不复活；远征日志显示「圣辉自愈」。其它敌人与无攻击者的直接伤害仍按原路径。实际浏览器用条件放大首战敌体生命，观察到了日志；这个条件夹具不是玩家实付战果。
