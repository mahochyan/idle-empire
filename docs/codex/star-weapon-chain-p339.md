# P339 星核兵装研究、锻造与首击接线

## 结论和边界

母本核能阶段 `warScience` 470081→470082 和 `weapon` 230082→230083 已接到本项目「星际先遣兵」现有军备系统，玩家可按前置研发、逐次锻造、装备并在远征和驻军触发首击。玩家可见名采用「星界战机」「星陨飞弹」，保留机器武器主体，后段显露星界西幻词汇。没有改 UI 样式、美术、100 关主线、材料副本结构或原创玩法。

本批是条件足额配置和代码路径验收，不是从 P338 有价存档实际购得。P338 检查点警戒 7650、知识 205249904、勋章 944、钢 1613、高能核心 29。首件研发还差 999056 勋章；首次 20 次锻造需钢 200000、高能核心 160。两件全部制成则研发共知识 2 亿、勋章 200 万，锻造共钢 40 万、高能核心 320。不能从定向 UI 注资和战斗夹具推论这些材料的自然净流、玩家时长或高警戒可胜。

## 实现和存档

`config.js` 增两件军备与首击配置；`math.js` 增默认状态、同 v32 候选迁移、校验、共同技能函数，远征调用该函数；`garrison.js` 驻军调用同函数。`ui.js` 仅增既有军备卡片的两个技能文案，没有改 CSS、布局或图像。研究、锻造和装备继续复用既有动作函数及失败回滚。

旧 v32 主档仍从 `rts_save` 读，缺两键时先在候选数据补未研究零值，迁移成功前把原文保存在 `rts_save_premigration`。明确非法的级数、无前置却研究飞弹、未来 v33 均拒载并阻止 `tick/save` 覆盖原文。P338 满编检查点实测候选迁移后保留警戒、铭石、知识与攻击星级。存档版本保持 v32；同版本的旧档缺键与新档缺键无法仅凭版本区分，因此缺键按兼容迁移处理，显式坏值仍拒载。

战斗技能只改 `B` 的临时单位，不写入 `S.pool` 或常驻阵型；首次未命中会消耗首击机会，与既有狙击／迫击首击规则一致。远征异步回调继续使用既有 `battleEpoch` 防旧战斗回调写入新状态。
