# 战败后伐木岗位重分配恢复 P115

日期：2026-09-25

策划文档版本：v2.42

## 问题与方法

P114发现固定0.9随机压力样本在第4关战败后，队列因木料不足停产；把等待提高至7200秒仍无法补齐弓手。本批沿用同一早期路线、敌人和确定性随机值，只在首次战败后转移现有村民岗位，再用真实生产tick、训练队列和同关战斗结算验证。

共比较从煤工或石工转出1～3人到伐木的恢复窗口。煤工转调样本为1人155／156／157／158秒、2人79秒、3人53秒；石工转调样本为1人158／600秒。全部分支不新增人口、不借入资源；队伍目标仍是15步兵、13弓手、15青铜刀盾兵。0.9是双方共用的固定随机压力值，不是概率或胜率样本。

## 结果

| 败后转调 | 等待 | 同关重试前补兵状态（三个支线） |
|---|---:|---|
| 1名煤工→伐木 | 155秒 | 均为12弓手／5青铜刀盾兵，弓手队列剩1，木79 |
| 1名煤工→伐木 | 156秒 | 均仍为12弓手／5刀盾兵，队列剩1；其中两支账面木82、可支付1名，但生产tick尚未交付 |
| 1名煤工→伐木 | 157～158秒 | 当前／食物支线在157秒达到13弓手；金属支线158秒仍差1名 |
| 2名煤工→伐木 | 79秒 | 均达到13弓手，但只剩3／4／3名青铜刀盾兵 |
| 3名煤工→伐木 | 53秒 | 均达到13弓手，但只剩2／3／2名青铜刀盾兵 |
| 1名石工→伐木 | 158秒 | 当前／食物支线达到13弓手，金属支线仍差1名；均只补到5名青铜刀盾兵 |
| 1名石工→伐木 | 600秒 | 三支均达到13弓手，分别保有14／9／15名青铜刀盾兵；金属支线尚有6名刀盾兵排队 |

常数0.9下上述重试仍全部失败。队伍和训练队列恢复只是恢复链路的一个验收点，不能保证在这个极端随机压力下战斗胜出。尤其是煤岗位直接支撑煤矿冶炼与铜补给，快速挪走煤工会把弓手木料瓶颈换成青铜兵铜料瓶颈；临时挪用已接近仓限的石料岗位，短期代价较小，但在金属支线和不同等待时间下结果仍不相同。

## 策划结论

这组早期样本支持把战后恢复设计成“看缺员兵种成本与当前资源库存，短期调度已有岗位”的候选方案；它不支持固定抽走煤工，也不支持固定等待时长。石料已接近仓限时，短期将1名石工转为伐木比抽调煤工更能保住金属兵补员，但600秒结果仍受原先支线库存影响。需要再用常数0.5及可复现种子分布验证，再决定是否纳入保底路线或提供显式岗位建议；任何自动调岗、储备等新机制先不立项。

本批不更改玩家代码、配置、奖励或存档，也没有改变敌人属性。P114/P115的常数随机压力测试不能代表普通玩家胜率，更没有验证敌压成长曲线。
