# P271｜星核实付档的第99关与终局兵种复查

2026-09-27。本批接续[P270星核实付档](nuclear-mixed-paid-p270.md)，核对「帝国战线」第90–100关能否承接用户确定的高难主线；《放置时代》式「拓境远征」仍承担材料和发展。**结论：现行第90–100关偏轻，而现行星际先遣兵在高压第100关没有形成科技后的有效战力台阶。**本批只交付隔离探针、实付开发存档与设计复查，暂不把候选敌数、兵种属性或科技硬锁写入玩家配置。

## 文档目标、代码现状、本次决定

文档目标是完成核心科技和综合军力成长后才可打完100关，且每个难度墙有可付的战力出口。代码现状：`levels.js` 第90关和第100关的Boss各11组、每组1人；第99关12组共144人。星际先遣兵需先付星核科技知识1亿、战备勋章80万，再按每人铜/铁/钢各8000训练；当前单兵生命4、攻击40、防御18、速度8，技能文案没有独立的实战效果。电磁兵攻击55，合金兵生命5.5、速度11，蒸汽装甲兵生命6.5、防御22。因此不能仅凭“最后解锁”推断星际兵更强。

本次决定是保留双线结构和正式数值，在实付编队中验证缺口。未经实付的临时强化仅作为灵敏度测试，不能视作定稿数值；单纯加Boss人数或加研究按钮锁都不能替代完整成长链验收。
