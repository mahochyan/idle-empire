# P180：实付骑兵线续闯第18—20关（2026-09-26）

> 历史基线：本报告的第20关为P186调整前的9 HP配置；文中“当前”指当时锁定的输入快照。正式关底配置见[P186](live-l20-boss-p186.md)。

## 同源起点与实际动作

[探针](../../tools/verify/probe-current-l18-l20-cavalry-p180.js)从[P175](current-l17-cavalry-bridge-p175.md)的四份第16关实胜终档重新执行骑兵线：真实建造骑兵训练场、实付研究侍从骑士、训练并打赢第17关。固定战斗随机流种子1／42，均有当前第3关首胜`+6拓居令`与隔离VM内关闭该奖励的分支。当前重建的第17关战后经济、兵池、编队、解锁与战斗结果逐项等于P175骑兵线记录；第17关敌阵除更名文案外未变。原始存档含`Date.now()`，本批记录新存档SHA，不将它与旧时间戳SHA强行比较。

每场从前一关真实结算档重载，使用`train()`实际排队、逐秒`tick()`等待三种兵补至青铜刀盾兵15／侍从骑士15／游侠13，再用真实清编／入编和异步战斗回调挑战下一关，战前战后均`save()`并重载核对。每场最多等待7200个模拟在线秒；未注入材料、士兵、战功或科技点，未调用市场、离线或驻军。所列“秒”只统计`tick()`次数，不含战斗动画和真人操作时间。四支第18—20关战前都实际入场这43名兵；民兵未入场。

## 关底职责与奖励复查

真实`initBattleState()`显示第19关敌军9团、78 HP、`atk×HP`合计702；第20关“骑兵统领”同为9团，却只有9 HP、`atk×HP`合计105。第20关虽有攻击×1.35、防御×1.3与30回合上限，四支真实骑兵线仍在1—2回合胜利，仅损4—7名兵；第19关反而耗4—5回合并损22—34名。这是**本样本下第20关Boss职责偏轻**的实战证据，不再只是静态配置推测。与[P178原兵线](current-l18-l20-bridge-p178.md)同种子、同第16关起点对照，原兵线两支止于第18关、两支止于第19关，从未触达第20关；骑兵线四支均通关，但它额外实付建筑、研究和多次昂贵补兵，不能把路线差异当作通用胜率或无成本平衡结论。本批不改Boss数值。

第20关名义奖励为木6000／石4500／粮4080、战功25，以及三种精魄各55%概率掉1；四支固定随机流各实际拿到两种精魄。由于这批终档木仓已满、石只差6到仓顶，实际入账木0、石6、粮约2995—3000，战功25。第19关名义木796／石597／粮541、战功11，样本中战功11与粮541入账，木同样入账0，石多为6。可见Boss名义奖励远大于第19关，但在这条路线的仓库状态下大部分木石溢出；粮食奖励则将低位余额补回上限3000。第20关胜后四支均有已击败1—20关记录，并从两个前排格解锁到三个；未把等待期间自然人口增长算作Boss奖励。
