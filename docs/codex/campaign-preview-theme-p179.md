# P179：关卡预告与敌阵、主题命名复查（2026-09-26）

## 问题与本次决定

当前`ui.js`关卡选择卡直接展示`CFG.enemies`的`name`、`desc`与实际敌军名册。改动前，10关仅有步兵却预告弓兵（3／13／23／33／43／53／63／73／83／93），9关只有步弓却预告骑兵（16／26／36／46／56／66／76／86／96）；另有9关仅出场T1“侍从骑士”却写“重骑兵”（17／27／37／47／57／67／77／87／97），38／48／58关的关卡名还称“重骑突击”。这些文案会使玩家按并不存在或级别不符的兵种准备出战。

本批仅修正上述31关的可见名称与描述。前段改用边境、军镇、山口、工坊、矿道、锻坊语汇，后段逐渐转为帝国、王都、圣殿；实际有T1骑兵时明确写“侍从骑士”，没有骑兵时写步弓前哨。第3关首胜“拓居令”及其6地契奖励保留。没有改`units`、`reward`、掉落、Boss倍率、战斗函数、存档或UI实现。

此处“步兵／步弓”按兵种系别和关卡编队命名；敌军摘要仍按现有`CFG.units`把基础步兵显示为“农民”、基础弓兵显示为“猎人”。关卡文案并没有把这些基础单位升级为专属帝国兵种。第10关已有“重甲步弓”称呼、后段法师与Boss名称是否需独立敌方造型，属于未完成的全时代美术／敌人身份映射；本次兵种缺席修正不替它们定稿。
