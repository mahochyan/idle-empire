# 机巧遗迹与神祇挑战的双奖励成长桥（P48）

## 文档目标、代码现状、本次决定

- 文档目标：沿《放置时代》的时代、资源与难度骨干推进，早期用我方机械／聚落美术命名，电力后的神祇内容转入西幻；先完成成长闭环，再设计新玩法。人口增长保留非关卡的经济路径。
- 改动前代码现状：我方机巧遗迹、幻影之神、守御之神挑战只结算专属材料；杀戮之神才结算独立勋章。P44真实新档到电力首兵时只有10勋章，科研精通6～20级须1950勋章；当时验证的路线额外生产银两并换4次勋章。
- 母本事实：`210(1)_unpacked/_analysis/entities_table.json` 的540001／540011／540021三个`godWar:Get`各自包含160010勋章×40，以及独立材料；基础奖励随警戒值按既有胜利算法增长。母本神祇和我方三处挑战是机制映射，名称与敌军编组仍用我方设计。
- 本次决定：在已有三处挑战补勋章基础40，与主材料同一次胜利结算；沿用现有警戒值倍率、仓容、写档失败回滚。早段玩家界面显示「机巧遗迹／遗迹晶核／战备勋章」，电力后显示「幻影之神／守御之神／神战勋章」。不改战斗敌人、人口、主线或存档字段。

## 新档实付回放

单位均为在线tick秒，探针不注入资源、胜利、人口或兵力。相同路线从真实新档到102人口、电力首兵、普通关卡0胜，机巧遗迹11胜（警戒值1100）后取得累计2714枚额外勋章；原路线另有10枚，故科研精通前库存2724。真实研究动作逐级付科研精通6～20级的1950勋章与知识97500，终点第2632423在线秒，余774枚，科研精通20级、知识毛产492→984/在线秒；高级市场交易次数0，v21主档重载保留。P44旧口径因缺少该来源而需要4笔银两交易，到第2635131秒才完成，耗2835秒；当前路线从同一第2632296秒节点仅增加127秒。两组都是高操作开发探针路线，不含动画及真人操作，也不构成总体难度已校准的证据。

## 第45关与后段边界

从当前完整新档在第2632423在线秒进入关卡段，种子9沿现有装甲预备队与实付补训路线45战全胜，至第2640912在线秒打开前／中／后各4阵位；关卡段耗8489在线秒，累计训练合金389、猎人129、装甲40，战损523，人口102，v21存档重载通过。早段多得的勋章未改变这段战斗费用或敌人；和P47旧双奖励缺失路线相比，终点提前2708在线秒，恰好来自科研段减少的等待。第45关打开阵位仍需要逐关胜利，新增勋章不会直接增加村民或解锁阵位。历史P47结果属于双奖励加入前的路线，不与本批新档口径混写。

用本批新第45关存档实付三团合金／装甲／猎人各40人，在固定随机0.5下连续补兵十胜，到杀戮警戒值1000、累计2948勋章后第11战败，所获2174勋章与历史同阵容相同，差额774来自起始库存。旧存档额外对照中，只买蒸汽装甲枪Lv1或Lv3也未突破1000；额外实付青铜／铁／白银各15人的六团阵容可突破1000，但在固定0.5下于1500前后再次受阻。种子1～20的重复试验是确定性样本，不是玩家胜率。新增双奖励解决前段科研费用和部分勋章存量，尚不能证明核能80万勋章、1亿知识仓以及后续全时代曲线可达。尤其我方HP参与伤害，后续军力质量成长须同时审视伤害、承伤、战损与驻军路径。
