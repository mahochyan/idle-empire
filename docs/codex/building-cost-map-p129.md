# P129：建筑升级成本按母本实体类型映射

日期：2026-09-25。范围：纠正P128工坊成本曲线的适用对象；只改建筑配置、`upCost`分派、专项回归和策划记录，不涉及UI、美术、存档或其它玩法。

## 发现与决定

母本配置区分`workShop`、`repertory`、`town`等实体族。`addWorkShopLv`（`deob_main.js`锚点1,485,372；源ID 260001–260015）使用分段线性费用；`addRepertoryLv`（锚点约1,488,608）是单独的仓储费用；`autoHouse`通过`Need[1]×(1+0.2×当前城镇级)`扣地契。现有项目并非每个`CFG.buildings`项都有母本映射，P128将工坊斜率套到全部非仓储建筑，证据范围不足。

P129在配置上将以下11个产出建筑／学院显式映射到母本workShop曲线：

| 我方建筑 | 母本workShop ID | 对象对应依据 |
|---|---:|---|
| 伐木场 | 260002 | 伐木工人产出加成 |
| 采石场 | 260003 | 矿工／矿石产出加成 |
| 农田 | 260001 | 食物工岗位产出加成；功能映射，不等同母本farm表240001 |
| 煤井 | 260005 | 煤工产出加成 |
| 矿井 | 260007 | 铜工产出加成；对应冶铜厂岗位效果，不是母本矿工实体260003 |
| 冶炼厂 | 260008 | 铁工产出加成 |
| 冶银厂 | 260009 | 银工产出加成 |
| 冶金厂 | 260010 | 金工产出加成 |
| 冶钢厂 | 260011 | 钢工产出加成 |
| 铸币厂 | 260012 | 铸币工产出加成 |
| 学院 | 260006 | 学者产出加成 |

`upCostModel:'workshop'`决定费用曲线，`workshopSourceId`记录证据来源。母本260015蒸汽工厂的Need/5特例仍由建筑级`upCostDivisor`覆盖；我方没有该来源设施映射。其余未映射建筑（含铜炉、营帐、训练兵营、箭塔、市场）保留原`ceil(upBase×upCostLv^lv)`；仓储继续分别使用存量线性／仓储分段曲线，聚落扩建继续使用单独的地契+20%级增公式。

显式来源ID只证明费用函数的对象类别，不证明我方`upBase`等同母本`Need`、当前`lv`等同源等级，或建筑产能收益一致。尤其农田和矿井是按岗位加成职责对应，不是同名实体对照。尚无证据的建筑不因共享`type`而自动套工坊公式。
