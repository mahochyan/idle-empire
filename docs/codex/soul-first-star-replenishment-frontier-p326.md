# P326 英魂首星补兵与警戒5000成长压力复查（2026-09-28）

## 文档目标、代码现状、本批决定

策划的骨干目标仍是《放置时代》式发展材料与成长／难度曲线，100关单独作为直到全科技后才能打完的高难主线；玩家可见主题由机巧工业渐入西幻。P325把英魂遗境接为九个可选敌位，并从P324真实付费满编档在选定连续随机流中取得奥术师首星，但结尾损失265兵未补。本批先用真实生产、训练和编队动作把该缺口补回，再从满编档分别测警戒5000的普通／精英敌位，以及“直接套母本指数倍率”的开发侧敏感度。**不把敏感度包装为已实施数值**，也不改变玩家代码、CSS、美术或100关。

当前运行代码在英魂战将母本怪物总生命与攻防相对值映射到我方单兵团模型，警戒强化为线性值；母本`getMonsterData_general`是每满1000警戒生命×1.4、攻防×1.2、数量×1.3。两套战斗量纲不同，单纯替换三个倍率不能证明难度对齐。P326用同一实际有价档做成对测试，给后续数值接线一个有证据的边界。

## 首星后有价补给

输入为P325[首星胜档](reports/data/p325-soul-nine-slot-first-star-save.json)，SHA-256 `624f027af07125a037e9c578cb58e8debc1a5eb5a1139c3f458f4a6d3667776f`。原档672总兵／626出战的编队取P324[警戒4550满编档](reports/data/p324-soul-alert4550-restored-save.json)，SHA-256 `ba54521f29f3bad88494f67b277c47e95c109a522f88ad9650c3a06e2e4aa69f`。P325首星档为407总兵／361出战，缺星际兵155、蒸汽装甲55、电磁兵55，合计265。通过真实`setPopAlloc`、逐秒`tick`、资源生产、`train`排队、`processQueue`实付及编队动作，补回265兵需8,873**模拟在线秒**（2小时27分53秒），实际扣铜／铁／钢各1,790,000；全过程最低粮292,229.6249，未断粮。终档[可重载](reports/data/p326-soul-first-star-restored-save.json)，SHA-256 `19881b1be6100c28efbb5e59bfbb878d79aa04d9604342700e978ed48267c594`，恢复672／626，警戒5000、余3铭石、奥术师首星和原九敌位均保留。完整资源／时间账见[补兵数据](reports/data/p326-soul-first-star-recovery.json)。这是单一高人口转岗排程，不是最短时间或玩家常态时长。

## 5000警戒战损和母本倍率敏感度

从同一恢复档对剩余普通、精英敌位各测128条独立xorshift32流。**现行代码**普通128/128胜，胜场中位战损28兵、均值31.21兵，胜奖5铭石／警戒+150；精英124/128胜，中位战损219兵、均值214.16兵，4个败场均损光626出战兵，胜奖7铭石／警戒+200。[完整实际战斗账](reports/data/p326-soul-alert5000-options.json)。种子1的普通胜场0战损，仅是选定条件结果；同种子精英胜损183兵，保留为[精英胜档](reports/data/p326-soul-alert5000-540399-win-save.json)。从该精英胜档真实补回183兵，又需6,970模拟在线秒，扣铜／铁／钢各1,350,000；[补兵账](reports/data/p326-soul-alert5000-elite-recovery.json)和[可重载恢复档](reports/data/p326-soul-alert5000-elite-restored-save.json)保留警戒5200、10铭石、首星及余下敌位。这是从首星补满档出发的一个独立选定战斗分支，战斗随机流重新设种子1；不能把分支胜率当作自然连续路线。

开发侧敏感度只临时包装真实`materialDomainEncounter`的英魂敌方数据，按源倍率把相对总生命×`1.4^floor(警戒/1000)×1.3^floor(警戒/1000)`、攻击规模×`1.3^floor(警戒/1000)`、攻防×`1.2^floor(警戒/1000)`，随后仍调用真实本地战斗，不保存这段包装为玩家代码。在5000警戒，同档普通128/128胜、胜场中位战损109；精英仅12/128胜、中位战损320，[对照数据](reports/data/p326-soul-alert5000-source-sensitivity.json)。敌方映射后的单兵团生命，普通从现行1700变为3993，精英从2337变为5491；这是**一种量纲映射假设**，不是母本战斗公式的等价证明。

同样的开发侧倍率套在P324警戒4550／91石满编档后，64个独立敌位生成流的首个普通目标仍64/64胜；但种子1从抽位起不重置随机流，前两场胜后到99石，第三场败且407出战兵全损、敌余57生命，[连续敏感度账](reports/data/p326-soul-source-growth-paid-check.json)。这不证明该倍率无解：中途真付补兵、其他编队和其他连续流都尚未测。它说明直接替换倍率会实质改变首星前可达性与补给成本，需作为下一张数值任务明确映射与验收，而不是把源倍率当成一行安全修正。
