## 已付入口与真实动作

开发侧报告目录原来没有第63／64关的完整检查点。本批从[P100零胜场、已付款扩仓存档](reports/data/p100-natural-campaign-entry-after-upgrades-save.json)出发，按下列现有P97工具命令顺序运行真实1–64关战斗、结算、补兵、编队，获得[第64关后v32存档](reports/data/p368-stage64-natural-paid-save.json)：

```powershell
node tools/verify/probe-stage-frontier.js --snapshot-in=docs/codex/reports/data/p100-natural-campaign-entry-after-upgrades-save.json --alloy-front --replenish --seed=9 --max-stage=64 --snapshot-final=docs/codex/reports/data/p368-stage64-natural-paid-save.json
```

命令退出码0、64／64关胜，无路线阻塞；第64关损12名弓手，战后113名总兵、68名现役。该路线在首战前已合法拥有34项科技、合金兵与装甲兵，属于高科研、高操作样本，不是一般玩家在第65关的军力代表。P368探针随后从这份原始第64关存档调用真实 `train`、`tick`、编队动作补12弓手，6在线秒实扣木960／石240／粮360，并恢复40合金兵＋40弓手、80人出战。接着真实建造步兵营并逐阶付费至T3，耗5＋20＋45＋90在线秒；第65关未胜前，`tierUpgradeLockReason('infantry_camp')`仍返回「需击败第65关『神射营』」。[第65关同源已付入口](reports/data/p368-stage65-entry-paid-save.json)可重载，125名总兵、80名现役。
