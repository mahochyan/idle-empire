# P280 星际觉醒前两技与简单守卫神技联校

> 本文是P280当时的战斗口径。P281已校正守卫出手人数与真伤量纲；现行结果见[后续复查](awakening-guard-mapping-p281.md)。

## 文档目标、代码现状、本次决定

《策划文档》要求母本式区域／材料成长与100关高难主线并行，星际先遣兵的觉醒应是成长手段，而非仅加基础属性。P279实付155名星际兵后，第6阶简单试炼11种子全败，且母本370009宇航兵的三段觉醒技与540091简单守卫神技都尚未进入临时战斗体。本批从P279可重载安全档做局部联校，不改100关、科技费、训练费、守卫基础攻生防、UI或美术。

母本`210(1)_unpacked/_analysis/entities_table.json`中，370009前两技为首次攻击前按每星0.6%概率降低目标防御（自身10%进场攻击），及每星0.3%概率造成真实伤害（自身1000%进场防御）；540091简单守卫攻击时30%概率追加自身30%攻击的真实伤害。解包脚本`deob_main.js`约偏移2292000的370009分支实际以`floor(0.6*superStar)`和`floor(0.3*superStar)`作为百分数，并在逐兵战斗对象上只判定一次；约偏移2315996的540091分支按千分之300判断追加伤害。因此本地合并兵团对每名**当前存活**星际兵在首次出手时逐次掷骰、每人用自己的入场攻防结算，并对简单守卫出手规模逐次掷骰。星数与兵员来自既有S字段，首次触发旗标、削防和真实伤害只存在于战斗体；远征与驻军共用函数及`applyCombatDamage()`，不造出常驻士兵。玩家可见战斗日志采用主题名「星核干扰」「星核贯穿」「圣域神技」。母本370009的100星第三技、540091的神力／神体及幻影／修罗守卫技能尚未实现；这次只验收上述三项效果。

## 真实路径与第6阶压力

源档为[P279已付款155兵档](reports/data/p279-awakening-star155-paid-save.json)，SHA-256 `5624c6aff153cb687b1e5d2a3b58402e5d34c69a2152c6a6a636e8c38f07e79b`，第5阶、130异果、626人出战。隔离VM中每个种子真实支付简单试炼、走现有异步战斗和败局结算。固定种子1–11各做四组：两技都暂屏蔽的旧基线、仅星际兵、仅守卫、双方同时开启；屏蔽仅在开发探针内替换函数，不写玩家代码或源档。旧基线11种子逐一与P279历史结果完全一致。逐种子数据和汇总见[技能因果汇总](reports/data/p280-awakening-skill-impact-summary.json)。
