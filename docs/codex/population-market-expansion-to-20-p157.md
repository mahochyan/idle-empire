# P157：零胜场市场扩容至20人口

日期：2026-09-26。单位为模拟在线秒；不代表现实玩家耗时。

## 验证范围

从P101生成的三份真实序列化新档分别接续顺序扩建、科研优先4人、科研优先7人路线。每条路线都不打关、不注入胜场奖励或资源；沿用P122的交易保留线：木100、石1000、粮1000。出售市场余量换金币，再经真实`exchangeResource()`购买地契、`upgradeSettlement('village')`扩容、在线`tick()`等待自然出生，最后给新村民分配木工。每次扩容后都保存并在隔离环境重载，核对人口、容量、岗位和聚落状态。

18→19需9张地契／900金币，村庄升至5级；19→20需10张／1000金币，升至6级。三路都达到20/20容量，保留0场战斗胜利；逐tick和每笔市场交易后都采样粮食，最低值仅高于1000保留线0.050–0.175。两次各把新居民转为木工，终点木工3人、产率9木/秒。

## 可得结论与边界

当前代码下，前段人口与住房可以靠自然出生、市场售余量买地契、聚落扩容形成零胜场保底；胜场不是18→20这段人口增长的必要门槛。第二档地契成本上升后，三路依然可续，但出售后的粮食几乎贴住保留线，不能把单次通过解释为宽裕、稳健的长期经济曲线。

该结果只覆盖三条经济／科研路线及18→20两个住房档。没有覆盖军事策略、短时在线与离线、战损补兵、随机战役或后续时代；也不评价玩家操作耗时、市场体验、美术/UI表现和最终奖励方案。应把这一段作为成长曲线的已验证局部接力，继续补四类策略共用的更高人口/时代检查点，再决定全局扩容节奏。
