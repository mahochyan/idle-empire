# P260–P261｜100关终局压力与电磁军备实付复查

**后续现行状态（v3.25）：**[P262–P263](nuclear-population-material-frontier-p263.md)沿另一条历史第45关、已实付80万勋章的同源路线扩至1002人口并复查材料挑战；它不与本报告的P242/P261第99关存档拼接资源、时间或胜场，尚未支付星核或完成100关终局校准。

2026-09-27。目标是让「帝国战线」第100关成为核心科技与综合军力成长后的高难主线终局；《放置时代》式「拓境远征」继续承担材料、时代与补兵供给。此处只校准终局的可达边界，不引入新玩法。原始游戏文件、正式关卡配置、存档格式与玩家UI均未修改。

## 现行落差与共同输入

现行 `levels.js` 第99关有12组共144名敌兵，第100关有11组共11名敌兵，后者的 `bossMult` 为攻击1.8、防御1.6。Boss倍率没有增加敌人的人数或生命。[P242尚未打过100关的战前v32档](reports/data/p242-stage100-recovered-save.json)原文SHA-256为 `8bab121b5fc92058356341423d4339bf8c4fdbf0906bb2284e01403330dd2630`：102人口、99关已胜、34项研究、未研究星核、没有兵种升阶。它在现行第100关可以实战胜利，但来自一条高操作、长时间在线推演的路线，不能当一般玩家概率。后续试验保留原档，只在隔离VM中改变候选第100关的11组敌兵人数。

## 电磁兵付费战前档

[P261探针](../../tools/verify/probe-stage100-electro-paid-p261.js)从同一P242原档出发，调用现行 `buildAct()` 把电磁兵坊从1级逐次升到12级，真实分配102名居民、推进生产 `tick()`，再经真实 `train()` 和队列付款把原有1名电磁兵补到40名。为铜等待11345、钢等待6240、训练20模拟在线秒，含其它步骤的总时间17781秒；39名新兵实付铜、铁、钢各312000。全程最低粮173007.08。最终合法设成电磁40前排、弓手20/20中后排，拥有164兵；重载仍为v32、99胜、34项研究、无星核或升阶。[完整实付结果](reports/data/p261-stage100-electro-paid.json)与[未通100关的电磁战前档](reports/data/p261-stage100-electro-paid-save.json)分开保存；后者原文SHA-256为 `b4dda7a54fff3f6e5cef74eef49ba2fb5614dd55b3bbfb9fcb3d4a1f8e0dbd4c`。这份档仍有此前P242路线形成的较高库存与操作量，不代表电磁科技在通常时长自然可得。

[P260探针](../../tools/verify/probe-stage100-pressure-p260.js)在每个独立分支中通过真实编队动作上兵，执行真实异步战斗回调、战损回写、保存与重载。候选仅把第100关每组1名敌兵等比例变为 `n` 名，保持11组构成、Boss倍率、战斗公式和奖励不变；`n=25`即275名、`n=40`即440名敌兵。每种编队与候选使用16条可重复的固定PRNG流。以下为胜流数／16，括号为**胜流**平均损兵；它们不是玩家胜率。

合金、装甲两种现有兵来自P242实付档；电磁与混编来自P261实付档，编队均经真实兵池校验。**条件星界列不是实付通关**：仅在隔离副本中临时加入星核研究及40名星界兵，检验现有终局兵是否有承接更陡关卡的理论能力；未支付星核科技、建造或造兵费用，也未生成真实成长路线。完整800条逐流结果、输入哈希、战前／战后存档哈希及敌军人数、生命、攻击质量在[P260原始数据](reports/data/p260-stage100-pressure.json)。其中单独40名星界兵加弓手在25／30／40倍候选均0/16胜，说明混编而非单一晚期兵种才提供上述效果。

电磁单前排在12倍就只赢6/16，反弱于装甲前排；`battleVitals()`把兵团生命纳入伤害结算，不能根据攻击面板或科技先后直接假定它更强。40倍条件混编虽15/16胜，胜流平均损114.33名（160名入场），补兵经济压力极高。P242档的现有科技仓上限约5001920，而星核研究要求科技点100000000、战备勋章800000；当前档的774勋章也不足。没有可支付的同源星核战前档，40倍候选可能使主线不可达；25倍又仍可由无星核实付混编16/16胜。因此**本批不修改正式第100关敌阵，也不加研究按钮硬锁**。下一步先完成星核知识容量、勋章与材料的实付来源和星界兵生产，用同源尚未通关100关的“未完成／已完成后期成长”两态，逐关核对第90–100关压力、首败补兵和恢复成本，再决定正式敌人数、生命与出手规模。区域线的材料经济仍需与主线军损联合验收。
