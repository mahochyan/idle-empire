# P170：第5关后T1兵线实付接力复查（2026-09-26）

## 问题与方法

P168／P169确认：继续等待或固定让10名T0步兵入场，均未稳定突破第7–10关。现有代码在第5关胜后允许步兵、弓兵营地升到T1，研究“民兵”和“游侠”。需要验证这条**现有**军备接力在当前首胜奖励版本是否真能付款、重训并进入下一场，而不能只根据静态配置说“已解锁”。

[P170探针](../../tools/verify/probe-t1-handoff-feasibility-p170.js)从P167同一真实新档路线的第5关首胜后即时保存点分出4支：粮／粮岗位、固定战斗种子1与42，各比较当前第3关+6拓居令和隔离VM无奖控制。重载该存档后，真实取消旧步兵／猎人待训队列，把2名石工改投木工，分别支付步兵和弓兵营地T1升阶、等待20秒完成，并核对旧兵返还日志各恰一次；再真实支付两条T1研究费、训练15民兵与13游侠，通过真实编队动作让刀盾兵、民兵和游侠参战。从第6关起按同一随机流逐关战斗；每胜之后补至持有10刀盾兵／15民兵／13游侠，等待600在线`tick()`秒，至第10关或首次失败。等待资源和训练各设1200秒上限；没有额外地契、资源注入、驻军或离线模拟，战斗回调墙钟时间不计入在线秒。

第5关检查点四支战功均14；双线T1研究各付200科技、5战功及木200／石100／粮150，研究后仍余4战功。营地升阶分别付木500／石300／粮200和木600／石300／粮200，真实完成时清退旧线拥有兵及未完成队列；旧兵退款日志按当时拥有量计算标称返材，步兵均15名，猎人5–13名。**实际入库受仓容截断**，探针只断言退款日志恰一次，后续动作均使用真实仓内余额付款，未把标称返材全额虚加进库存。新T1训练配置为每民兵木80／石40／粮60、每游侠木120／石40／粮50；四支均通过真实研究、扣费、训练、结算与存档重载，第6关分别2–3回合胜。

第6关虽然**拥有**15民兵，单团上限10、前排另一个格放刀盾兵，因此每支只让10民兵实际入场；5名留预备。此后种子1两支在满目标持有量、实际10刀盾／10民兵／13游侠入场时败于L7；种子42两支用同样满编入场胜L7、败于L8。种子1补L7民兵队列时曾因材料不足暂停62在线秒，战前已补齐；种子42后续队列未暂停。无奖支最低粮仅3.51–11.52，说明这条军备路线靠近断粮，奖励支的更多住房／粮工在这些样本里提供了更大的资源缓冲。

## 设计决定与边界

把“第5关后营地升阶→旧兵返材→研究→重训→编队”列为第一章现有的真实成长路径：它在这4条样本中可付款且第6关可用。但这不是第10关解决方案。P167刀盾优先旧兵路线在相同粮粮种子1／42当前有奖支的首败分别为L9／L8；P170改了岗位、军种、资源开支和第6关开战时点，不能把它的L7／L8直接解释成“T1兵比T0弱”的单变量结论。当前可确定的下一瓶颈是营帐单团容量／前排格对已训练民兵的入场限制，以及L7–L10连续战损和口粮承受能力；应优先检查合法扩团或另一现有阵位成长路径，再按同档付费比较敌压。不要因本样本而直接改人口倍率或统一削关。

本报告用当前代码里的“民兵／游侠”标识原有兵线。现行猎人／游侠还带“精灵”种族标签；这是玩家可见的早期西幻用词，后续名称与造型审查应明确它如何服务边境聚落主题，不能因沿用旧标签而跳过我方世界观设计。此批不新增玩法，不触碰正在并行美化的UI文件。
