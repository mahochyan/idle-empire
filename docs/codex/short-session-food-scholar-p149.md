# P149：四学者短时战役的首个离线粮食截断（2026-09-26）

## 方法与边界

P149沿用P145逐秒粮账探针，只把人口入口切换为真实`--research-priority --research-workers=4`零胜场新档路线；该路线通过真实`save()`导出后交给P102重载，继续使用当前生产、训练、战斗、奖励、队列和`settleOffline()`。在首个不完整离线窗捕获诊断后，探针对照P145顺序扩建路线的战役检查点与粮账；对照字段逐项相等断言通过。

这不是完整P112战役成功回放：短时profile仍会在首个截断处中止。固定随机值0.5，军备准备、编队及战役规则按P102既有路线；人口自然增员与离线仍调用真实函数。所有存档只在开发harness内读写。

## 设计含义

在“每600在线秒后离线8小时”的这一组新档路线里，4学者研究优先没有缓解第4关胜后的8小时供粮截断；两条路线进入该窗口时的可见经济、岗位与军队状态相同。该结果与P112先前的同档对照一致，但并不能证明连续在线科研冲刺无收益，也不能外推到其它在线/离线频率、库存或战损。P146/P147粮工调配结果只来自同一类战后检查点，正式岗位规则仍需比较机会成本和其它战役路线。
