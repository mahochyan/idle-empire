# 人口成长差距与时代命名收束（P103，2026-09-25）

- 对应权威设计：[《策划文档.md》D15、§8.4、§8.7、§8.9](../../策划文档.md)
- 范围：依据母本源码审计、当前工作区函数与P101/P102真实动作样本，收束人口调速方向和阶段命名；不改游戏代码、配置、奖励、存档或素材。

## 用户确认的主题边界

用户原话：“机器什么的还行，但是后面神神鬼鬼的西幻一些”。据此采用渐变，而不是全程机械或开局就神魔化：

| 阶段 | 玩家可见主题 | 名称示例（草案） |
|---|---|---|
| 聚落至黄金 | 聚落、工艺、城邦与工业 | 村庄、冶铜、铁匠、银库、王都 |
| 合金至蒸汽 | 机械制造、工造、工业遗址 | 合金军备、蒸汽工厂、蒸汽装甲；独立支线用“遗迹勘探—机巧遗迹—遗迹守卫—遗迹晶核” |
| 电力 | 能源科技为底，少量引入西幻挑战与圣物 | 镜影巫后／幽影花晶、圣盾巨像／守誓圣石、深渊君王／深渊核心；通用奖励可评估“圣战徽记” |
| 核能以后 | 科技军备与神祇、星界、异界意象逐步交汇 | 星界、神裔、圣物、位面、虚空等词根；逐角色结合职责和美术再定 |

这些是命名方向和候选，不是最终定名或美术批准。母本名称仅供依赖核对；内部ID、资源键、存档字段和玩法职责保持稳定。合金—蒸汽支线继续用我方已有的“机巧遗迹／遗迹晶核”机械工业命名，避免把“神之领域／神域水晶”变成早期玩家可见名。电力为过渡层，不要求每件物品都改成奇幻词；核能以后再明显增强西幻气质。

## 人口差距的诊断

**母本事实：**[时代映射审计](era-mapping-audit.md)记录了源函数：在线定时器每10秒尝试自然增员；粮食大于0且实际人口低于容量时，增加`2 + 5 × 已配置“育”政策位数`，受剩余容量截断。母本因此也把住房容量、地契扩建和粮食作为人口增长的必要条件。

**我方现状：**当前`config.js`将基础增员设为2人／10秒、“育”位另加5人／位／10秒；`math.js`同样检查粮食和空余容量，并由在线tick累计出生时间。当前新档为0/4人口容量、30地契和300粮食。出生基准与母本一致，不能仅凭“人数跟不上时代”就把基础速度上调。

**可复现路线：**P101真实函数VM的三条零普通关胜场路线均到达18/18：逐级扩建5096秒，批量扩建无“育”位6450秒，批量扩建并开“育”位6822秒；均为模拟在线秒。后两条相差372秒，但研究、交易与扩建顺序不完全相同，不能当作“生育政策导致变慢”的单变量结论。P102的+6地契战后敏感度只带来一次扩容和一名自然出生村民，在既测补兵窗口中没有改变第6关结果。

**设计判断：**现在最值得优先校准的是“扩容供给和岗位预算何时接上”，尤其是开局地契用尽后、冶铜研究与市场完工并能稳定购契之前的空窗；后续还要同时看食物、仓容和劳动力分配。增加基础出生率在住房已满时不会生效；只增加战后地契也不能解决零战斗路线、持续岗位或军队口粮问题。

**出生等待与住房等待要分开计时：**按当前基础`+2／10秒`，容量有空位且有粮时，新增1个岗位人口最多等一个10秒出生tick，新增4个容量通常在20秒内填满。住房已满时，不论把出生倍率提高多少，实际人口都不会增加。因此人口里程碑的总等待应拆成`扩容供给／费用 + 科技与建造门 + 有粮出生填充`；若前两项远长于最后一项，应调地契续供或门槛时点，而不是调出生率。

**当前工作区的无胜场开局续供路径：**初始30地契按村庄费用5／6／7／8可升至容量8、余4；下一次扩建需9。当前P101逐级扩建探针在t=500模拟在线秒建成市场，随后还要通过城镇化研究、生产与7次交易动作筹契；t=1851首次扩建小镇，容量8→10、人口仍为8，t=1861才填满。即市场建成到首次住房扩容相隔1351模拟在线秒，而扩容后的两名村民约10秒即可出生。这个当前样本支持“市场能在零胜场续供”，也显示实际长等待在研究／资源／购契节奏，不在出生tick。历史审计中出现的t=372来自另一版代码／路线，不能与当前P101路线拼作同版本曲线；当前证据以[P101路线报告](population-growth-design-p101.md)和[三路线快照](reports/data/p101-population-routes-0-18.json)为准。

## 建议采用的人口骨干

1. 保留自然出生硬保底：有粮、有住房、在线推进才增长；暂不改基础`+2／10秒`和已配置“育”位倍率。
2. 把容量续供作为主要调速旋钮：以“开局30地契→村庄容量8／余4→无胜场解锁基础市场→买到至少5地契补足下一次9地契扩建”为早期可达检查点，再按时代开放城镇与城市扩建；每个住房节点须对得上下一阶段实际岗位数和备用调岗空间。该检查点不等于时长目标。
3. “育”政策的开放时点要和第一次持续扩容一起评估。不要只看倍率；同时计算研究、配置成本和新增人口是否能早于市场或金属岗位门形成有效劳动力。
4. 首通奖励只做未来住房加速：在胜利后发放、不能直接生人，也不能回填当前战斗战力。P15按章给地契及第3关额外+6仍是未确认的敏感度候选。
5. 下一轮用同一新档、同一里程碑和同一单位比较零战斗经济、均衡战斗、科研优先、短时上线／离线四条路线。每个检查点记录在线秒、地契来源/支出、住房容量、实际人口、空闲工人、粮食净流、关键岗位净产、科技门、兵力与战损补回；先定岗位预算，再反推奖励和可接受等待。

## 验收边界

P101和P102是当前机制的真实函数样本，不是放置时代对照路线的同策略复现，也不是玩家平均时长。它们支持“基础出生公式先不动、优先找扩容和岗位断档”的设计方向，不足以定稿首通地契数量、每时代人口目标、离线出生规则或50小时完成度。母本与我方的全时代经济、军力、奖励及短时上线曲线仍待统一推演，原创玩法继续后置。
