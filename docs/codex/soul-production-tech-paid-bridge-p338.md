## 文档目标、代码现状、本次决定

文档目标是沿《放置时代》的发展与军力曲线，让独立区域副本承接材料成长，100关维持需全部科技的高难主线；早段机巧工业、后段西幻星界。P337从警戒7050／79石满编档实付4.8亿钢升星际先遣兵120攻击兵装星，最终拿到出战兵种首颗英魂星，但该段耗717636模拟在线秒，不能凭单一路线判断平衡。代码现状并非只有兵装这一项可投资：同一源档已有电力、星核时代研究，`electricProduction`与`nuclearProduction`均0级，知识205249904。母本生产科技460099／460084逐级提高非钱币岗位产出，我方`CFG.eraStorage`已接对应研究，前五级仅耗知识、第六级才加稀有材料；`prodRate()`对两项采用独立的`(1+0.1×等级)`乘区，`productionSecond()`仍逐秒支付加工原料。本批不改这些规则，真实购买并比较完整付费路线。
