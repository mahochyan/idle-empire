## 文档目标、代码现状、本次决定

《策划文档》要求：100关仍是全部核心科技后才能打完的高难主线，另一条区域/材料线尽量承接《放置时代》的发展与成长曲线；早期偏机巧，星核后逐渐转向西幻神祇。P274接入圣域异果与独立觉醒首阶，但只证明旧口径下的一次实付。复查发现两处会改变后续成长的偏差：它把全编队人数当试炼费用，并把简单／完美／极限难度直接倍乘守卫人数和攻防，守卫又遗漏母本单兵生命层。本批校正计费和守卫生成，保留已付款历史档，不修改100关、原创玩法或并行美术资产。

母本`210(1)_unpacked/_analysis/deob_main.js`的试炼入口在约2144529偏移处实际读取`playerData[0].Num`，计算`10×GodGameLv当前阶数＋首个出战兵团人数`；页面说明只写「上阵士兵数量」，P274把它解释为全编队总数，不符合真实代码。母本约1394101处`getMonsterDataGod_SS`先把**本次选择的难度轨虚拟加1**，然后分别算人数、单兵攻击/生命/防御：人数基础50＋30×当前总阶＋简单10×胜场＋完美20×胜场＋极限40×胜场，再乘370009的`ArmyGodPer=2.1`；攻/生/防各有不同的历史难度权重。540091–093三档守卫表的基础为人数50、单兵攻30、生200、防5，区别还包含各自特殊技能。

我方现按前/中/后排的第一个非空兵团计费；人数及攻生防使用上述母本分项公式。由于我方兵团伤害公式与母本不同，守卫总HP＝源人数×源单兵HP÷10、单兵攻击＝源攻击÷10取整、出手规模＝源人数，防御用源值。这些除数是**本地战斗口径适配**，不是母本原值；首阶简单守卫由旧版105HP/低出手规模变为126出手规模、5556HP、攻6、防10。完美、极限首阶分别为147/6791/6/11与189/9525/7/12（顺序：出手规模/总HP/攻击/防御）。守卫特殊技能和缄默之神的封印等技能仍未接入，不称完整复现母本。
