# P398｜四策略首败后，同档跨入铁器

日期：2026-09-30。起点 `master` / `4cab3d7c4579d8236835cc593188807663e8bef8`。本批只新增开发探针和结果，不修改游戏运行代码、UI 或存档结构。P397 的战役探针没有导出首败后终档，因此 P398 从各自真实新档重新执行相同人口、市场购契、首胜扩村、补兵、战斗、首败及一次败后重试动作，然后**在同一个运行中的存档上**延伸到铁器。不是把独立钢仓或量子路线拼接到四策略上。

四档的起点分别是本探针从真实初始状态重新生成并保存的 `p398-four-strategy-economic-pop18-save.json`、`p398-four-strategy-balanced-pop18-save.json`、`p398-four-strategy-military-pop18-save.json`、`p398-four-strategy-short-session-pop18-save.json`，均为 18 人口、0 主线胜场。它们不是从四份不同的时代终档拼出来的。探针继续调用实际 `researchScience`、`buildAct`、`train`、`tick`、`save`、短会话 `settleOffline` 和战斗结算。四路线的城镇化及冶铁术已在各自人口阶段实付，接续段逐一以知识 1000 研究铁仓库、知识 2500 研究铁器时代，支付木 600、石 600、粮 300 建铁匠铺，然后队列真实扣粮 500、铁 100，训练出首名铁器长枪兵。账本在研究前后记录知识余额；建造动作前后逐项核对木石粮扣费；训练队列先确认不预扣资源，再用只记录并转发原函数的包装器核对完工时恰好扣一次粮 500、铁 100。每个研究和首兵存档都再次读取；最终四份 `rts_save` 各自重载成功，均保持铁器科技、铁匠铺 Lv.1 和一名铁兵。固定战斗随机数为 0.5，开发 harness 冻结自然驻军，不能据此推断随机胜率。
