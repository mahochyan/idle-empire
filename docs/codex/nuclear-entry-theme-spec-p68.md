# P68 时代主题词表与核能入口规格（主题修订：2026-09-25）

策划目标是沿《放置时代》的发展、容量、军备和难度依赖制作我方游戏；玩家看见的是我方像素世界。用户最新澄清原话：“机器什么的还行，但是后面神神鬼鬼的西幻一些”。本规格把电力设为渐变起点：合金至蒸汽保持机巧、制造和工业遗迹；电力保留能源科技与军备底层，开始少量加入原创西幻挑战和材料；核能以后再逐步增强神祇、魔法、圣物、异界与星界意象。母本名称继续用于源实体对照，但玩家可见层不照搬“神之领域／神域水晶”等专名；最终词汇须与我方像素美术和角色职责匹配，不能只替换标签却略去费用、材料和战斗出口。本报告的前序运行记录描述旧名称、旧代码状态与核能入口条件，保留作为历史证据；本次仅修订主题命名规格，**没有改动玩家代码、数值或存档，也没有宣称核能自然可达**。

## 核能当前门槛与原始证据

母本解包实体表`210(1)_unpacked/_analysis/entities_table.json`直接核得：发展科技450023前置450022、单笔知识160003×100,000,000与勋章160010×800,000；宇航兵370009以450023为门，招募铜150006／铁150007／钢150010各8,000，`Interval=8,000ms`；核能容量/产量科技460081～084均以450023为门。母本450023的`Unlocked`写自身，不是“研究后没有功能”；兵种限制另在370009。母本数据是机制与成本锚点，尚未证明我方军团属性、岗位净产、角色像素造型或实际训练时长可原样照抄。

我方当前玩家代码只到`sci_electric_age`；没有`sci_nuclear_age`、宇航兵训练口及核能科技。真实v29验证档`docs/codex/reports/data/p67-electric12-armor3-paid.json`独立`loadSaveAndApply()`为`ok`，第45关，公共储存精通100、蒸汽知识8、电力知识12、图书馆603、研究院300、机巧拓仓图纸已用68。调用现行`resCap('tech')`得25,144,922；勋章库存803,404，守御之石197。核能知识仓容差74,855,078；电力知识13级单笔需知识26,000,000和守御之石260，当前容量差855,078、石差63。守御之神警戒值3500在该档实付电磁甲3级阵容下仍战败，不能预支下一级材料。

当前知识容量由`expandedResCap('tech')`、学院/图书馆/研究院级数、公共储存精通、蒸汽与电力知识倍率、图纸使用数共同决定。条件副本直接调用真实容量函数，所得只是**构型目标，不是实付路线**：

## 下一段实施门与验收

1. **先取得下一笔实际付款空间与材料。** 从P67同一档选择可支付的图书馆、研究院或图纸扩容，至少使仓容到26,000,000；按实际兵力、装备、站位、训练成本和战损打通守御3500或找到已存在且来源可靠的守御石路径，使库存到260。容量与石必须同档满足，随后真实调用`upgradeEraStorage('electricKnowledge')`并重载验证13级。不能给测试档直接填石或等级后称“已达”。
2. **把1亿容量拆成连续的可付节点。** 每一级电力知识先核本级知识单笔、材料、当前容量，再付费升级；并行比较建仓与图纸路径的在线秒、主动战斗、刷新和建造次数。任何高等级材料路线都必须在所需警戒值下真实战胜并可持续补兵，不能只用奖励公式累计。
3. **同一存档验收核能入口。** 达到`resCap('tech')≥100,000,000`，实际攒满知识1亿且仍有勋章80万，同时保留前置电力研究；随后才接核能科技配置与对应角色/训练设施，测试“知识来源→前置→一次扣费→解锁设施→三金属训练→队列结算→远征/驻军”。后续核能科技460081～084不得反过来用于跨越核能研究本身的容量墙。
4. **再校准节奏。** P67单一路线从P66档新增1,901,696模拟在线秒（约528.25小时），仅蛮牛100战补勋章用了977,287秒，尚未算真人点击、动画与离线。因此必须同时报告在线等待、主动操作和自然日，不把“内容至少50小时”误读成允许任何高倍等待。保留早期人口经济增长独立于打关；关卡胜利可加速，不充当唯一村民来源。
