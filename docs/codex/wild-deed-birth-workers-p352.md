## 同源动作与可比边界

从[P342已付费存档](reports/data/p342-hide-paid-seed1-save.json)和[P329的626人目标阵容](reports/data/p329-soul-refreshed-save.json)出发，按[P349](wild-offline-queue-p349.md)原动作重演首战及首个四小时窗口：首战前在线实付补兵1,609秒，打败铁脊蜥龙，损379兵；战后实排379兵，以粮食100、钢料902岗位调用真实`save() → loadSaveAndApply() → settleOffline()`。首窗只产56兵，323未产订单用`dismissN()`取消；主档SHA与[P349三战数据](reports/data/p349-wild-offline-queue-3battle.json)的对应窗口完全相同。此时边贸离线被动奖励真实到账兽骨30,240、勋章7,560、地契4,536，人口仍为1,002。

随后用玩家动作`researchScience('sci_birth_policy')`支付1,000科技点。探针读取游戏`settlementCostAt()`逐级价格，在4,536地契内枚举村庄、小镇、城市增量，按**先最大化容量、再最小化费用**选择：村庄+54级花1,917契，小镇+33级花2,573契，城市不扩，共花4,490契，人口上限1,002→1,122，余46契。实际分别调用`settlementBatchPreview()`和`upgradeSettlementBatch()`，没有直接写资源或人口。该预算下再多1容量不可付，同为+120容量的更贵组合不作为最终候选。

政策对照只配置原有小镇5级已经提供的政策位：一组调用`setSmallTownPolicy(0,'birth')`一次，另一组依次调用0～4号位五次，每次真实保存。然后在线逐秒`tick()`至人口自然增到1,122；一育为每10秒7人，耗180秒，五育为每10秒27人，耗50秒。新增120人真实分配到铜工并在线工作10秒，铜库存增2,970；此10秒计入活跃时间。两组都按P349在线生产、付款训练、编队至626人打第二战，随后实排第二战损兵，进入第二个四小时离线窗口。科技、扩建、政策和岗位点击本身依当前游戏规则即时完成；出生、采集、补兵和离线均计秒，战斗动画时间按零处理。

第二战在三组P352候选及P349中都是败，损626、警戒值3,930、战后随机流`58098231`，队列组成均为星际先遣155、蒸汽装甲55、电磁101、合金特种55、黄金骑兵40、弓兵220，共626。探针直接断言与P349第二战胜负、战后兵力、警戒、随机流和队列逐项一致，因此第二窗产兵有相同的分母；后续离线货位随机数仍可能因在线时序分叉，不外推到第三战。第二窗岗位一次设定后四小时内不自动换岗。`五育·空置120人`从五育同一第二战后存档起，仅将第二窗岗位从全员1,122人的`粮100／铜330／铁330／钢302／金60`改成`粮100／铜300／铁300／钢302`共1,002人；两份[全员夹具](reports/data/p352-birth-deed-five-policy-optimal-two-window-second-logout-save.json)和[空置夹具](reports/data/p352-birth-deed-five-policy-optimal-base-workers-two-window-second-logout-save.json)都是可重载v32主档，除`popAlloc`外字节字段完全相同。

一育→五育把出生等待减少130秒，但第二战前资源与训练修复多耗113秒，所以总活跃只缩短17秒；**不能只把出生节约当作上线收益**。五育两份第二次下线夹具相同，仅岗位不同，故这120名新增工人在本固定岗位方案中使第二窗多产**37兵**（382对345）。细分为黄金骑兵多产38、电磁兵少产1；新增工位分布为铜+30、铁+30、金+60。P349的277到五育全员的382，差105包含原有1,002人从纯钢岗位转为铜／铁／钢岗位、首窗后在线供料与扩容出生等变化；不可把105全归因新增人口。P350同档首窗全预存方案可产379，但需下线前实付准备2,751秒；它与本批第二窗入口不同，不能用单列产兵数评判优劣。

五育全员工位到窗末煤只剩16.30，铜6,298.55；电磁兵及星际先遣兵下一人各需铜8,000，因此待产的电磁89／星际155共244人因铜不足直接暂停。煤几乎耗尽又使铜、铁、钢的后续加工难以持续。空置120工对照还剩黄金骑兵38，因为没有金工。首窗地契已实付扩容，第二窗地契4,536再次入账，余量从46增至4,582；人口容量1,122尚未跨到2,000，故第二窗被动倍率仍是1.05，奖励仍为30,240骨／7,560勋章／4,536地契。新增人口也增加口粮负担；三组全程食物最低采样为398,125.98，未触发断粮截断。
