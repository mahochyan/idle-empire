# 电力前金属仓容路线对照（P39，2026-09-24）

> 历史口径：本表运行于P40仓库分段费用修正之前，不能当作当前版本时长。现行费用的两路重测见[仓库分段费用复核](repertory-cost-curve.md)；铁仓600／900级在新费用下尚未重测。

目标是复核当前机械阶段的钢仓容墙。四条路线都从真实新档出发，固定既有战斗随机脚本，合金阶段逐笔购买冶钢精通前五级，最终达到102人口、零普通关卡胜利、储存精通100级、蒸汽科研6级／金属5级，实际支付电力时代研究费并训练首名电磁兵。`probe-electric-era.js`只增加开发侧参数`--iron-store=N`；参数在蒸汽金属仓5级及知识容量500万后，先把铁仓逐级升到N，再沿原路径把钢容量升到100万。所有建造、生产、研究、招募都调用现有动作；没有注入资源、人口、建筑、科技、兵力或胜利。

内部时间单位为在线tick秒，小时只做展示换算。四条路线在同一个第1851018秒达到知识容量5001920。钢容量达到100万的时点分别为2410654、2221677、2193076、2363731秒。铁仓每级给钢容量50、钢仓每级给钢容量100，再受储存精通及蒸汽金属仓乘区放大；铁仓不能只按仓库面板的“铁容量+200”理解。300级是这组样本中操作增量相对节时最有利的一条，600级在线时间最短，900级则在在线时间和建造次数上都劣于600级。这里的“最短”仅指四条固定路线，不是全策略最优值；不同交错建造、岗位安排或离线推进未比较。建造次数也只统计本探针新增阶段，不包含前段动作、岗位切换、真实点击和建筑动画时间。

母本解包表存在金属容量产业`320003`，但它的上级`320000`要求星域材料`170021/170022/170023`，目前看到的发展研究`450123`依赖核能`450023`。这些静态数据不足以证明电力前能获得该乘区，因此本次没有移植成免费的前期容量增益。下一项设计工作应核对母本实际前置／材料来源与我方可达链，再决定是引入有付费门槛的机械期容量层、调整建筑分段成本，还是改善逐级建造交互；三者都要重新跑新档时间、操作量、存档和战斗验收。当前约628小时的单路径仍远超50小时量级，不能宣称成长／难度曲线已校准。后期可见名延续用户确定的神魔西幻阶段；本阶段维持铁仓、钢仓库、冶钢精通的机械词汇，不把星域材料命名直接搬进前期界面。
