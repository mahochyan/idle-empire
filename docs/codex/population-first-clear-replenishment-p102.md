# 首通扩容到真实补兵的短窗对照（P102，2026-09-25）

- 对应权威设计：[《策划文档.md》§8.4、§8.9](../../策划文档.md)
- 输入：当前工作区真实零胜场18人口经济路由、青铜军备准备档、普通首胜奖励P15候选。
- 范围：检验第3关战后+6地契敏感度能否经扩容、自然出生、岗位生产和实际训练改变第6关结果；不批准候选数值，不改游戏运行代码、配置、奖励、玩家存档或美术。所有奖励与动作只写入隔离VM的内存`localStorage`。
- 复跑：[P102探针](../../tools/verify/probe-population-first-clear-replenish-p102.js)；[逐关原始数据](reports/data/p102-population-first-clear-replenishment.json)。

## 对照条件

从同一条零普通关胜场的新档路线取得18人口／18容量，在模拟在线tick 5,555时完成相同军备准备：15名基础步兵、13名猎人、8名青铜刀盾兵。三条分支均固定战斗随机值0.5；对照普通首胜候选与第3关胜后额外+6地契。候选只在第3关战斗结算后到账；它与当关胜负无因果倒置。真实聚落动作支付9地契，把容量18升到19；再推进10秒，出生第19名村民。

**奖励口径补充（P155，2026-09-26）**：P102探针的“普通首胜候选”不是当前线上奖励。真实`clearReward()`在每个胜利关卡后向隔离存档增加`ceil(关卡ID/10)`张地契；所有分支都注入这笔基础候选，`frontloaded-*`分支再在第3关胜利后额外增加6张。当前`levels.js`的关卡奖励配置不含地契字段。因此本报告所有结果属于测试候选奖励模型下的敏感性回放，不证明现行奖励、关卡首通行为或线上人口曲线；真实无地契奖励注入的关卡战斗对照另见[P139](live-deed-baseline-p139.md)。

胜过第3、4、5关后，三支都按同一实际动作把基础步兵补到15、猎人补到13、青铜刀盾兵目标补到15。三个间隔各保留原有10秒在线推进，并额外测试每段0、60、180、600秒；第6关入口分别在起点后50、230、590、1,850模拟在线秒。资源生产、口粮、训练队列扣款、编队和战斗均调用当前真实函数。

额外人口用两种岗位政策测试：

- **稳粮**：从18人岗位组合增配一名粮工，最终为石6、粮4、煤6、铜3；实测粮产率13.05／秒，金属配方不变。
- **青铜补训倾斜**：把岗位调整为石5、粮2、煤8、铜4；铜产率从原岗位组合的3提高到4／秒，但粮产率降为6.525／秒。它把生产预算投向青铜兵所需金属，并牺牲粮食产能。

## 结果

| 每次战后额外等待 | 普通首胜候选 | +6稳粮分支 | +6青铜补训倾斜分支 |
|---:|---|---|---|
| 0秒 | 5胜，第6关败；入场30人，含2青铜刀盾兵 | 相同：5胜，第6关败；30人、2青铜刀盾兵 | 相同：5胜，第6关败；30人、2青铜刀盾兵 |
| 60秒 | 6胜；入场35人，含7青铜刀盾兵 | 相同：6胜；35人、7青铜刀盾兵 | 相同：6胜；35人、7青铜刀盾兵 |
| 180秒 | 6胜；入场43人，含15青铜刀盾兵 | 相同：6胜；43人、15青铜刀盾兵 | 6胜；入场37人，含9青铜刀盾兵 |
| 600秒 | 6胜；入场43人，含15青铜刀盾兵 | 相同：6胜；43人、15青铜刀盾兵 | 6胜；43人、15青铜刀盾兵 |

三种分支第6关均为第4回合结束。+6没有在已测试窗口改变第6关胜负；稳粮路线的入场兵力与普通候选相同。60秒／胜时普通候选本身也已从原固定招募样本的第6关失败转为通过，因此这个结果验证的是双方都能借补训等待跨过当前样本门槛，不是额外人口使奖励分支提前过关。180秒的青铜倾斜路线在铜仓已达800、但粮食仅285.6时仍有6名青铜兵因资源不足停在训练队列（单名耗粮300），入场少6名青铜兵；这说明单加金属岗位会把瓶颈转到食物。到600秒窗口后，同一分支也补到15名青铜兵。

## 设计结论与边界

1. **+6地契只买到一次住房容量，不等于+6人口或战斗力。**本样本真实结果是容量／人口+1；后续是否形成军力，取决于训练费用、可用岗位、仓储与额外等待。
2. **不能把人口数单独当作发展速度。**必须同时验收新人口投入岗位后的净产出、军粮和可招兵数。P102金属倾斜分支产铜更快，却在180秒每段的设置下少带6名青铜兵；稳粮分支避免了这个转移瓶颈，但没有改变第6关门槛。
3. **当前证据不支持把第3关+6作为补足《放置时代》人口曲线的解法。**它可以保留为战后扩容敏感度，但奖励数量和发放时点仍未确认。主成长仍应由自然出生、无胜场市场续供与按岗位预算扩容承接；何处需要提速，要由同档多策略里程碑曲线决定，不能从此单兵种小样本定案。
4. **样本限制**：18人口、一个真实军备路线、固定随机值0.5，只推进至第6关；短窗每次胜利等待相同，不代表玩家平均离线/上线节奏。它不是奖励公式、多策略成长、50小时目标、完整战损恢复或放置时代全曲线的验收。

P102把P101留下的“新增劳动力延时生产和补训未测”补成一组可复跑短窗对照，但整体曲线仍未校准。下一步应让自然增员与市场扩容、重点岗位预算、仓容和军队补给出现在同一批零战斗／均衡／科研／短时上线路线中；保持原创玩法后置。主题名称继续依用户确认从前中段机械工业逐步转向后段西幻意象。
