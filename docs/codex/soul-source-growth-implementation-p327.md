# P327 英魂警戒指数成长接线与首星实付复核（2026-09-28）

## 文档目标、代码现状、本批决定

玩家确定100关是直到全科技后才能打完的高难主线，另一套区域材料副本按《放置时代》承担发展成长。P325已接九个独立可选英魂位，P326又验证了当前线性警戒与母本每满1000警戒的指数成长差异；直接套指数的开发侧敏感度让警戒5000精英英魂的128个固定流胜场由124降到12，并使未补兵的首星前选定连续流停在99石。本批先用真实生产和训练证明该倍率下仍有一条可付首星路线，再把源倍率接入**英魂战专用**配置／遭遇计算，不改100关、其他神域、驻军、CSS或美术。这里对齐的是母本生命1.4、攻防1.2、人数1.3的**相对增长形状**；母本怪物与我方单体兵团不是同一战斗量纲，不能宣称战斗等值。

`CFG.soulRealm.growth`现显式记录每1000警戒生命×1.4、攻击／防御×1.2、人数×1.3。一个选中英魂仍是我方战斗系统的一支单体兵团：生命总量承接源生命×人数，`attackMass`承接源人数，攻防分别承接源对应倍率。警戒按整千跳阶，未满1000不提前强化；奖励和每位警戒增量仍取既有逐位源值。极大合法警戒使用有限、安全的战斗参数上界，**不裁剪存档中的警戒进度**。源表最后一档截至100万警戒；本地超过后仍生成神话英魂，避免旧进度无可挑战目标。这是明确的本地延续规则，不冒充母本原始区间。
