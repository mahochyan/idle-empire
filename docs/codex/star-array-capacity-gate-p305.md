# P305｜核源星阵不能直接跨越量子知识仓门

日期：2026-09-28。文档目标仍是以《放置时代》的经济、成长与难度骨干承接本项目主题；100关是完成核心科技和成熟军力后的高难主线，发展副本提供材料和长期成长。P304已经实付电力科研16→17级，却仍未达到量子时代30亿知识单笔研究的仓容。本批核对母本星阵是否能成为当前阶段的容量捷径，并在同一实付档计算星阵研究的前置仓容费用。只增开发侧探针、数据和文档，不改运行代码、数值、存档或并行UI美术。

## 母本事实与当前状态

母本 `450123`「星域异兽」从核能时代后研究，单笔知识2亿、勋章100万；`450223`「核源星阵」紧接其后，单笔知识3亿、勋章200万。源 `320004` 确实是「知识上限」属性，容量函数把所有已开放、对应属性的星阵槽位值汇总后再乘入知识仓。槽位基础值为每级4%，索引每跨3位另加每级2%，实际值还受变异和兵种觉醒倍率影响。这证明星阵是母本后期容量路线，**但并非研究按钮一按就有倍率**。

源码 `superArmyPer` 对每个兵种独立检查觉醒数据：只有到20阶且至少50星，星阵属性才得到首档0.6倍；100/150/200/250/300星分别升至0.8/1/1.2/1.4/1.6倍。20阶以前或不足50星，已开放槽位汇总仍乘0。母本还要通过星域异兽取得星源石、星变石、星核石，槽位升级/刷新/开放分别消耗它们；只加研究与倍率、不给材料战和逐笔支付会形成免费成长。源 `530001` 一星异兽胜利静态奖励三种石各10只是配置基数，实际战斗和警戒收益尚未在我方验证。

[P304可重载实付终档](reports/data/p304-electric-knowledge17-guardian-paid-save.json)原文 SHA-256 `596abcd27b71e8c90f1bac53b9fe5bca1b7a1b30f4c9c085d7b69fe3562eda99`。当前我方知识仓166,765,547，知识3,652、勋章9,324、拓仓图纸已用92张，蒸汽/电力/星核科研16/17/6级；星际先遣兵觉醒6阶7星。母本星阵首档生效条件与该实付成长相差14阶、至少43星。即使未来实现同类星阵，当前档也不能靠它先付2亿研究，更不能把尚未实付的倍率写入P304的30亿容量下界。

## 当前规则下的前置仓容费用

探针固定上述档的图书馆、研究院、储存精通和92张图纸，只搜索现有三项知识仓科技至100级，以真实 `resCap('tech')` 取容量、逐级 `eraStorageCost` 复核费用。按**总知识费最低**排序的条件组合如下；材料仍须另从战斗获得，未付款，不代表最短时间或最省战损。

**本次决定：**修正P304“优先看星阵容量乘区”的含义：星阵可列为后期成长内容，但不能作为6阶7星实付档解决量子仓门的近程方案。下一张实施任务应先沿现有机巧遗迹材料回流，把蒸汽科研16→22级的1,116晶核缺口、逐级知识生产和战损放进同一有价账；同时独立核100万至300万勋章的实际来源与等待。待星域研究、材料战和20阶觉醒路线可付，再设计我方机械—西幻主题的星阵实现，不以免费属性或直接削费绕开依赖。完整量子研究、军种/武器/区域、7–20阶、90–100关终局和50小时多策略仍未验收，原创玩法继续后置。
