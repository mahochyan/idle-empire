# P75 双电磁兵团打通守御4000／4100并实付电力科研15级

## 结论

承接 P74 的第45关、126人口、470人、守御警戒值4000的真实v29开发档，当前代码已有一个**可付款**的战力出口：电磁兵坊逐级升至32级，真实生产并支付铜／铁／钢各36万招募45名电磁兵。按双电磁兵团＋合金兵＋装甲兵四前排，保持Boss、装备、伤害公式与30回合上限不变，守御4000固定种子1～12均胜。首胜损63人，直接以残兵续打4100固定12种子全败；真实补齐63人后4100固定12种子9胜。两次守御胜利使石102→313，再以学者岗位实际生产并一次支付科技点3000万、石300，电力科研14→15级。

这闭合了当前一笔材料／知识双门，不代表母本完整难度曲线、核能时代或50小时目标已完成。全链从P74四后排猎人档的第7,572,237模拟在线秒到第7,728,006秒新增155,769秒，约43.27模拟在线小时；从P73粮工档第7,557,061秒算新增170,945秒，约47.48小时。两者均不含真人操作、战斗动画及更早的第45关／80万勋章路线。不能把这段高频开发回放当作玩家完成时间。

## 文档目标、代码现状与本次决定

- **文档目标**：借鉴母本时代／军备／成长难度骨架，保留我方像素外观。基础人口由经济／聚落扩容持续供给，战斗是材料与加速入口；每道材料墙后要有可付款的成长出口。早中段营帐、电磁兵坊与兵装保持聚落／机巧工业词；电力后材料挑战继续叫「守御之神／守御之石」，符合已定的后段西幻命名，不把母本早段「神之领域」搬回当前界面。
- **代码现状**：双电磁团在我方`DAMAGE_COEF`、比例防御、30回合与兵坊容量下可赢4000；必须同时承担15级兵坊、逐人三金属招募、战损补兵及大量军粮。母本兵370008招募也耗铜／铁／钢各8000，但我方兵坊费用、统一训练节奏和兵团战斗仍是本地适配，不能因此宣称数值曲线已经吻合。母本核能门要求单笔知识1亿与勋章80万；最终档勋章804284够库存门，知识仓40,582,080仍差59,417,920，且我方尚未接核能研究入口。下一笔电力科研16级又需科技点3200万、石320；当前石13。
- **本次决定**：保留Boss倍率、30回合、原军备参数与v29字段；将双电磁实付路线记为当前可达出口，同时把其极高的在线时长与岗位互斥记作后期曲线待校准问题。后续先核母本知识仓／人口／军备的同源增益与容量上界，再决定玩家代码的最小调整；不把本次开发回放当作50小时验收，也不提前添加原创玩法。
