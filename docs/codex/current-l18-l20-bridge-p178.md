# P178：第17关实胜后的第二章补兵与关底触达（2026-09-26）

## 起点与方法

[探针](../../tools/verify/probe-current-l18-l20-bridge-p178.js)从P175四支原兵线实胜第17关的同源路线重建其序列化终档：固定随机流1／42，各含当前第3关首胜`+6拓居令`分支及隔离VM内关闭此奖的对照。每份第17关战后档均与[P175原始记录](reports/data/p175-current-l17-cavalry-bridge.json)的经济、人口、兵池、队列、战绩和战斗结果逐项一致。保存JSON内有`Date.now()`时间戳，因而跨次重跑的原始存档SHA不会相同；本批记录本次SHA，不把它与P175旧时间戳SHA硬比。

从各自第17关获胜档独立重载后，依次以真实`train()`、逐秒`tick()`、编队动作、`openBattle()`异步回调、结算和保存重载尝试第18～20关。每场前将原有青铜刀盾兵／民兵／游侠补至15／15／13，共43名实兵入场；最多等待7200模拟在线秒。随机流仍按P175的种子和关卡固定。没有注入资源、科技或兵力，没有使用市场、离线结算或驻军，也没有修改玩家代码、关卡或UI。
