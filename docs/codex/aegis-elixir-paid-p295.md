# P295 圣盾秘剂：复合永久成长与实胜使用

## 文档目标、代码现状、本次决定

《策划文档》要求拓境／圣域材料副本承接母本长期成长，100 关仍是全部科技后的陡峭主线；原创新玩法后置。P294 已接入攻击道具「炽翼战剂」，防御道具及其兑换链还未承接。本批只补这条成长链，按本项目后期西幻主题命名为**「圣盾秘剂」**，不改并行进行的 UI 美术、100 关难度、敌人属性或现有警戒台阶。

工作区母本解包表 `210(1)_unpacked/_analysis/entities_table.json` 中 `180003` 玄武清虚丹每份给指定兵种基础 DEF +1、基础 ATK 与 HP 各 +5%，基础上限 30 份。`380029` 是权重 10、每 3 份 `180002` 换 1 份 `180003`。`deob_main.js` 的 `winGodWar` 稀有掉落分档为胜后警戒不超过 2000 时 50/10000，2001–4000 为 100/10000，4001–6000 为 150/10000，6001 起为 200/10000。本批把这些值映射到六条已开放的神域材料战；攻击与防御数值由远征／驻军共用函数计算，生命只加在我方战斗临时单兵生命上，不生成额外士兵。由于本项目生命也参与伤害，这一成长的实战收益需按本项目公式再校准，不能直接套用母本胜率。

`config.js` 配置道具、市场货品和掉落档；`math.js` 接入库存、每兵种使用次数、市场购买、实扣使用、胜利后的独立稀有判定及结算回滚；`ui.js` 仅在既有圣域货架和圣兽血脉卡增加必要按钮、库存、次数和奖励预览。市场仍每 1200 秒抽 10 格、总权重 2625，新货权重 10 占原先未实现商品的空位。按钮禁用仅为提示，交易和使用动作另做参数、库存、拥有兵种、战斗中、上限与存档保护检查。
