# 人口策略的短时回访间隔对照（P113，2026-09-25）

- 对应权威设计：[《策划文档.md》§8.4、§8.9](../../策划文档.md)
- 探针：[人口短时回访间隔P113](../../tools/verify/probe-population-session-cadence-p113.js)，使用真实P101零胜场新档路线和`save()`／`settleOffline()`。
- 原始结果：[四档在线／离线矩阵](reports/data/p113-population-session-cadence.json)。
- 存档范围：每条路线均从隔离新档开始；没有读取或写入玩家浏览器`rts_save`。

## 对照方法

按顺序扩建与市场后4名学者科研优先两种路线，均使用每600在线秒存档并离线结算一次；离线时长分别为600、1800、3600、28800秒。记录实际在线秒、结算离线秒、共同人口检查点的时间/人口/容量/库存和岗位操作。人口路线关闭普通战斗与随机驻军，所有建造、研究、交易、岗位分配走P101真实函数。探针只对照人口阶段，不将计划资源注入路线。

| 1800秒（30分钟） | 3973在线＋10800离线秒 | 3973在线＋10800离线秒 | 24/28 | 四个早期研究/扩建检查点的科技库存不同，检查点时间相同，随后合流。 |
| 3600秒（1小时） | 3968在线＋21600离线秒 | 3968在线＋21600离线秒 | 28/28 | 人口、容量、时间和库存里程碑逐项相同。 |

两条路线都达到18/18容量，且四档都比顺序扩建多6次岗位分配。10分钟离线档的科研路线另多2次交易；其余三档交易次数相同。122秒只计模拟在线推进，不计玩家实际操作、读屏或点按时间，因此不能直接等同玩家省下的时长。30分钟档两路到18人的时间已相同；较长离线样本中，两路的仓容和库存状态最终逐检查点一致。

## 设计含义与边界

1. 科研优先只在本次最高频的600秒在线／600秒离线安排里提前人口；提前量为122模拟在线秒，且伴随更多岗位分配与交易动作。它不是基础出生率的替代，也不足以单独解决整体成长落后。
2. 1800秒及更长离线档未显示18人口时间收益；3600秒和28800秒下全部28个共同检查点完全相同。这支持“长离线与既有库存上限抹平早期岗位先后差异”的解释，但没有单独证明仓容封顶是唯一原因。
3. 这些是固定脚本路线、早期18人口目标和四种离线间隔，不含玩家操作耗时、战役奖励、战损、驻军或中后期资源链；不能外推为真实玩家收益、最优策略或50小时曲线验收。
4. 本批只新增开发探针、原始数据、报告和策划记录；不改玩家运行代码、配置、奖励、美术或存档结构。
