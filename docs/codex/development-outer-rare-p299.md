# P299：外域稀有血剂与战剂来源

日期：2026-09-28。文档目标是让「拓境远征」承接《放置时代》式发展与长期材料成长；代码现状是四档外域只发地契／战备勋章，缺少母本 `itemPill` 来源。本批决定补外域胜利的低概率永久道具，不改主线100关、外域敌阵、市场价格、兵种效果或并行美术。

母本静态表 `210(1)_unpacked/_analysis/entities_table.json`：`180001` 麟血道具路径含外域，`180002` 攻击道具路径含外域；外域 `570001`～`570004` 对应村、镇、城、王都。可执行依据为 `deob_main.js` 字符位1536676起 `winBigWar`：尾号1／2／3的血剂概率为 `floor(10×战前收益系数)/10000`；尾号4的血剂概率封顶 `1000/10000`，攻击药概率封顶 `100/10000`。王都攻击药源码中判定上限前有一个 `5×系数` 的条件表达式，实际未触顶时赋值为 `50×系数`；我方战前警戒最高13000，故直接取 `min(100,floor(50×系数))` 与该区间执行结果一致。两种道具分别抽签。`180003` 静态路径也写外域，但本批审查的 `winBigWar` 没有实发分支，不能据路径文字直接添加。

本项目适配：继续使用已有**各区域独立**警戒，每胜+20、战斗计算封顶13000；母本同势力层级共享杀戮值，因此这不是原样复制。稀有概率读取开战时警戒，系数在1000以下为 `1+K×40/5000`，之后为 `9+(K−1000)×40/20000`。不乘胜后阶位或尚未建立的全局奖励加成，命中数量固定1；库存仍按现有道具上限入库，历史超限值不裁剪。状态已有 `sacredBlood`／`emberElixir`，没有新增存档字段或迁移。

推演口径：假设连续**已经获胜**50场、每场警戒从0依次增加20、独立抽签且未触库存上限，调用当前 `materialDomainEncounter()` 实现逐场算得：村寨血剂期望0.244份、至少一次命中21.71%；王都血剂期望1.2295份、至少一次71.30%；王都战剂期望0.4817份、至少一次38.37%。这是给定50胜的概率，不含战损、补兵时间、失败或现实玩家时长，不能当可持续收入证明；王都连续50胜的军力成本尤其未验。

实现改动：`config.js` 保存源基础概率和上限；`math.js` 在外域遭遇快照上算战前概率，实际胜利结算时独立抽签、实入、显示并与地契／警戒／战损同场保存，写盘失败仍走既有整场回滚；`ui.js` 拓境卡以我方主题名显示概率。没有修改 CSS、图片、`index.html` 或驻军战斗路径（外域只属于远征）。
