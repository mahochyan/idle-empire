# P398 双线军力成长桥：区域研究资源与兵营进度门

基线：`4cab3d7c4579d8236835cc593188807663e8bef8`。100 关仍是难度陡峭的主线，拓境区域仍按现有科技与警戒值承担发展线。P397 只把训练建筑升阶和兵种研究的关卡门改为「主线胜场或对应区域首胜」；当前 `buildAct`、训练锁、根兵种与分支研究仍查 Boss 次数，而区域胜场不给 `S.merit` / `S.essence`。因此无主线 Boss 的区域路线即使打赢，也不能完整研究、训练 T1–T3 旧兵线。

本批只复用已有存档字段和动作。骑兵训练场沿用 1 个 Boss 门，另接受边疆铜脉哨站首胜；法师塔沿用 4 个 Boss 门，另接受外域工造军镇首胜。旧 Boss 路径、建造/研究/训练费用、科技前置和兵营 tier 均保留。建筑、研究、训练、兵谱和建筑卡必须调用同一门槛判断；历史已建/已研究者不反向剥夺。

区域胜利同场给现有战功与精魄，败北、逃跑、重复结算不给。奖励不写 `S.defeated`，不新增字段或存档版本。所有收益通过既有 `endBattle` 的一次 `save()` 提交；失败时连同区域胜次、原有奖励和兵力结算回滚。

村寨的同类精魄第 2 个分别在第 4/5/6 次胜利、第 5 个分别在第 13/14/15 次胜利。军镇远程精魄同样分别在第 4/5/6 与第 13/14/15 次；疾风、铁壁分别在第 3/4 与第 9/10 次。主线 L10 盾/矛/剑每次各以 50% 概率掉 1，L20 远程三类各以 55% 掉 1、疾风/铁壁各保底 2；区域确定性循环以更多次胜利换取研究材料，避免重复刷区域比主线 Boss 更快。T1 步兵研究需 5 战功，铜脉单独需 3 胜；骑兵根需 8 战功，铜脉单独需 4 胜；若先研究步兵再骑兵，两项共需 13 战功，铜脉单独需 7 胜，科技/木/石/粮以及建设、晋升费用另计。

精魄是我方原有兵种研究资源；参考游戏的对应外域奖励目前仅有地契、勋章和稀有材料。本表是让本项目两条副本路线衔接的数值适配，不声称为参考游戏原始掉落。开发侧仍需用真实出战、战损与资源补给验证重复区域战的可持续性，不能仅凭本表宣称自然新档能完成全部旧兵线。

验收：未胜仍锁、区域结算后真实建造/升阶/研究/训练、主线旧档不回归、战功和八类精魄次数精确、重复/败北/敌人尚存时伪造胜利不发奖、`save()` 写入失败整场回滚、重载保留且没有虚构主线胜场。当前隔离事务测试通过把敌方 `alive=false` 构造胜利终局，再调用实际 `endBattle` / `save` 路径；它验证结算与研究动作，不证明这些区域可由自然新档战胜。自然可胜性需使用既有可达档完整运行战斗另验。UI 冒烟检查建筑与兵谱门槛显示一致；Android WebView 另记未验证。

## 本次实施与核验

`config.js` 为六个既有区域配置战功、仅村寨/军镇配置按原胜次循环的精魄，并给骑兵训练场/法师塔标注对应拓境首胜门。`math.js` 的共用建筑进度判断供建造、训练与 UI 调用；区域战胜分支将战功/精魄放进原有 `endBattle` 一次保存与失败回滚。`technology.js` 的兵种研究动作复用同一判断。`ui.js` 的建筑卡、军事建造列表、兵营和兵谱共用门槛，并准确显示新奖励来源。没有新增存档字段；本批开始时共享工作区已由另一并行切片升至 v33，本批只使用原有 `S.merit` 与 `S.essence`，旧库存、旧研究和旧主线胜场保留。
