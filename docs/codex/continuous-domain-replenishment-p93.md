## 目的与回放口径

P92建议把P91真实补兵方法延伸到机巧遗迹和电力挑战，并使用共同检查点。P93从P90使用的同一份P81库存快照开始，独立重载四种挑战、四条xorshift随机流；每次最多12次尝试，胜负后都把实际战损按现有岗位、`tick()`、训练队列、编队动作真实补齐，再继续挑战。战败后警戒值保持不变，仍在同一值复试。种子1、2、3、4是敏感性样本，不是玩家胜率估计。

共同起点：`S.tick=7912641`、人口214、现役并完整编队437人；输入快照加载后警戒值为机巧遗迹`godRevival=4000`、光学拟态机`godPhantom=0`、重装防卫机`godGuardian=4500`、战术演算机`godSlaughter=2800`。挑战奖励库存分别为遗迹晶核41、防护模块19、相位晶簇0、高能核心70；战备勋章810836。快照其余岗位与资源保持原状，没有注入军队、资源、警戒值或属性。

表中损失人数包括胜败场；补兵秒数只计真实资源生产、岗位转换与训练期间推进的模拟在线秒，不含战斗动画/现实等待。补招成本是训练队列实际扣除的向量；逐秒训练期间的维护通过真实`tick()`结算，但本批未另拆“训练粮”与“军队/人口维护粮”净额。挑战奖励仅记录配置奖励实际入库量，没有把不同奖励换算成招募金属价值。

## 设计结论与边界

1. **当前晚期阵容不是各专项挑战的统一成长入口。**同一检查点的四条流显示极大分化：光学拟态机在前1200警戒零损；战术演算机大多能打赢但要付补兵；遗迹在4000起点只有4/12胜；重装防卫机4500为0/12。若只用“挑战有奖励”或“材料随警戒上升”评估成长，会漏掉不同的胜负与替兵成本。
2. **某条线赢得多也不等于能自给。**遗迹和战术演算机掉落的晶核/高能核心与勋章，不是现役阵容主要铜、铁、钢补招费；守御石挑战本回放没有奖励。当前回放中打赢的奖励没有抵消主招募资源，补兵依赖岗位持续生产与初始仓储。因未单独计算四条路线各类资源的长期净产与库存门，本批不宣布正净收益或可持续。
3. **失利后原地重试可能形成昂贵的停滞段。**重装防卫机四条固定流48次均未胜、警戒值不变，但真实补满又耗约84.64–88.56小时总在线生产/训练时间。此结论只限当前437兵阵容、K4500和所测四条随机流；不是该挑战永远不可胜或所有玩家的难度判决。机巧遗迹的四条流都在4400结束，也不足以认定K4400是硬墙。
4. **用单一“平均警戒曲线”会掩盖奖励/敌压支线差异。**四条挑战必须分别记敌压、实际入库、战损、招募向量和补兵时间；光学拟态机的早段无损奖励不应覆盖到高警戒预期，机巧遗迹与守御石也不能用战术演算机胜场率替代。
5. **这批是验证，不是内容/数值改动。**玩家显示名和像素资产继续服从D15阶段主题；本报告保留内部挑战键和当前显示名用于核验，不表示名称、美术或战斗配置已定稿。

下一步应对普通战役和驻军挑战应用同一检查点、分开记录独立单场成本与连续真实补兵；随后从统一新档策略重放至相同检查点。只有把挑战回流与铁/钢招募成本、粮耗、资源生产、容量和墙前/墙后等待合并，才能决定哪些挑战适合作为《放置时代》式并行成长通道。
