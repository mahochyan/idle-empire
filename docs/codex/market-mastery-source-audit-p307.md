# P307｜贸易精通与市场补货时间复查

日期：2026-09-28。策划目标仍是母本式发展副本供应时代材料，100关作为全科技后的高难主线；玩家外观采用本项目美术，早段偏机巧、后段逐步转西幻。P306从实付档用20场遗迹战与19剂市场净化跨过2亿知识仓，但选定路线用了约170.75小时倍率1模拟生产时间。本批检查母本市场科技是否能实质缩短这段等待，不改变玩家运行代码、存档或UI。

母本实体 `460020`「贸易精通」前置 `450809`「丝绸之路」，最高50级，静态费用字段为知识300及后续知识300／勋章2。`380049`净化剂货位的`MarketTime=40`。解包源码`refreshResource`在本轮抽出某货品`n`格后，给它的可购次数为 `floor(n × (1 + 贸易精通等级 / MarketTime))`。因此单格净化剂在0–39级仍只可买1剂，40–50级才变2剂；两格时20级可买3剂。母本市场仍每1200秒按权重抽10格，净化剂单格权重10/2625；科技不改刷新间隔或抽中率。

另一个独立科技`460016`「市场存量」提升手动刷新次数上限。源码`getMarketTime`给基础上限5次，每级+1；`refreshTimer`每1200秒在充满前补一次次数，充满时自动换货，`marketRefresh`消耗一次次数并立即重抽。**这是储存刷新机会，而不是加快其长期产生速率。**当前我方市场只有自动补货，没有手动刷新次数；不能把母本存量回溯写入P306旧档，或将两项不同科技混称“市场加速”。

以P306报告的19次净化购买和每次固定种子291重设后等待30000倍率1模拟秒为条件，若货架已有40级精通且每次只出现一格净化剂，10次出现可供19剂：市场等待由570000降至300000秒，即83.33小时；保留P306其它44716秒不变时，总计约95.75小时。**这不是实付新路线**：我方尚无该科技，研究费未支付，战斗与净化的时间顺序也未重新实跑。按母本权重独立抽格计算，长期平均每26.25轮产出一格净化剂；为19剂所需的市场时间，一格一次约166.25小时，一格两次约87.5小时，均只是期望值近似，不是保底或典型玩家时长。50小时的150轮期望抽中约5.71格，40级也只对应约11.43剂的期望供量。母本5次基础存量只能提前花已经积累的机会，不能改善长期产出率；更高存量等级须另行研究付费。

**本次决定：**暂不单独移植「贸易精通」或用免费补货弥平P306账本。它是母本可考虑的市场配套成长，但对稀有净化剂主要是40级阈值后的单次货架翻倍，无法单独证明本项目后段材料与勋章路线、单局至少50小时内容目标或完整成长曲线合理。近期优先同一实付档核遗迹更高警戒的军力、其它晶核/勋章有价来源与战损补回；市场科技若进入实施，应连同手动刷新次数、研究付款、旧档保护、随机性和UI一并作为单独可验收任务处理。后期玩家名需按西幻主题另定，不把母本ID或名称直接作为上线文案。
