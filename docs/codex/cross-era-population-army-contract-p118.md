# 跨时代人口、产业与军力承接契约 P118

日期：2026-09-25  
策划文档版本：v2.45

## 目标和结论

本批把人口、经济岗位、粮食维护、仓容与兵力成长放在同一个时代交接结构里，作为《策划文档》§8.3–8.5的共用验收契约。它整合现有母本映射和P101–P116证据；不新增玩法，不改当前增长倍率、敌人、奖励或存档。

**阶段方向已能确定，十时代人数和时间仍不能定稿。**我方当前基础增长为有粮、有容量时每10秒+2人，出生在 `math.js` 中独立于关卡胜利；这与母本基础速率同形。已有零战斗路线能到18人口，且第3关的额外地契候选没有改变固定队列下的第6关胜负。因此人口不足不能仅凭关卡进度推断为出生慢：应先分别检查住房/地契续供、岗位预算、粮净流、关键仓容和战损补兵。基础出生倍率暂不提高。

## 每时代交接的硬验收合同

时代 `A → B` 只有同时满足以下条件才标为“成长可达”；只解锁研究或只在终档拥有资源不算通过：

1. **住房与劳动**：人口自然增长路径不要求胜场；容量与地契续供在上一段已开放。进入时实际人口 `N` 至少覆盖当期同时运行岗位数，另列闲置/可调岗位数；不能把容量、地契余额或累计出生时间冒充实际人口。
2. **真实生产**：按当前版本真实配方从最终产品向矿/石、煤、铜铁等上游倒推人员；同一时期计入建设、研究、市场和粮军维护。使用真实逐秒结算处理断料、满仓、加工、建筑计时和训练队列。
3. **口粮守恒**：当前食物产出要覆盖所有实际人口口粮、现役军队动态维护和真实加工耗粮；断粮后仍有可逆的岗位/生产恢复路。现行引用值为有效粮工2.25食物/人/秒、居民0.1食物/人/秒、铸币消耗1食物/工/秒、军队按兵种 `upkeep` 与维护档位计算；每次数值变更都以当前`CFG`与生产函数复算，不沿用旧报告中的假设值。
4. **下一笔与仓容**：抵达门槛前能逐步扩足该次研究/建造仓容，并留出支付后开展生产/招募的原料；不能先要求超仓库存再解锁扩仓办法。记录进入库存、单笔最大值、仓容、扩容花费和扩后净产率。
5. **军力与奖励**：士兵由真实训练队列和资源费用形成，与村民不是同一人口池；普通战役/专项挑战/驻军分别计入奖励、失败损失、口粮和重训时间。每个必经战斗入口须在该场胜利前已有自然可达的编队；战后首次扩容奖只加速后续住房，不回填当前战力。可重复挑战若作为长期军力入口，必须证明其实际奖励扣仓容、替兵费用、粮耗和战损后有可用净回报。
6. **时间和操作**：至少并列零战斗经济、均衡战斗、军事倾斜、短时在线/离线四路；每路记录模拟在线秒、自然经过时间、主动岗位/交易/扩容/战斗次数、关键检查点、战损补回和下一道墙。跨快照拼接不构成一路证明。

对当前工作区公式，稳态粮食检验可写为：

```text
粮工实际产出
  ≥ 实际人口 × CFG.popFoodCost
    + 所有现役兵种 upkeep（含当前维护档位）
    + 实际运转岗位/加工的食物消耗
```

这里不固定写入粮工数，因为建筑加成、时代乘区、仓满截断、军队数量与免费维护带都会改变右侧或有效产出。此式是检查点条件，不是用起始净率乘游戏时长的离线模拟。

## 主题承接

人口和工种仍表现为我方聚落经济，不应因为后段西幻主题把早期村民改成神祇/魔法劳动力。开局至黄金使用村镇、工艺、金属产业和城邦词汇；合金至蒸汽为制造、工造与机巧遗址；电力开始少量融合魔法挑战与圣物；核能以后逐步增强星界、异界、神裔、位面与虚空意象。内部资源键、源ID、存档字段和玩法职责保持稳定；西幻命名是我方美术映射，不照搬母本专名。

## 本批状态

本批把人口增长方向、最低岗位角色、实际军粮、仓容/研究墙和兵力回补约束并入一份可检查的时代接力合同。具体十时代人口目标、每策略到达时间、量子/终局军力与区域收益，以及完整美术资产表仍未证明；下一阶段须选共同新档里程碑组复跑，不把不同报告的成功点相加。此次只新增报告及权威策划文档交叉引用，没有运行时改动；原始源码与证据工作区保持不变。
