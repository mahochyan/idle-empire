当前粮仓容量为3000。2600是本次抽测中首条逐种子复现P142胜场和首败点的线；调岗发生在种子1／2／3／42／12345的L5／L7／L11／L5／L4恢复窗后，库存约2664.6／2781.6／3000／3000／2675.4。2800线下种子1于L6恢复窗后约2823调回，种子2未触线；种子3／42／12345分别在L11／L5／L5恢复窗后达到3000。3000线只在封顶时触发，种子2同样未触线。2600、2800、3000三条线均保住P142的逐种子结果；600–2200线在该样本中均为34胜。

这支持把“近满仓才回调”保留为当前仓容下的**岗位策略候选**，尚不能写入全局规则：样本只有一个早期入口和五个种子，尚未覆盖其它仓容、经济/科研/军事/短时路线、败战恢复或跨时代粮耗，也不等于玩家胜率。后续应在更广的同源路线验证库存安全余量与待训练兵种队列，再决定阈值是否跟仓容比例或补兵缺口联动。
