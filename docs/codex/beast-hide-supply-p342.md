## 文档目标、代码现状与本次决定

文档目标是让母本式郊野副本持续供给发展材料、兽骨／交易经验与军备成长；100关仍是全科技后完成的高难主线，玩家可见主题沿本项目机巧工业到后期西幻，原创玩法后置。P341 证据表明母本交易经验门槛与本项目相符，但本项目缺少母本六兽战的基础兽皮及兽皮换物资货位。母本实体 `210(1)_unpacked/_analysis/entities_table.json` 中六条 `smallWar` 的基础奖励均为兽皮2、兽骨15；资源160007兽皮基础上限9999。`deob_main.js` 的 `winSmallWar` 把两项基础奖励乘同一胜利收益系数并向下取整，故本项目以当前郊野已有的骨倍率计算兽皮，不另造奖励曲线。

本批接入兽皮资源、六猎场胜利结算及十二条母本权重1的兽皮货位：290001–003换食物、290011–013换木材、290021–023换矿石（我方石料）、290041–043换煤。母本另有290031–033换麻布；本项目还没有麻布资源和相应产业链，这三条**未实现**，在原交易所等级的总权重中仍占位置，不把概率转给已实现商品。货位从边贸行1级即可按原20分钟在线时钟刷新；每格独立抽签、同商品重复上架数累加，折扣品质沿现有货位逻辑。兽皮可在原郊野卡查看，只有实际抽到且兽皮、目标仓容都足够时才允许实扣交易；每笔成功交易积1边贸经验。界面只在既有卡片加库存、货位与按钮，没有改 CSS、美术系统或其它 agent 的UI范围。

费用与收益沿母本普通商品的交易所等级因子 `1+0.2×(Lv−1)`；费用再乘已抽出的品质折扣并向上取整，收益向下取整。我方动作在目标资源仓容不足时拒绝整笔支付，避免玩家付出兽皮却只收到被仓容截掉的一部分；这是对母本结算上限行为的保守适配，已明确与母本不同。新增兽皮上限以母本9999为基础，既有非货币仓容研究／图纸可依本项目规则提高当前仓容。历史超仓存量不会被裁剪。
