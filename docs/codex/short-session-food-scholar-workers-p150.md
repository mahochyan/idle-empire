# P150：四学者路线低矿物下的离线粮工复验（2026-09-26）

## 方法与范围

P150从P149四学者科研优先路线在第4关胜后、首个离线窗开始前的真实隔离`save()`检查点出发。粮食保持56.293556，人口19/19、军队及8名待训青铜守卫队列保持不变；石、煤、铜分别设为真实仓容的0%、10%、50%。每个库存档比较2名粮工基线，以及通过真实`setPopAlloc()`从石／煤／铜各转1人或2人，达到3／4名粮工的路线；每种均调用真实`settleOffline()`结算28800秒。

与P147一样，矿物库存是在战后训练队列已存在的检查点才改写。结论不涉及从新档筹备战役或首次建立队列，也不读写玩家浏览器存档。

## 设计含义与边界

P149已证明四学者路线进入截断窗时的可见状态和逐秒账与P145顺序扩建路线相同；P150进一步在四学者路线自身的真实存档上验证了低矿物压力下临时加粮工仍能完整撑过单个8小时离线窗口。它支持把“队列直付＋新增军队维护”纳入离线预算，并将临时粮工列为该19人口战后节点的可测岗位调节候选；它不支持固定全局粮工数或全面宣称P112短时战役已通过。所有来源岗位的资源终点都回到仓容上限，因而无法比较石／煤／铜的长期机会成本；4学者前期资源供给、战败后重建、其它兵种和多次连续离线仍未覆盖。
