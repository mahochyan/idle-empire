# P177：零胜场20→28人口的城市扩建路线（2026-09-26）

## 同档问题与方法

P164已从三份真实20人、零胜场存档逐级扩村至28人，但需116张地契。当前配置里的城市每级增加4个住房位，20人档已经实付研究过前置`冶铁术`且有5000科技点。本批分别从P158的三份**同一序列化20人终档**重载，先真实支付2200科技点研究`城市化`，再用市场售出木／石／粮余量、按100钱币／张购契，两次实付城市扩建。每次扩建后在线等待自然出生，并把新增4人通过真实岗位动作分配为木工；每累计600在线秒调用`save()`、结算28800秒离线，再重载核对。市场保留木100、石1000、粮1000。没有关卡胜利、资源注入、直接改`S`或写入玩家浏览器存档。

P177启动前发现P158/P164旧原始数据中的`math.js`输入哈希与当前工作树不一致。依次重跑P157、P158、P164后，三批人口与时钟摘要未变，输入哈希已重新对应当前代码；P177同时核验这两份来源数据的全部输入哈希和HEAD。此次重跑只是刷新开发侧隔离数据，不修改玩家代码或旧存档。

复查探针时还核对了P158序列化终档的每项摘要；城市每次出生后只把**本次新生**居民转为木工，保留起点原有的2名空闲居民，与P164逐人扩村的岗位投入量一致。购契前后钱币／地契余额和扩建后地契扣减均由实际动作结果断言。

城市Lv1→2、Lv2→3分别实付36／42地契，合计78契／7800钱币，比村庄8级少38契／3800钱币。每次城市扩建后4名居民均在20在线秒内按当前每10秒出生2人的规则自然补齐，终点三份存档都是28/28、0胜场、0地契。城市线相对P164少约17.7%／17.7%／18.7%的20→28主动在线时间；离线总时间少16／16／8小时，但仍需120／120／128小时模拟离线等待。P177终点知识回到5000容量上限，是后续实际生产和离线结算的结果，不代表2200研究费用被免除；研究动作当时已断言从5000扣至2800。

三支城市线的续接段粮食观测最低均触及1000保留线；顺序／4学者终点粮食1049.15，7学者1905.8。该方案降低住房筹契成本，但没有解决战斗补兵、军粮断档或第28人以后的住房。城市化并非新系统，属于当前规则下更合适的经济发展路线。策划可把“市场购契→科技解锁城市→城市扩建→自然出生”作为零胜场人口保底的下一档，并让第3关一次性拓居令提供加速；不必把关卡胜利改成村民直接增长，也不应仅凭该同档比较提高出生倍率。
