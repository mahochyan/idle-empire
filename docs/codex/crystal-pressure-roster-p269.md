# P269｜机巧遗迹晶核：警戒台阶、兵额与真实补兵

2026-09-27。100关「帝国战线」仍是全核心科技后才应打完的高难主线；「拓境远征」承担《放置时代》式区域材料成长。P268已把图书馆、研究院实付到满级，知识容量87339595仍低于星核研究单笔1亿。本批只核其中一条补口：机巧遗迹晶核能否连续取得、战损能否真实补回。没有调整副本敌压或玩家数值，也没有触碰并行UI美化。

## 文档目标、代码现状、本次决定

策划目标是后期研究必须在同一存档中付得起材料和知识，不能拿单场胜率替代连续供给。代码中`openMaterialDomain('godCrystal')`胜利才给晶核，警戒每胜+100；兵额受训练建筑`unitCap()`、每团`regMax()`与四前排/四中排/四后排阵位共同限制。P268来源档有437兵、晶核41、机巧遗迹警戒4000，知识仓87339595；蒸汽科研从14升到18级若独立承担破亿仓容，需累计晶核660，即还差619。本批决定先用当前军力找警戒断点，再把**现有训练上限内**的79名缺员走真实资源、训练、编队链路，重测连续挑战。不把条件加兵视为已付款。

[警戒敏感性探针](../../tools/verify/probe-crystal-pressure-p269.js)从[P268 v32实付档](reports/data/p268-nuclear-capacity-buildings-save.json)独立加载每次战斗，来源文本SHA-256为`81ecdd146bd13f575ff43e4c6ae85ce1f77ed2ba9fae94afaa78f65ae6e1795b`。每个警戒值4000–5000取16条固定随机流，调用真实异步战斗与结算；下一场重新加载同档，因此这里的警戒赋值和79人加兵仅用于条件上界。

条件编队只增加原有三个兵种：电磁兵17、合金特种兵38、装甲兵24；黄金骑兵原有40人已达当前上限。现有前排四格均已占用，合金与装甲虽各还可训练1人，单团55人限制使其无法入场。本次不扩阵位或训练建筑。原阵容与满员阵容的[逐警戒数据](reports/data/p269-crystal-pressure.json)、[条件满员数据](reports/data/p269-crystal-pressure-conditional-full-roster.json)分别保留；16流是定位台阶的有限样本，不是玩家胜率。

[原437兵连续实战](../../tools/verify/probe-crystal-continuous-p269.js)在每胜后真实调岗、逐秒生产、`train()`扣费、排队、重编、保存和隔离重载，且补员期间粮净产保持正。固定流13首胜损76兵，1078模拟在线秒补齐后在4100警戒败；流6、16各两胜并每场补满，随后在4200败。三路晶核终量分别93、146、146。此样本明确不能仅凭4000单胜就推到所缺619晶核。

当前可做的策划判断：现有兵额是4000–4400警戒的明显门槛，实付79人能将连续挑战推进到至少五胜，但三条实付流最多持有364晶核，仍低于仅蒸汽科研补口所需660；即使具备660，还须逐级支付知识并最终同点囤足星核研究的1亿知识和80万勋章。不能据三流把4600以后判为数学不可达，也不能为了单一副本直接下调难度。下一步应优先检查边贸图纸的真实上架/刷新/材料账，或复核装备和其它军力成长，再以**混合扩仓的实际付款**定后期材料曲线；100关终局仍保持高难，区域副本承担材料成长，原创玩法后置。
