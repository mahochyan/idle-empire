# 我方普通战役前十关与母本早期成长职责映射 P117

日期：2026-09-25  
策划文档版本：v2.44

## 目的与证据口径

P116确认了我方第1–6关的实际敌军编成与早期压力断点。本批把第1–10关放到《放置时代》的早期成长结构中比较，回答“每段关卡应该承担什么成长职责”，不伪造逐关的一对一对应。

《放置时代》没有与我方普通战役相同的固定1–100线性表。它把郊外狩猎、边疆资源点、外域六国和后段区域分给不同生成器、奖励函数与成长门。以下参考数值是静态模板事实；进入实战后还会受品质、杀戮值、人数和区域生成器影响。没有运行母本客户端，也没有从静态模板推断实际玩家胜率。

我方数值来自当前工作区`levels.js`和`config.js`；第1–6关压力样本来自真实战斗初始化对象和P116固定随机流。人数加权攻击仅作面板索引，不能当作DPS、胜率或关卡完整强度。

| 2 | 9／9／36；108/75/64 | 郊外同一区域内的轻度强度递进。 | 只提高熟悉敌人的数量，不应要求额外时代材料或依赖胜场生人口。 |

| 4 | 30／30／180；125/88/75 | 近似“开启更高压力内容”的节点；母本靠新区域/门槛扩张，不是一次把同一挑战抬到近3倍。 | 当前首个压力墙：人数从11跳到30、加权攻击从44到180（4.09倍），并首次加入弓手。P116的15/15个零等待固定分支都先败在此关。必须作为首个编队/经济检查点，并验证前置人口、弓手训练、木料与败后恢复是否自然可达。 |
| 5 | 6／6／36；136/95/81 | 母本没有已核实的“通关后固定喘息关”一一对应。 | 若保留当前大幅降压，应明确把它设计成L4之后的喘息/重整段；现有奖励只比前关小幅增长，尚未显示明显的恢复出口。它无法帮助玩家首次打过L4，因此不能用它掩盖L4前置成长断点。 |

## 设计决议候选与未决项

1. **关卡骨干按职责映射**：L1–3熟悉基础编成；L4第一次组合压力墙；L5有意作为可解释的恢复段或将编队平滑；L6–9形成可以被产业与军队成长承接的阶梯；L10作为章节里程碑。母本的“郊外→边疆→外域”体现并行区域逐层打开，不复制成每关一换区域。
2. **人口与战力分开**：村民基础增长继续由住房/粮食和时间承接，胜场只能作为明确的加速/扩容出口候选；不把通关人数写成军队可持续规模，也不把村民直接发成士兵。第4关前必须验证零死锁的补兵与产业入口。
3. **收益分成战役推进与材料通道**：普通关奖励推进基础资源与进度；母本式稀缺材料、地契/勋章职责应由对应区域/专项通道承担。任何首通专属扩容候选都是我方适配，不称作母本事实；须另核首通与重复战的实际收益、仓容截断和补兵成本。
4. **先修曲线职责，再定面板值**：L4陡升、L5骤降、L6再升是已证断点，但P116是5条确定性随机流，不是玩家胜率。L7–10尚无从早期入口的同档战斗回放；特别是L10静态指标提示Boss职责可能没有落在敌方强度上，不能仅凭晚期军队打过就定稿。
5. **主题命名**：本段以军镇、前哨、巡线、弩阵、铁闸、工造等朴素军事/工业词汇为主；当前L3“弓兵哨位”与纯步兵编成不符。神祇、圣物、位面、星界一类西幻词汇继续留到电力以后逐步引入，遵守D15；不照搬母本专名。

## 本批结论

第1–10关可作为我方早期开局战役的节奏骨架，但不能称为《放置时代》逐关翻版。母本可迁移的是“战斗区域也提供后续成长入口、难度跟随内容门逐层展开、敌压与回报分通道记录”；我方当前最需要定稿的是L4前的入口支撑、L5喘息职责、L6恢复承接，以及L10章节Boss的实际强度和奖励语义。P117只补充静态映射和设计决议候选，没有改配置、敌军、奖励、人口、存档或代码。
