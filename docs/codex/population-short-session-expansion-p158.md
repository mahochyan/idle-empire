# P158：短会话路线从新档扩容至20人口

日期：2026-09-26。在线秒、离线秒均为模拟时长；不包含真实玩家的点击与决策时间。

## 方法与范围

分别从顺序扩建、科研优先4人、科研优先7人的真实P101零胜场新档开始。P101阶段每600在线秒调用真实`save()`，再用真实`settleOffline()`结算完整28800秒离线；从其真实序列化18人口终档继续，以相同的600秒在线／8小时离线节奏，通过当前市场出售余量、购买地契、真实村庄扩容、在线自然出生和木工调岗达到20人。每次住房扩容后真实保存并在隔离环境重载。

续接阶段对每秒`productionSecond()`结果和每笔市场交易后的粮食都采样；每个离线窗必须完整且无截断。另断言离线前后人口、容量、出生时钟一致，三路胜场始终为0，粮食不低于1000保留线。无奖励注入、资源注入或游戏状态直改。

“省下在线秒”只与P157三条连续在线路线比较主动在线时间；短会话路线分别额外经历72、72、80小时离线。数字不能把离线等待算成免费加速，也不能代表真实游玩体验。P101保存点之前每一路都有7个完整8小时离线窗；扩容续接阶段顺序与4学者再各完成2窗，7学者完成3窗，所有窗均完整、没有粮食截断。

三路都零胜场达到20/20，终点新增村民均可分到木工；每次购契仍按保留100木／1000石／1000粮交易。续接阶段最低粮正好触及1000保留线，市场出售库存已无额外余粮垫。离线生产能把资源补到下一次市场交易可用的水平，但离线不增加居民，也不改变出生计时器；容量仍需先在线买契、扩村，再在线等待自然出生。

## 设计判断与边界

自然出生和市场住房可以一起支撑经济、科研和短会话路线到20人口，关卡胜利不是该段基础人口的必要来源。短会话将部分产能等待移入离线窗，降低了主动在线秒，但市场交易把粮食压到保留线，现有证据不能证明玩家有足够宽的失误余量。后续曲线应把在线产出、离线结算、保留库存、地契成本和住房档分别记录，不以人口出生倍率替代住房支付能力。

本批短会话从新档运行到P101的真实18人口存档再继续到20人口，覆盖三条经济／科研分配，不含军事策略、关卡战损、失败恢复、驻军消耗、更多随机流或20人口以上住房。虽与P157共用真实序列化人口路线，仍不能当作四类策略、完整战役、十时代曲线或玩家耗时验收。详见[P158原始数据](reports/data/p158-short-session-population-18-to-20.json)。
