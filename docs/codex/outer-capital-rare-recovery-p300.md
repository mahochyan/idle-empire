# P300｜铸金王都稀有掉落后的实付战损、重建与复战

日期：2026-09-28。文档目标是让「拓境远征」按母本式区域挑战承担长期成长；P299代码已在外域真实胜利中抽「圣兽血剂／炽翼战剂」，但其50场**条件必胜**收益推演没有计算军队损失。本批决定用现行代码重放P259的铸金王都实付军队，核验稀有道具实际产出和失败后的补兵边界。没有调整敌阵、掉率、岗位、科技、100关主线、存档格式或并行美术。

## 起点与口径

[完整逐战账](reports/data/p300-outer-capital-rare-recovery.json)由[探针](../../tools/verify/probe-outer-capital-rare-recovery-p300.js)生成。从[P258实付黄金军队档](reports/data/p258-outer-capital-gold-army-save.json)经当前`loadSaveAndApply()`独立迁移成v32候选输入；原文件和玩家`rts_save`不改。每条路线重新从同一档出发，共16条固定随机流；前排15青铜刀盾兵＋15黄金重骑兵、后排13弓手T1。调用现有异步王都战斗、真实胜负／战损／稀有抽签／保存、P259住房扩容与自然出生、岗位调配、逐人训练付款、在线逐秒生产和保存重载。每流至首次战败后再完整重建一次，并在**同一警戒**、同一满编军队上实付复战一次。每次重建上限20,000模拟在线秒。时间不含玩家点击、动画、现实离线或设备性能。

16流在首次失败前各连胜3–14场，共159胜；这与P259旧流的连胜向量一致。首次失败警戒60–280，16次均为43兵全损。此前每胜后补兵与首次败后补兵均在上限内完成；首次败后补兵用时1,919–3,740模拟在线秒，均值2,426.1875秒，按配置各付木1,560、石520、粮20,150、金1,500、铜1,500。付款后的最低粮只有0.0951，说明这套岗位策略贴着粮食下限运行。每条路线从起点至首次败后重建累计10,919–31,790模拟在线秒，均值22,895.9375秒；16条**互相独立**路线的时间合计366,335秒、训练付款合计木99,480／石33,160／粮2,196,150／金147,700／铜225,900，不能当作一个玩家档的连续成本。各路线最终人口24–35。

败后同警戒复战16次，11胜、5次再全损；获胜的11次仍损19–40兵，只剩3–24兵，均值13.73兵。故已证明失败后**这组路线可以实付重建**，也证明单次重建不保证在该警戒稳定取胜；未证明无限循环、净资源正收益、不同兵种／血脉加点下的效果或玩家胜率。

连同11次复战胜利共170胜，实际稀有掉落为「圣兽血剂」3份、「炽翼战剂」0份；每场概率按开战前警戒从现行遭遇函数读取。对这170个**已胜场次**求和，条件期望分别为1.5428与1.4102份；按独立抽签计算0战剂概率约24.26%，因此0掉落不构成掉率故障证据。16流中的血剂命中分布为第4、7、9流各1份，没有在本批使用于血脉。战损限制了可胜场数；不能用170胜的掉落数倒推长期每小时收益。

[第11流首次败后恢复档](reports/data/p300-outer-capital-flow11-recovered-save.json)保存了当前v32可重载检查点：王都14胜、警戒280，原43兵重建齐全、血剂／战剂各0；紧接着同警戒复战在该固定流再次全损。可在后续**另立任务**从此档审查军备、阵型或长期经济，不把本批探针结果直接调成正式数值。
