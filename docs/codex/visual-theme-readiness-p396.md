## 量子、奇点和最小交付

`config.js` 已有「星界量子时代」及「星界构装卫士」，后者 PNG/动作帧/512px 立绘已在 manifest；并非量子全无美术。但 `ui.js` 的城镇时代列表到核能为止，量子研究后仍显示核能城镇；九景中没有量子场景。运行配置中也没有独立奇点时代或与之对应的城镇场景，策划里的奇点仍是后续内容目标，不可写成已上线。

为了尽快交付**当前可玩的版本**，保留九张正式全景和现有 60/42 资产，隔离全部 3D/清场候选；不因预览存在而临时切换运行图。为了进一步宣称 **D15 视觉路线已经完整设计**，至少还需要：(1) 电力三挑战的最终玩家可见名和与之对应的“机巧向神祇过渡”角色稿，联动单位立绘、战斗图和材料卡；(2) 核能、量子、奇点三段的场景/角色/建筑映射表，明确量子城镇需要独立图还是在核能景上有意延续，以及奇点是否为正式时代；(3) 对最终选定资产做手机画幅与真实浏览器/Android 复核。现有候选不满足这些交付，故本报告不建议随一次玩法提交将其作为已完成 UI 美化整体推送。

验证：`node` 枚举 manifest 的 60 单位、42 建筑、九场景及其引用文件，退出码 0、缺失 0；读取 `tools/visual/era-model-pipeline/audit.json`，其九时代 `readyForRuntime` 均为 false；静态目视九景并置、核能当前/清场候选、三名机体挑战和量子卫士立绘。本报告未运行浏览器或 Android 测试，不修改 `rts_save`，回退只需删除本报告。
