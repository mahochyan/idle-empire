# P288 边疆铁点与金铸币来源

## 文档目标、代码现状、本次决定

《策划文档》要求 100 关继续作为需完整科技成长才能打完的高难主线，拓境／圣域承接《放置时代》式材料成长，前期名称偏机械、后期偏西幻。P287 已核出母本净化剂的静态购买链，但我方没有相应金币来源。本批只接上母本已存在的铁点奖励和铸币岗位，不接净化剂、凝血丹或新市场商品；并行 UI 美化的 HTML、CSS、图片不在本批范围。

母本工作区 `210(1)_unpacked/_analysis/entities_table.json`：铁点 `560006` 的 `middleWar:Get` 第二项是资源 `160006` ×50；铸金币岗位 `350015` 每 4000 毫秒消耗金属金 `150009` ×1、产金币 `160006` ×2；资源 `160006` 基础仓上限 10000。对应我方新增独立资源「金铸币」，与金属金「金」、既有铜系「钱币」和「银两」分离。边疆铁脉关隘每次**真实胜利**发 50 金铸币；失败不发，点位升级与主线胜场仍分账。已开放冶金和当前档案所需铸币科技后，玩家可把村民分配到金铸币岗位；每人每在线秒平均消耗金属金 0.25、产金铸币 0.5，离线按同一配方及离线系数结算，满仓停工、缺料不倒扣。

这是母本材料经济的一段，不是警戒 5000 核心战的解法。P285 实付满编档的原始资源有金属金约 227、知识约 5468、勋章 2472、核心 47。以源商店 9999 金币购买一枚凝血丹的**静态标价**计，两名铸币工需连续约 9999 在线秒和 4999.5 金属金才产出 9999 金铸币；现有金属金远远不够，生产金属金及其仓储、商品上架与兑换仍需另行实付核算。源金币上限 10000 也意味着三枚丹若可买，须分次购买并保存中间物品，不能一次囤够 29997 金币。本批没有把源价格直接作为我方价格或宣称第 7 阶、取核闭环已解决。
