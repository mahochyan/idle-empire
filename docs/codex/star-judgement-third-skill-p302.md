# P302｜星际先遣兵100星第三技「星辉裁决」

日期：2026-09-28。文档目标是让「帝国战线」第100关依赖后期科技和**有实效的**军力成长，而母本式发展线提供觉醒、材料和军备。P301证明只给终局首领加兵不能形成这个台阶：刚付费换入101名星际兵的编队，在每组170敌兵的128条固定流中只胜1条。现行代码已接入星际兵前两项觉醒技能，但母本370009的100星第三技尚缺。本批决定补该源机制的战斗效果，不调整第90–100关、兵种基础面板、觉醒升星费用或并行UI美术。**当前实付档最高仍只有7星；本批不是100星自然可达或百关终局验收。**

## 母本证据与我方适配

母本静态表`210(1)_unpacked/_analysis/entities_table.json`的370009说明第三技：至少100星，每星0.7%触发概率；第一个攻击的己方兵员命中时，对敌方全体造成各自最大生命10%的真实损失，并按自身入场生命每2000再削2%防御，最多削20%。直接执行证据为`210(1)_unpacked/_analysis/deob_main.js`约偏移2292260–2293400：概率先`floor(0.7×superStar)`成整数百分比；实际条件为`superStar>=100`、`TeamID===0`和当次目标`HP>0.99×MaxHP`。`TeamID`在约偏移2380902由我方出场兵员顺序从0分配，因此本地以出场编号0的首团映射。源群体效果实际把各敌体`HP`设成`floor(0.9×MaxHP)`，防御乘`max(0.8,(96−2×floor(InitMaxHP/2000))/100)`；不是对当前HP再乘0.9。源`InitMaxHP`是逐兵值，当前项目单兵生命约按源÷100，故还原100倍后计算每2000档。

本项目聚合兵团每个团代表多人；前两技继续按当前存活人数逐人掷骰，第三技**仅首团代替源首位单兵掷一次**，避免把“首位兵员”误放大成几十次全体打击。目标必须在本场首次出手时仍高于99%最大生命；其他团不触发。命中后只改敌方战斗体：每个存活敌团生命至多降到自身最大生命的90%，已受伤低于该值的不被反向治疗；防御按源公式逐团削减，最多20%。临时护盾独立保留，不变成兵力；结算仍由现有`combatSurvivors()`与保存回滚路径处理。远征和驻军共用`applyAwakeningOpeningSkills()`，现有100星以下技能的掷骰顺序不变。战斗日志按后期西幻主题称「星辉裁决」，不照搬母本“宇航兵”名称。聚合体无法判断编号0的单兵是否已在本团第一次出手前单独阵亡；本地以首团仍存活代表，这可能高估被先手伤害后的触发机会，须在完整战斗模型校准时复核。
