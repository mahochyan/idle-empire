# P54 郊野兽骨兑勋章与回合上限对照（2026-09-24）

文档目标仍是《策划文档.md》§8：沿《放置时代》的成长骨干完成可付军备、材料回流和难度曲线，前段机械／工造名称、后段神魔西幻名称按用户确认执行。P53代码现状为实付三级电磁枪在守御警戒值2000胜、2100因30回合上限败；核能仍需知识1亿与勋章80万同时支付。本批先在同一真实v22档量出战斗回合敏感性和已接入的郊野兽骨→边贸行勋章路线；只扩展开发探针参数，不改玩家战斗、经济数值、UI或存档格式。

## 母本与当前入口

母本290015交换所可用兽骨10换勋章20，100%成功；我方现有「边贸行」`exchangeBonesForMedals`按此价格实际扣费、保存且不占高级市场每日次数。母本电磁步枪研究470072在470071后需知识200万／勋章5万，狙击枪470073在470072后需知识250万／勋章7万，电磁甲470074又在470073后需知识30万／勋章1.5万。这三项静态研究费合计勋章13.5万；其后230072／230073锻造还分别用神族之核170011，220071电磁甲制造用钢。母本540001杀戮之神的`Get`同时列勋章40和神族之核1。当前我方尚无神族之核持久资源、杀戮之神该材料奖励及完整步枪→狙击枪→电磁甲链；即使勋章足够，也不能声称军备已能购买或锻造。以上均按工作区解包版`210(1)_unpacked/_analysis/entities_table.json`相应ID复核，尚未运行母本客户端。

## 本批决定、验证与回退

不调整玩家回合上限或勋章价格。兽骨兑换已经提供超过后续三项静态研究费的**勋章数量**，但缺神族之核、技能枪效果映射和可持续军力质量；下一批若接这条链，必须把材料来源、研究前置、锻造与装备、战斗／驻军和v22存档迁移完整闭合，不能只加一个防具按钮。对80万核能费，须另验更多区域与策略，而非以单一郊野档冒称可达。前段「郊野／边贸／机巧」与后段「杀戮之神／神族之核」延续用户主题分层，原创玩法继续后置。
