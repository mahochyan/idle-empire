# P161：沿P160两种岗位终档续接扩容至28人口

日期：2026-09-26。时间均为模拟时间；在线秒不含操作时间，离线秒不是免费成长。

## 方法与范围

P160补存了两份真实24人口终档，本批分别通过`loadSaveAndApply()`重载并与P160终态摘要逐字段核对后续跑。两档都来自同一P159无地契L1–L11战役终档，但岗位不同：基线为木6／石6／粮3／煤6／铜3，候选为木6／石5／粮4／煤6／铜3。P161沿用各自岗位，不再调岗。

扩容、筹币和自然出生都走真实市场、`settlementBatchPreview()`、`upgradeSettlement()`、`tick()`、保存/重载和`settleOffline()`函数。每600模拟在线秒结算28800秒离线；市场交易保留木100、石1000、粮1000。每次成交、粮食生产、人口、容量、岗位和离线窗都写入原始数据。没有发放地契奖励或注入资源；`Date.now()`只在隔离harness进程内按来源存档时间推进。

## 设计含义与边界

住房续供证据从24推进到28：在同一战役入口后，市场卖余量、购买逐级增加的地契、扩村和在线自然出生仍能维持两种岗位样本。给粮工多1人让该样本筹币更快，短期内少损失粮食，但最低值仍正好触及1000保留线；没有安全余粮。该配置可作为玩家可选的资源调配方式继续验证，不是固定推荐岗位，更不能用来定全局出生倍率、地契奖励或扩容节奏。

证据只覆盖一个顺序扩建人口入口、一个固定随机流打至L11、两份P160派生岗位终档和每600在线秒＋8小时离线的单一profile。没有战斗L12以后、其它军事/科研路线、额外随机流、不同库存与仓容、连续在线、长期石料机会成本或28人以上验证。模拟累计离线为232–240小时，不等同玩家实际等待或50小时目标达成；全时代难度/成长曲线尚未闭环，原创玩法继续后置。
