# P348：边贸行离线被动供给接线

## 问题与规则

P347用P346代码真实重播了29个离线窗口，边贸货位会轮换，却没有兽骨、战备勋章或地契的被动收入。母本解包脚本`210(1)_unpacked/_analysis/deob_main.js`的`getExchangeReward`（字符偏移约1419144）在交易所达到25级、单次离线满900秒后发放这三项。它位于离线交易所／市场刷新之后，不需要货位、刷新次数或自动购买。

本项目保留玩家可见名称「边贸行」。令`T=min(30,floor((边贸行等级−15)/10))`，`M=1+0.05×floor(住房人口上限/1000)`，每次合格结算分别发放`floor(2×秒数×T×M)`兽骨、`floor(0.5×秒数×T×M)`战备勋章、`floor(0.3×秒数×T×M)`地契，逐项按现有仓容封顶；不乘0.6资源生产系数，也不增加交易经验。母本直接采用封顶离线原始秒数；我方采用`offlineAdvanceSec()`实际结算秒数，避免断粮截断后奖励超过离线报告时长。历史超仓库存原样保留，不因本次发奖反向裁剪。这两处是本项目存档与报告一致性选择，不能称逐项复刻母本。

已写入存档的合法收益是玩家资源，关闭后续发奖也应保留它们。若回退本批逻辑，可移除`settleOffline()`里的奖励调用及其函数和CFG常数；不自动删除既得骨、勋章、地契。下一步应沿P347同一有价档在新规则下重播交易与补兵，并验证战后提前排队、离线岗位供料是否能缩短实际在线补兵时间；100关全科技高难主线、区域副本发展职责和原创玩法后置方向不变。
