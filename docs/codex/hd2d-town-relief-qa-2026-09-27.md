# 主城九时代全景浮雕样板与验收（2026-09-27）

## 事实基线

- 当前工作区基线 `master` / `406bce4dc86a7d12f442ceebe5143ec9fa6f6e6d`，保留已有未提交改动；未 reset、提交或推送。
- 项目指令提到的参考快照 `98571e38801f71bfdbb982a626e0e58f510abb98` 在本地 Git 的作者与提交日期均为 2026-05-17，和指令中的 2026-09-18 不一致；它未作为回退目标。
- `hd2d.js` 原先在时代全景 PNG 加载后隐藏主城 3D 场景中除灯光和镜头外的所有子节点，因此 WebGL 主城画面实质上只剩镜头前平面图。
- 九时代全景均为 1024×525 且构图一致，细节质量高。七个现有 GLB 各约 5–7 KB，为程序化低面数建筑，直接盖在全景上会破坏美术一致性。

## 本次改动

- 从当前时代全景的六个地标区域实时生成软边透明贴图，贴在有分段 z 起伏的 Three.js 平面上。默认镜头对准原画；展开地图平移时仅偏移数像素，保留九时代原画为主视觉。
- 工人从快照读取木、石、粮分配，按 1/2/3 个像素角色显示并附落地阴影。驻军激活时出现守卫；施工中的建筑显示施工标记；驻军警戒阶段显示警戒标记。地图底部保留木、石、粮和巡防文字状态。
- 状态条明确以“工人：”开头，区分这里的岗位人数与顶部的木、石、粮库存；浏览器实际主页与四宽度样板均检查此标签。
- 展开与收起后复位镜头和指针状态。WebGL 全景热区按屏幕投影位置取 48 CSS px 的点击范围，继续调用原有 `openTownTarget`，文字入口保持可用。无 WebGL 的原二维地图仍可回退。
- 只改视觉读取层和样式；未改 `S/B`、战斗逻辑、资源数值或 `rts_save` 字段。

## 尚缺和回退

这是可审查的 2.5D 浮雕与视差层，不是完成的独立三维建筑：屋顶和立面没有按九时代美术逐件建模，原画光影是烘焙在贴图里的，不能宣称已实现建筑真实投影或统一实时光照。Android 最终 APK 需在本改动后重建并复验；目前没有物理手机可测。

视觉回退可恢复 `hd2d.js` 的主城浮雕/标记/热区段与 `visual.css` 状态条规则，直接 `file://` 打开则自动显示已有二维地图。存档结构未变。
