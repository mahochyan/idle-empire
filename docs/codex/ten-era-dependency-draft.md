## 证据、术语和现状

- **母本事实**：`210(1)_unpacked/_analysis/deob_main.js`；文中 `@数字` 是该文件读入 JavaScript 字符串后的零起点 UTF-16 字符偏移。结构索引见 [`era-mapping-audit.md`](era-mapping-audit.md)，本草稿又从 `entities_table.json` 对照了 370001–370015、280001–280008 和 350001–350015 的门槛、原料。只读静态注册表不能证明按钮可点击、价格实际扣除、战斗胜率或到达时长。
- **费用记法**：`知`=160003 知识，`勋`=160010 勋章，`粮/木/矿/煤/铜/铁/银/金/钢`=150001/2/3/5/6/7/8/9/10；金是**金属金 150009**，绝非金币 160006。下表费用是**单个研究的 `Need` 配置**，不含此前研究、建筑、容量和军队的累计费用。
- **前置记法**：`A ← B` 表示 A 的 `LimitID=B`，不是仅按知识费用排序推得的游玩顺序。研究 `Unlocked`、对象 `LimitID`、对象建造/招募费用须分别核对；数据表有错指和缺失门槛。
- **我方代码现状**：当前未提交工作区的 `config.js` 有食物/木材/石料/科技点/铜/铁/金币/地契、可重复的村庄/小镇/城市容量、8 个 `sciencesLong` 发展节点、学院/矿井/冶炼厂/铸币厂/市场和我方独立兵种。`math.js` 已用人口实际库存与 v4 存档。没有时代里程碑树、麻/煤/银/金属金/钢的完整资源与岗位、逐资源仓库、十时代军备和对应区域的实现。当前改动未作本草稿的运行验收。`sci_copper/iron/urbanization/city` 是**部分功能映射**，不等于母本研究链或费用已对齐。

## 从母本事实到我方方案：当前未闭合点

1. **开局知识与容量**。我方已有 0/4 人口、30 地契、学者与聚落扩容，但初始学院可建、食物库存300、铜科技路线都与母本有意不同。应先用当前真实实现回放“第一名学者→第一项研究→第一次扩容”，再决定哪些差异保留；母本研究费用直接复制到我方单仓库/单学院会形成容量死锁。
