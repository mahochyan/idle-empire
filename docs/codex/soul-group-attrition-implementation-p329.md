我方此前把一群英魂合为单个 Boss，按每名生命×人数给一条总 HP、按人数给独立 `attackMass`，却在其剩极少 HP 时仍让进场全员出手。这是本地量纲换算偏差。本批仅给 `materialDomainEncounter('soulStone')` 返回的英魂敌群加 `attackMassFallsWithHp:true`，复用既有 `combatAttackMass` 按剩余 HP 比例估算存活人数；生命、攻击、防御、每千警戒倍率、九位抽选、奖励与其他 Boss 数值均不改。现有 `applyCombatDamage` 在战斗体上扣生命，护盾不折减人数；该标记只挂 `B` 中的遭遇体，不新增 `S`／存档字段。此折算是本地近似，不等于逐名模拟母本的全部技能或伤害分配。
