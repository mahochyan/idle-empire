种子间损兵和替换费差异很大：种子2五关损失53人，而种子1损失31人；补兵等待也不与总损兵数简单成比例，因为损失兵种决定所需的金属上游和岗位切换。最高的单关补回为第47关种子2，1202秒；最低的单关为第46关种子2，1秒。上述时间是游戏`S.tick`模拟在线秒，不是现实等待或玩家操作时间；四条种子是敏感性回放，不是玩家胜率或期望值。

每条路线都得到五关当前配置奖励。第46–49关奖励以木、石、粮与战功为主；第50关Boss每场配置奖励木27600、石21000、战功55。它们没有支付这些阵容实际花掉的铜／铁／钢。四条独立路线的补回成本不可彼此累加成玩家账单，但每条路线自身显示：普通主线能持续解锁关卡，并不意味着当期战斗奖励可自给现役晚期军队。

## 设计判断

1. **晚期主线前沿可通，不代表损耗轻。**当前437人预备档以四条种子都能从46通到50；每五关损失31–53名现役兵，并各自消耗约3.8万–5.8万铜、3.8万–5.7万铁及3.85万–5.84万钢。不能只用“5/5通关”判断这一段成长顺畅。
2. **主线胜利回报与晚期补军材料脱节。**单段关卡奖励给木、石、粮、战功，实战替兵却大量消耗金属。要继续沿用《放置时代》的多支线成长节奏，主线、专项区域与军备生产须按各自奖励/费用角色协同；不能期待基础物资奖励自动抵消金属军损。
3. **村民成长应承接扩军成本，但不把村民直接等同于兵。**【建议，待统一账本核定】住房和食物支持持续自然增员，通关里程碑解锁更高聚落容量/产业入口；新增人口通过岗位产能、金属供给与训练能力间接支持扩军。Boss节点可提供能推动下一段扩容的定向发展资源，但不逐关直接生成士兵，也不预先指定奖励数值。
4. **该样本是压力点，不是全曲线验收。**P81起点已有晚期军备、214人口和437人阵容，不包含从新档抵达45关的时间；只覆盖46–50五关和四条独立随机流。不能外推第51–100关、普通玩家胜率、初期军力或自然驻军随机事件。
5. **皮肤命名继续服从用户主题。**报告保留当前关卡名供代码核查；中期机器与军备词可保留，电力以后逐步增加原创西幻意象。现存名称和历史代码不作为最终命名承诺。

结合P89（新档至45关的单条固定路线）、P93（专项挑战真实补回）和P94（驻军模板威胁与损兵），目前已经能比较不同模式的局部成本，但仍缺51–100关同档连续回放、失败后重建再战、多策略新档至共同检查点、短时上线与离线边界，以及包含岗位和军粮机会成本的统一净收支表。母本骨干和完整成长/难度曲线仍未完成，原创玩法继续后置。
