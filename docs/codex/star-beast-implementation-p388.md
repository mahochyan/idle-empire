## 已实现

- 参考快照 `210(1)_unpacked/_analysis/entities_table.json` 中的 530001–530009 九阶星兽：每天每阶胜利最多一次，失败或撤退不占次数；三种星阵材料同额掉落，首阶各 10，九阶各 250；警戒随获胜阶位加 100–500。每满 1000 警戒，生命 ×1.2、攻防 ×1.1、奖励基数 +20%。每日三次免费镇静，每次警戒 -1000（最低 0）。
- 我方兵团战斗量纲适配：源 1200 人 × 单人生命 ÷170 记为聚合生命，源攻击和防御各 ÷100，最多六条活跃队列，随聚合生命下降而减员。因此首阶 0 警戒的面板是 211764 生命、30 攻击、5 防御、6 初始队列；它不是源游戏逐兵模拟的等价声称。P389 的 16 条固定流敏感性显示，最初 ÷100 且六队恒定出手时 P386 实付档 0/16 胜；改成 ÷170 且队列随生命下降后同档 11/16 胜，故采用后者作为当前已付档入口口径。此样本不代表自然胜率或后续高阶长期收益。
- 星兽采用现有兽类图像，远征页研究解锁后显示九阶入口；三种材料通过真实战斗结算发放、按各自道具仓上限封顶。每日记录、警戒、材料一起保存；失败写档回滚；旧档候选迁移补警戒零值，并保留迁移前原文。
- 第 100 关新增「星辉圣阵」与「星界量子时代」首次挑战研究门；主线开战动作、选关和自动续关一致，旧已通关记录可重战。正式敌阵仍为 11 敌，**终战数值难度没有通过实付全科技档验收**，详见 [P387 门禁审计](stage100-gate-design-p387.md)。
