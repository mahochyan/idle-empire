# P394｜第 50–80 关主线首领压力收束

## 目标、代码现状与决定

原第 50／60／70／80 关都由 11 个各 1 人的兵团组成。相邻普通关分别有 120／128／128／140 人；由于现行战斗生命按兵团人数计，首领的攻防倍率不能弥补人数造成的生命回落。正式配置保留原兵种、攻防倍率、奖励和存档字段，只把每组人数依次设为 12／13／14／15，即总数 132／143／154／165。这样章末承接前一关的战损压力，下一章首关保留喘息段。

隔离候选和原配置对照见 [调整前 16 流账](reports/data/p394-boss-cliffs-before.json)。从同一[自然战役入口档](reports/data/p100-natural-campaign-entry-before-upgrades-save.json)进入，使用现有 40 合金前排、胜后真实训练补员的 P97 连续动作；种子 1–16 各自从入口重载，逐关战至第 81 关。候选 16／16 到达并胜第 81 关，四个首领全部 16／16 获胜。正式落表后再从同一入口执行，结果逐流与候选完全一致，见 [正式配置 16 流账](reports/data/p394-boss-cliffs-after.json)和[复跑探针](../../tools/verify/probe-boss-cliffs-p394.js)。
