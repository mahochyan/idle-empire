# P142：无地契战役中的粮工岗位对照（2026-09-25）

## 目的与方法

P141的固定木工支线有木料很快触顶、战后粮食偏低的问题。P142从同一P139无地契18人口战前档出发，第3关胜利后不加居民，只把1名石工调为粮工：石5／粮4／煤6／铜3，人口与岗位总数仍为18。当前工作区CFG/敌阵与P102真实生产、训练、分工、tick、战斗、战损、奖励和补兵函数照常运行；关闭隔离探针候选首通地契，5个xorshift32种子各跑当前岗位、金属倾斜、粮工倾斜三支，每胜后等待600模拟在线秒，首次战败即止，共15条路线。

P142逐种子重跑P139当前及金属支线，并断言首次失败关卡与胜场数一致。新增粮工支线在L3胜后把1名石工改为粮工，保持18／18，不扩容、不增人口、不注入奖励地契。

改岗后4名粮工的实测粮产率为9.9／秒；同档原3名粮工为7.425／秒。首个600秒补兵窗口结束时，粮工支线各种子都把青铜守卫库存补至13、队列余2；当前岗位支线此时仍有6–7名青铜守卫待补。代价是前4个种子的粮食结余仅约13.5、29.9、34.2、51.2，种子12345约296.5。增加的口粮产能被更多训练完成的士兵和后续军需迅速消耗，不能仅看“粮工产率上升”。

## 设计判断与边界

- 此样本说明，18人口不变时把劳动力投向粮食，可能比固定木工更直接地转成补兵；它没有证明常驻4粮工是普遍最优。种子2少推进一关，种子42和12345结果不变，种子3的大幅推进不能代替多策略稳定性验证。
- L3胜后等待窗口末的粮食较低，下一场及更长窗口的口粮安全仍是门槛。本批不据此提高人口出生倍率、增加固定粮工、修改奖励或下调敌军。
- 下一轮应在同源路线里比较“补兵队列需要粮食时短期加粮、粮食储备恢复后回调到木／金属”的手动调岗策略，并记录操作次数、最低粮食、各兵种队列与下一战结果。只有该路线跨种子改善且没有口粮断档，才可把灵活调岗写为正式骨干建议；本批没有加入自动调岗机制。
