## 已修复的确定性缺陷

`openAwakeningTrial()` 原先先扣圣域异果并保存，再进入 `openBattle()`。旧存档或规则变化可保有超过当前军团整编规模的编队；`openBattle()` 会拒战，试炼却返回 `ok:true`，已经扣费落盘。修复前以 P390 已付档为起点，在**隔离测试夹具中设置**军制已研究、50 星与异果 1000 来构造超额状态（没有宣称这 50 星自然付得），保留原有 600 人编队；真实函数返回 `{ok:true,cost:109}`，存档异果变 891，`S.battleActive=false`。修复在付款前使用与 `openBattle()` **同一** `formSoldierCount()>steamMilitaryActiveFieldCap()` 条件，并给出明确缩编提示；不裁剪旧档军队，也不改费用或战斗公式。

已逐分支核对 `openBattle('awakeningTrial')` 的其它拒战条件：战斗中、存档保护、核能研究和目标兵部署已由试炼入口先拦；目标兵正数部署也保证编队非空。每日星兽、英魂槽和拓境历史离线分支均不适用于觉醒试炼；试炼付款标记在开战前设置。现有已知后付拒战路径因此闭合。将来若扩充试炼域的开战门，仍需同步前置检查或改成统一事务。

## §8.9 八项的最短关键路径

1. **先封内容与依赖，不凭空扩关。** 逐项定稿仍待决的 45 个母本研究、非直映兵种、后量子时代及区域效果，给每项明确我方主题名、实际运行效果、首笔知识/勋章/材料/容量来源、首通与复刷回报。P403 已核源端 450025 后有区域回报增幅和季节领取，但 450125/225 未见可用战斗奖表；当前我方只到 1000 亿知识的星界时序引擎，P404 自然档知识仓约 54.78 亿。收费空节点或虚构奖励不能关闭此项。
2. **沿相同存档走通两条线。** 从 P404 第 50 关有价首胜档逐关真付建造、科研、训练、补兵并打到第 100 关；同时在需要材料时真实进入拓境，逐场记录战损、实际入库、容量截断、交易和失败恢复。历史高配档 46–100 连胜不能替代从当前第 50 关的连续接力；P404 星界秘典 Lv8 是另一份后量子档，不与其拼时长。
3. **再落末关强度。** 先明确“全部科技”的确切清单，包括已停用历史科技和 100 倍播放便利科技如何处理；若引擎属于必需项，需完成自然单笔 1000 亿知识/3000 万勋章付款。由第 99 关已胜、100 未胜的同源档比较成长前后合法军力、阵位、星阵、量子兵和兵装实付的首通战果，再选正式敌阵。P404 正式 1100 敌在兵装强化前后均 16/16 胜，现有两个科技 flag 只是资格门，不证明“全科技成长后才能打完”。
4. **最后做全路线数值、美术与兼容总验。** 同版本从新档分别跑重经济、均衡、军事、短会话/动态离线四策略，按秒、资源、粮/维护、仓容、科技、战损与回补和真实关卡结果统一记账，核 50 小时目标；同时逐时代验机巧工业到后段西幻的名称、兵种/建筑/区域美术和移动端状态。人口已有零胜场自然出生与购契，锁定科技/兵种在本批 Edge 104/104 检查中隐藏且已拥有旧物仍可见，但其后段资产和四策略节奏不能因此判全过。最终所有新增字段再按 `rts_save` 当前 v36 做迁移、坏档保护、写入失败与真实浏览器验收。
