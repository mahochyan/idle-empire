# P171：实付扩仓扩团打通第一章的同档路线（2026-09-26）

## 问题与同源起点

P170证实第5关后的T1民兵／游侠可付费重训，但营帐Lv1单团只容10人，15名民兵有5名留在预备池；其两种种子样本继续败于L7／L8。代码允许营帐Lv2把单团上限升至15，可当前木／石仓容只有2400／1600，装不下营帐所需木3060／石3060。因此先核验现有仓库链能否真正把这笔升级费存入、付出，并把新增出战人数带过第10关。

[P171探针](../../tools/verify/probe-paid-regiment-capacity-p171.js)按P170／P167的真实新档动作重新取得第5关首胜存档。粮／粮岗位、种子1和42、当前L3+6与隔离VM无奖构成4支；与P170对应检查点的tick、人口、资源、岗位和战功逐项一致。两次回放的存档含墙钟时间戳和编队ID，字节哈希不要求相同。各支重载自身存档后真实取消旧步兵／猎人待训队列，3名石工转木工；逐级支付并等待仓库Lv1→5，再支付营帐Lv1→2，之后真实升级双T1营地、等待旧兵返还、研究民兵／游侠并训练至拥有15青铜刀盾兵／15民兵／13游侠。每次战前经真实编队动作放入前排15刀盾＋15民兵、后／中排13游侠；第6关开打，之后每胜按缺口补训、等待600在线`tick()`秒，再打下一关，直到L10或首次失败。每关使用与P167同规则的固定随机流；没有资源注入、驻军或离线模拟，战斗回调墙钟时间不计入在线秒。

## 建造账与结果

仓库Lv2／3／4／5逐级实付木960／1120／1280／1440，完工需11／12／13／14秒，总计木4800、建造计时50秒；期间还要等木工生产至每笔可付。Lv5完工后木／石仓容为4800／3200。营帐Lv2随后实付木3060、石3060、粮1700，40秒完工，`regMax()`由10升到15；升级中暂为5，路线等待其完工才编队出征。另有两座营地T1升阶、双线研究与三线新兵训练费；它们都通过真实扣费、训练队列和存档重载，旧兵日志是按拥有数计算的**标称退款**，实际入库仍受仓容约束。

四支从第5关胜利到第10关胜利总共推进3580–3639模拟在线秒，其中第6关后四个胜利间隔各600秒。每场的**拥有量和实际入场量相同**：15刀盾／15民兵／13游侠；前排仍仅两个格，靠营帐Lv2的每团15人承载。种子1的L10虽然胜利，民兵15名全部阵亡；种子42的L10战后尚有7名民兵。第10关胜利不是下一章无需补兵的证明。三支最低粮只有约11.48–17.98，训练队列也在若干在线秒因材料不足暂停；本路线真实可达，但军粮和操作容错很窄。四支是两种固定随机流和一种岗位策略的受控样本，不代表玩家平均胜率。

## 本次设计决定

第一章目前已有“市场／拓居令扩住房→新增居民分岗→仓库Lv5存下大笔建造费→营帐Lv2扩团→第5关后T1研究与重训→15＋15＋13真实出战→逐场补兵”的**可付费通关路径**。第3关拓居令在这些样本里提前住房、缩短部分准备时间，却不是唯一通关来源；无奖对照也能走同一高操作路径，但粮食余量更窄。暂不直接上调出生倍率、追加关卡直送村民或削弱第10关Boss。要把这条高操作路径变成可信的成长曲线，下一轮需用更多种子、经济／均衡／军事／短会话岗位和离线安排，在同一检查点验证仓容、军粮、补兵时间、L10战损及L11承接；并把P171与等时、等资源的少兵入场对照分开，不能把四支全胜单独归因于营帐Lv2。

主题命名继续沿我方“边境拓居、军镇工造”前段，机器工业至蒸汽，电力后渐入西幻。本文沿用当前配置的“游侠／精灵”以方便核对实际代码；它们是早期玩家可见的西幻标签，后续美术与显示名复核须说明其在我方边境世界观里的身份，不照搬参考游戏专名。原创玩法仍后置，且不触碰并行美化中的UI。
