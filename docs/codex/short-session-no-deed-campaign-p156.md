# P156：无首通地契的短时战役对照（2026-09-26）

## 方法与范围

为厘清P151–P154中基础首通候选地契的影响，从P154使用的同一条`sequential-expansion`零胜场人口路线重新生成终档，再交给P102。P102只在隔离副本中关闭`ceil(关卡ID/10)`基础地契和L3额外+6地契，并禁用只服务于额外奖励分支的岗位改配；其余军备准备、训练、战斗、结算与离线调用保持真实函数。沿用当前岗位配置（3粮工）、固定随机值0.5、每600在线秒后离线28800秒和败后600在线秒重试。候选奖励对照取自P154的`current`岗位分支；探针逐项校验P154原始数据中各输入SHA-256与当前文件及HEAD。

## 结果

P154与P156从同一入口开始：tick 206063、18/18人口、步兵15／猎人13／青铜刀盾兵8、同一岗位与资源。二者直到L9首次战败的战斗和补兵记录相同，L9等待600在线秒后重试都获胜。

| 检查点 | 基础候选地契（P154当前岗位） | 无地契（P156） |
|---|---|---|
| L10前tick | 441447 | 441447 |
| L10前人口／容量 | 19/19 | 18/18 |
| L10前军队 | 15／12／15 | 15／12／15 |
| L10前资源 | 木55、石1600、粮3000、煤600、铜800，其余一致 | 与左侧逐项相同 |
| L10 | 第5回合胜；战后15／12／2 | 第5回合胜；战后15／12／2 |
| L11 | 下一恢复窗补至15／13／15，第1回合胜 | 同左 |

P156的无地契控制在每次战斗结算后都记录了余额：L1–L8胜利、L9首败与重试胜利、L10和L11胜利，共12条记录，全部为0。9个28800秒离线窗均完整推进，窗末粮食均为3000，未改变岗位。P154基础候选奖励路线在L10前为19/19，P156无地契路线为18/18；这个固定样本里的人口／容量差异没有改变L10、L11战果，也没有改变L10前可比的tick、资源与编队。

## 设计含义与限制

此结果说明在当前顺序扩建人口入口、18人军备档、3粮工岗位、单一随机值0.5和该短时profile下，P151–P154接续到L11并不依赖基础候选地契；无地契路线仍需要真实的600秒败后补训和下一次恢复窗。P154的19/19人口是候选奖励产生的容量／出生差异，不能描述为现行玩家奖励。P156不能证明其他人口分配、种子、军队准备、在线节奏、章节或长期人口曲线也不需要奖励；P112完整短时战役、多策略与全时代成长仍未通过。
