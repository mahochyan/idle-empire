# P306｜实付遗迹晶核与2亿知识仓

日期：2026-09-28。文档目标仍是以《放置时代》发展副本供材料和经济成长，以100关作为完成核心科技后的高难主线；美术沿用本项目，后期命名逐步融入西幻。P305在当前实付档算出2亿知识仓最少还需蒸汽科研16→22级，但1,116个遗迹晶核缺口尚无实付账。本批从同一隔离档继续，以现有遗迹战、市场净化、人口岗位、训练及升级动作逐笔付款，不改玩家运行数值、存档字段、UI或美术。

## 实际走通的链路

输入为[P304可重载终档](reports/data/p304-electric-knowledge17-guardian-paid-save.json)，原文 SHA-256 `596abcd27b71e8c90f1bac53b9fe5bca1b7a1b30f4c9c085d7b69fe3562eda99`；原626人阵型从[P285实付满编档](reports/data/p285-awakening-stage6-full-roster-paid-save.json)只读取得。开始时知识仓166,765,547、遗迹晶核54、蒸汽科研16级、勋章9,324，现有军队620人、远征出战575人。先按真实资源生产与训练补齐既有51人战损，恢复626人出战。

[P306逐笔账](reports/data/p306-steam-knowledge22-crystal-paid.json)在20轮中每轮都用当前 `openMaterialDomain('godCrystal')` 开战并真实结算。首场警戒4600直接胜；之后19轮分别经当前特殊市场实扣3份圣兽血剂购1剂镇域净化剂，消耗后把上一场升到4700的遗迹警戒降回4600。20场固定战斗种子4均胜，每胜获56晶核、2,268勋章、3血剂，损111人；总获晶核1,120，库存54→1,174，勋章9,324→54,684。每次战后按原兵种岗位生产、真实训练扣款和重新编队，下一场仍以626人出战。包含开局51人在内，共补回2,160人；探针记录真实 `payTrainingCost` 资源差值并与每笔训练账核对，合计钢9,134,200、铁9,068,000、铜9,068,000、粮993,000。20场总损2,220人，末场111人未再补，所以终档出战515／总军560，不把未付补兵算作完成。

市场各轮固定种子291，按 `offlineAdvanceSec(1200,1)` 逐段推进，19次上架等待均为30,000**倍率1模拟生产秒**，共570,000秒。生产、补兵和筹知识另用 `tick()` 44,716**模拟在线秒**；合计614,716模拟秒（约170.75小时），最低粮库存352,859.81。倍率1模拟秒不是现实玩家在线或离线日历时长；探针不计点击、战斗动画、随机失败和人为岗位切换耗时。每场战斗、每轮市场都重设选定随机种子，这是存在性路径，不代表自然连续随机流或典型等待。市场等待一项已占158.33模拟小时，因此这条路径**没有满足**策划的50小时多策略成长目标；也不能据此断言其它策略一定失败。

晶核1,174到手后，岗位真实产知识，依次调用 `upgradeEraStorage('steamKnowledge')` 六次，实扣知识5.1/5.4/5.7/6.0/6.3/6.6百万、晶核170/180/190/200/210/220，总知识35,100,000与晶核1,170。知识仓每级实测升至173,179,607／179,593,666／186,007,726／192,421,785／198,835,845／**205,249,904**；蒸汽科研22级、晶核余4、知识余5,884。[可重载v32终档](reports/data/p306-steam-knowledge22-crystal-paid-save.json) SHA-256 `5f0d037cde645de2c7e4c7b4e5fa3aa4fd74b3c396012c235346b51dbecb005f`，两次完整探针运行得到同一终档哈希，输入两档原文未变。

**本次决定：**2亿仓容缺口可通过现有发展材料战与真实经济补兵付款，不再仅是条件推算；但这只跨过母本星域异兽研究的**知识仓门槛**，并未积攒单笔2亿知识，也未达到该研究所需100万勋章。当前终档54,684勋章，尚差945,316；量子研究30亿知识/300万勋章更远。优先检查无需反复等稀有净化剂的晶核/勋章回流与升级路线，并以同一档测试不同阵型和市场/野兽兑换策略，才可能校准50小时目标。不会因为单条固定胜流就直接削弱遗迹警戒或免费发放晶核。星阵仍须20阶/50星、前置研究、星石来源和逐笔支付，不能替代现阶段成长。
