# P395｜铁仓跨钢容量：蒸汽首兵的实付路线对照

日期：2026-09-30。基线 `master` / `0300e8c96cd9960d03886511dd931c37ae41852d`。策划目标是人口与产业可脱离主线关卡继续成长；这里检验零主线胜场下，从新档到首名蒸汽装甲兵的钢容量接力。它不是全局50小时或全时代通关验收。

真实 `resCap('steel')` 在每级铁仓给基础钢容量 +50，每级钢仓给 +100。此前铁仓说明只写铁容量，建筑详情也未提示钢收益；本批把既有规则显示在铁仓详情，并显示当前钢上限，**不改容量公式、建造费用或存档结构**。钢仓升到64级是旧探针的一种固定路线，不是必经路线。

比较的早期钢精通路线先通过现有郊野胜仗取兽骨、实际支付知识和勋章研究到20级；对照各路线再用真实生产、市场、岗位分配、建仓、研究、训练和逐秒推进，达到10000钢容量、研发蒸汽时代并训练一名装甲兵。所有路线主线胜场为0、人口26。50级铁仓是已测离散点中最快，较同样提前钢精通而不建铁仓少37,092模拟在线秒；与无提前钢精通旧基线的92,461秒差异混有**两项策略变化**，不能只归因于铁仓。铁仓过高会占用铁料和建造时间，使第100级以后反而更慢。本批未穷举最佳等级，也没有把操作所需墙钟时间计入模拟在线秒。
