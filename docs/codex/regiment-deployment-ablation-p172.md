# P172：同费用下前排实际入场人数的配对复查（2026-09-26）

P171的“扩仓→营帐Lv2→T1双线→15刀盾＋15民兵＋13游侠”四支均胜L6–L10，但相较P170还改变了木工数、等待时长、仓容、费用和补训目标。不能把全胜直接归因于营帐扩大的实际入场人数。[P172探针](../../tools/verify/probe-regiment-deployment-causal-p172.js)从同一真实L5首胜存档分叉，**完整复用P171的付费、岗位、等待、训练目标和营帐Lv2**，只在每次真实编队时把前排两团各放15人与各放10人对照；游侠均放13人。第6关开战前两支的tick、资源、建筑、科研、拥有量及逐项支付／等待记录相同，战后按同样持有目标补兵并各等600在线`tick()`秒，至L10或首次失败。两个固定种子×当前L3+6／隔离无奖，共4对；没有资源注入或玩家运行代码改动。

| 固定种子与奖励 | 各团前排15人、后排13游侠 | 各团前排10人、后排13游侠 |
|---|---|---|
| 种子1，当前L3+6 | 胜L6–L10；L10用6回合 | 胜L6–L9；L10第5回合败 |
| 种子1，隔离无奖 | 胜L6–L10；L10用6回合 | 胜L6–L9；L10第5回合败 |
| 种子42，当前L3+6 | 胜L6–L10；L10用3回合 | 胜L6–L10；L10用4回合 |
| 种子42，隔离无奖 | 胜L6–L10；L10用3回合 | 胜L6–L10；L10用4回合 |

种子1说明**在相同付费和第6关战前资源条件下**，增加两团实际入场人数会改变该路线的第10关胜负；种子42两种编队都能胜，但15人团少用1回合。战斗后战损、补训、库存自然分叉，故这项配对识别的是“从第6关起采用较大实编的整段策略效果”，不是将L10单场胜负差归给某一轮攻击。两支都已经支付营帐Lv2的费用，不能用这项数据证明“没有升营帐就绝对打不过”；P171的仓容、生产时间和旧兵退款同样是可达路径的一部分。

此批支持把**实际入场量**而非拥有量写入早期难度验收：第5关后有两个前排格、营帐Lv1每团10人；仓库Lv5和营帐Lv2可让两团各15人出战。策划暂不追加直接发村民、直接加人口倍率或一刀切降低L10敌压。下一轮应跨更多随机流与经济／均衡／军事／短会话策略复核军粮安全、L10战损和L11补兵，再把实测时钟与《放置时代》目标曲线并列；两种种子不构成玩家胜率估计。前段仍使用边境、军镇、聚落工造语汇，晚期西幻渐进，原创玩法继续后置。
