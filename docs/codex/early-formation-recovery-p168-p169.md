# P168／P169：第6–10关补兵恢复与实际编队复查（2026-09-26）

## 设计目标与当前状态

人口不靠通关才能出生；第3关首胜的6张“拓居令”已能在当前市场策略中提前住房扩建。P167的现行战役样本却全部在第6–9关首次战败，没有首败前的第10关实战。它的逐场`beforeArmy`原本是**拥有量**：兵池、远征编队和驻军之和；不能当成入场兵力。第5关胜后开放第二前排格，但固定编队仍先放满刀盾兵。P167第6关40场拥有37–43名士兵，实际入场22–28名，步兵均未入场。本批先纠正统计口径，再检验败后等待和真实编队动作，仍不改玩家数值或UI。

## 同源方法

[P168探针](../../tools/verify/probe-current-first-clear-recovery-p168.js)复用P167来自真实新档的18/18、零胜场军备存档，从L1逐关打到首次失败，保存、重载该档后才进行续战。取木／粮、粮／粮两种新增居民岗位、5个固定战斗随机种子和当前L3+6／隔离VM无奖两支，共20个首次失败存档。每档分别把0、1、2名石工经真实`setPopAlloc`转木工，真实补训、等待600或1800在线`tick()`秒并同关重试；重试胜利后每隔600秒继续打下一关，至L10或下一次失败。120个结果是同源敏感度变体，不是120个独立玩家。

[P169探针](../../tools/verify/probe-early-formation-bridge-p169.js)使用同一18人存档、同样的两种岗位、五种子和两条奖励支线，组成20对从L1开始的战役。每对到L5的战斗、库存和编队相同；只从L6起比较“先排刀盾兵填前排”与“前排先放至多10刀盾兵、再放至多10步兵”。第6关两团均满10人，之后按可用库存补位。两支均经真实`clrForm`、`openFormModal`、`confirmForm`编队，并经真实战斗、结算和补训；首次失败即停。每关按种子与关号重置相同战斗随机流，战斗回调墙钟时间不计入在线秒；没有离线或驻军模拟，也没有资源注入。

## 实际结果

| 对照 | 观察结果 | 能说明什么 |
|---|---|---|
| P168：20个首败存档×6种恢复 | 120次续战中，同关重试10次获胜，2次实际开打L10，0次通关L10 | 现有编队有极少数路线能摸到章末，但这套恢复动作未闭合章末胜利。2次L10来自同一“粮粮／种子42／有奖／不转木工”存档的600与1800秒变体，不能算作两个独立成功路线。 |
| P168：600与1800秒配对 | 60对首次失败续战的最终阻挡关卡完全相同 | 单独延长此段在线等待，在这组策略里未改变胜负边界。 |
| P168：满持有量与出战 | 续战前120次中有82次持有15步兵／13猎人／15刀盾兵，但各次重试的步兵实际出战仍为0 | 仅看补兵库存会把编队占位问题误判成军力充足；需把持有、队列、实际出战分别记账。 |
| P169：混编策略对刀盾优先 | 20对中，混编首败关后移3、前移9、不变8；两种编队均无首败前L10尝试 | 让预备步兵入场确实改变战损与胜负，但“每种至多10人”的前排搭配不是稳定的早期过关方案。 |

P169的20对第6关两支均获胜：原编队步兵0入场，混编步兵10入场。混编第6关平均损失6名步兵、4.15名刀盾兵；原编队平均损失0名步兵、5.4名刀盾兵。木粮种子1有奖支，原编队第6关3回合胜、损7刀盾兵，之后首次败于L8；混编第6关5回合胜、损10步兵／9刀盾兵／2猎人，之后首次败于L7。也有混编把木粮种子2的首败由L8推到L9，因此不把单场战损或单一随机流当成普遍因果。

P168的粮粮种子42有奖支在首次L8失败后，不转木工的两种等待窗均可重试胜L8、再胜L9，却败于L10：L10前持有15步兵／5猎人／15刀盾兵，实际入场0／5／15；败后刀盾兵和猎人归零，15步兵仍在预备池。这是当前奖励版本的真实L10尝试，不等于稳过。木工转调虽可补到更多猎人，有的同源分支仍在L8失败；战斗目标选择、编队与战损会让“库存更多”不单调转成胜场。

## 本次设计决定

保留“拓居令”作为早期住房加速设计，不宣称它已修复难度曲线；不因P168等待无效而直接加速人口出生，不因P169混编局部有效而统一替玩家改编队。第6关之后的验收表须分开列出：人口与住房、粮／木／石净流及仓容、兵池拥有量、队列未完成数、实际入场兵种和人数、战损回补秒数、首败关和第10关实战结果。下一项优先核实L5胜后现有营地升阶和T1兵线：真实研究费、建造费、返还旧兵、重新训练及出战收益；如果这条可付费路线仍无法接力，再同源校准L7–L10敌军压力和章节奖励。前段名称继续服务聚落、军镇和机巧工业主题；后续再渐入西幻，不新增原创玩法。
