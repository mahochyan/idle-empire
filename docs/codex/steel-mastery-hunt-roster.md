# 冶钢精通20级兽骨线：合金猎队扩军复核（P43，2026-09-24）

P42的8名合金兵能在固定随机值0.5／0.9下连续59胜，取足冶钢精通20级所需兽骨；固定0.1却在第55场全损。为了把这段难度变成已有成长系统能应对的门槛，本批只检验**实付升级合金兵坊、再训练两人**，不降低野猪属性、提高奖励或注入兵力。内部时间单位是在线tick秒；探针即时推进异步战斗，均不含点击、动画、思考或现实等待。

自然新档在冶钢精通5级、26人口、零普通关卡胜利时已拥有1名合金兵。营帐Lv1可编10人；合金兵坊Lv1训练上限8，必须先付真实`upCost`升到Lv2（木2200、石1981、粮1651、工期11秒），训练上限变11。再按现有训练动作增加至10名合金兵，相对8人队额外付两人的粮3000、钢200，并等待实际训练完成。10人编入前排，59场胜利共得兽骨2994、郊野警戒值590；清编后10人全归兵池，先换勋章支付冶钢精通6～13级，余1854骨留给知识扩仓后的14～20级。v21主档重载保留兵坊等级、兵池、兽骨及精通等级。
