# P292 圣兽血脉：血剂永久生命成长与实付验证

## 文档目标、代码现状、本次决定

《策划文档》要求发展副本持续供给全科技后高难 100 关主线的成长资源，原创新玩法后置。P291 已补齐六条神域材料战的「圣兽血剂」胜利掉落，但血剂仍只能换镇域净化剂；母本 `180001`「麒麟凝血丹」的另一主要用途尚未实现。本批根据本地 `210(1)_unpacked/_analysis/entities_table.json` 的 `AddHP=1`、`LimitNum=300` 和 `deob_main.js` 的 `pillUse` 动作，接入**指定兵种每份基础生命永久 +1%**，基础上限 300 次。母本另有突破使用上限的道具，本批尚未映射。

我方单位以母本单兵 HP 100:1 映射为小数生命，故每份血剂对某兵种的单兵生命增加其当前配置基础值的 1%，不把原式的整数取整直接套在 1～6.5 HP 的我方单位上。效果按使用次数**加算**在基础生命上，再与既有升星、觉醒生命共同进入 `battleVitals`；远征和驻军都从这个函数取生命，敌人不享受。由于我方伤害公式使用当前生命参与计算，血脉也会间接增强该兵种输出，这是与母本单项属性展示不同的本地战斗联动，长线平衡仍需实战校准。血剂还可在市场以 3 份换 1 剂净化剂，两种用途竞争同一库存；未变更敌人、市场权重、补货周期或 100 关奖励。

`config.js` 增加血脉参数；`math.js` 增加每兵种使用次数 `S.bloodline`、实扣动作及共享生命计算；`ui.js` 在战斗页增设「圣兽血脉」卡，机巧遗迹于合金阶段开放时即可使用，可为当前拥有的非敌方兵种选择使用份数。动作层检验兵种、拥有量、战斗状态、正整数份数、血剂库存及单兵种 300 次上限；主档或备份写入失败会回滚血剂与次数。存档仍为 v32，同版本旧档在**独立候选数据**中补空表，保留原始文本至迁移前保护副本；已有合法 0 使用次数可往返。未知、负数或超 300 的新字段数据进入保护模式，不静默裁剪。
