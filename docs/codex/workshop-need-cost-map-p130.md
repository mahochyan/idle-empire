## 真实铜投入路线

母本Need将冶炼厂升级的一项费用定为铜500。项目初始铜容量不足以直接支付，因而只把成本改低不能构成可达性证明。开发探针改为调用真实动作先建/升铜仓，再按需要扩铁仓（当前铁仓也增加铜容量），并在升级煤井后投入4名铜工，再继续冶炼和炼钢。路线未注入资源、人口、科技或普通关卡胜场。

## P130结束时仍待校准（P131复核）

P130只把升级基价对齐来源Need。初建build成本仍是项目值；当时伐木场、采石场、农田的初始加成0.20及每级0.25仍高于母本每级10%成长，P131已校正这三项倍率。食物基础产率、其它建筑的效果等级、资源单位成本、产出/消耗、仓容增长和等待时间尚未全表对照。低粮检查点仍需保留粮储安全余量，不能只看是否抵达蒸汽。全时代、多策略、战斗补员、离线和50小时目标均未验收，原创玩法继续后置。
