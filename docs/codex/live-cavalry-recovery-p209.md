# P209：猎风弩骑第29关败后实付恢复与重战（2026-09-26）

**结论：P208 原流1的73人全灭档可以在同一正式配置下重新补满并挑战第29关。** 保留原岗位和仓容，从0现役、粮约2.843的完整败后 `rts_save` 出发，真实排队、逐秒在线 `tick()`、付款训练，**1868模拟在线秒**内实产73人并清空队列，低于本批7200秒预算。独立从这份补满档重战，固定流1仍在第4回合全灭、敌余28 HP；固定流15第4回合获胜、损46人。结果表明这个败局有实付恢复路径，不保证流1重试能获胜，也不代表玩家胜率。

为核对“重打奖励”边界，仅在流15胜利分支再调用真实训练和逐秒推进，实付补回损失的46人，1173秒内重回73人，然后以固定流15**合法再次开一场**第29关。再次获胜、损46人，普通奖励再次实入木0／石6／粮975、战功再次+16，而 `defeated` 中第29关仍只出现一次；本关没有另设首通奖励或精魄掉落。这里证实的是**两场独立、合法胜利都可获得普通资源和战功，关卡进度不重复插入**。本批没有调用同一场战斗的异步回调或 `endBattle()` 两次来测试重复结算；不能把合法重打当成同场领奖漏洞。
