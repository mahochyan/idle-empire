# 零胜场经济路线继续扩至19人口 P121

日期：2026-09-25

策划文档版本：v2.48

## 问题与边界

本批接续P101的真实新档路线，检查18人口满住房后，能否不打关取得下一点住房并自然增加第19名村民。它只验证当前代码中的人口/聚落/市场路径，不改玩家奖励、出生公式、存档、运行代码或UI；“地契加速扩容”仍是设计方向讨论，不等于已上线首通奖励。

## 方法

- 由P101真实零胜场路线生成终档并序列化，重新载入后确认战斗胜场为0、人口和容量均为18，起点累计tick为5316。
- 调用真实`settlementBatchPreview('village',1)`、`exchangeResource()`、`upgradeSettlement()`、自然出生tick和`setPopAlloc()`。不注入资源、不手改游戏状态，也不写玩家存档。
- 下一次村庄扩容需9地契。按市场当前兑换函数筹足900金币，再买9地契；出售木料、粮食余量时分别保留100木与1000粮，石料保留1000。逐笔纳入出售后的库存后，最低粮库存修正为1000.075，交易后的木、石、粮仍为正。
- 升级村庄后等待自然出生，再把新增居民分到木工，观察实际岗位人数及木材产率。

## 结果

| 检查点 | 结果 |
|---|---:|
| 零胜场起点 | 18人口／18容量，tick 5316 |
| 村庄扩容 | 4级→5级，支付9地契；9地契由900金币兑换取得 |
| 市场筹币 | 10笔余量交易；含交易后余额的最小粮库存1000.075 |
| 自然出生 | 扩容后10秒，人口从18增至19；最终tick 6386，胜场仍为0 |
| 第19人转岗 | 木工人数1→2，木材产率达到6/秒 |
| 扩容与出生总耗时 | 从起点至19人口共1070模拟在线秒；不含玩家实际操作时间 |

起点18人口岗位为木1、石4、粮2、煤5、铜1、铁2、学者1；终点使用同一P101经济存档继续生产。终档为19/19人口，17人分配岗位、2人空闲。数值说明当前自然出生没有战斗胜场门槛，但可出生的人数受住房容量限制；下一户住房又要靠地契，地契需要市场可售余量支撑。这条路线显示“经济上可达”不自动等于“扩容节奏足够快”。

## 设计判断

1. 保留自然出生作为人口基础供给；关卡不应成为获得村民的唯一办法。
2. 把住房/地契续供和出生率分开校准。当前样本到18人口后，市场筹币和扩容成本形成新的等待点；不能只提高每10秒出生人数，因为满住房时出生无法兑现。
3. 继续把战斗首通定位为可选的后续扩容加速来源，而非直接送人口或替代住房、口粮与军队训练。该奖励仍须用户确认并经多路线校准。
4. 第19人能转成木工产能，但单岗位敏感度不能确定长期岗位配置。人口、木/石/粮库存、煤铜铁生产、仓容和军力补回仍须在相同新档路线一起验收。
5. 1070秒只属于P101这一条零战斗路线和当前经济参数，不是玩家典型游玩时长；没有验证持续重复扩容、战斗路线、离线节奏或时代曲线。
