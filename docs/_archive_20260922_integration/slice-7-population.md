# 切片 7 报告 · S5 人口结构对齐（派生式增长）

## 1. 切片名与范围
- 切片：**S5 人口结构对齐**（`分期计划.md` 切片 7；骨架拟合高风险项）
- 目标：对齐竞品"人口随时间增长到上限"的结构（竞品：基础人口 4；`getPeopleSpeed = 2+5×城镇` 每 10s 一跳，@1310081 + `0x2710` 定时器）
- **关键设计选择（兼容纪律）**：
  1. **派生式人口**：`popCurrent()` 由**已持久化的 `S.tick`** 推导 → **不新增存档字段**（无需 v3），存档/导入/迁移天然兼容，回滚只需关开关
  2. **不回收既有分配**：历史存档里"分配数 > 当前人口"时**照原样保留**（AGENTS 第 3 条：不得默默裁剪），仅限制**新增分配**
- 改动（3 个生产文件）：
  - `config.js`：`CFG.pop = { growth:true, base:4, per10sBase:2, per10sPerTown:5 }`
  - `math.js`：新增 `popGrowthPer10s()/popCurrent()`；`popFree()` 改为基于 `popCurrent()`
  - `ui.js`：`res-pop` 与主页村民行显示 `已分配/当前人口（上限 X）`（**展示同源**）
  - 测试/工具：新增 C01-C03；`equiv.js` 关闭清单加 `CFG.pop.growth`
- 回滚：`CFG.pop.growth=false` → 立即回到"人口 = 城镇上限"（C03 证明）
