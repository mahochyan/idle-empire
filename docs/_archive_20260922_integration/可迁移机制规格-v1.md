# 放置时代可迁移机制规格 v1（阶段 2 产出）

- 前提（用户裁决）：本项目**无服务端** → 竞品"服务端能力"一律转译为**本地等价规格**，不新建服务/依赖
- 依据：`reports/backend-recon.md` C.2（客户端可确认契约）、`analysis-economy.md` §5、`report\0` §1、我方代码行号
- 阅读约定：**竞品**=放置时代可确认事实（偏移可复核）；**现状**=我方代码事实；**规格**=本地等价设计（标【规格】）；**待确认**=材料不足或需你裁决
- 优先级：本轮先写 G1-G5（时间/离线/存档/幂等/调度），G6-G8 随后
- **验收层（追加）**：本文件所有规格的通过标准一律以 `实机验证标准.md` 为准（分层 L1/L2/L3/L4 + 证据归档 + 阈值）；**仅单测通过不构成验收**

## S1 时间权威与本地时钟不可信（对应缺口 G1/G3）★
| 栏 | 内容 |
