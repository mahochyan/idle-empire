# 发布检查清单（切片 16 · D1 版本号纪律）

> 对应规格 S6「配置驱动与静态版本化（热更等价物）」。本项目**无服务端热更**，静态版本号 `?v=N` 就是热更等价物。

## 1. 机制事实（代码位置）
- `index.html@1069-1080`：加载器 IIFE
  - `var V='1'`：缓存版本号（**唯一发布锚点**）
  - `q = (http|https) ? '?v='+V : ''`：**协议感知**（`file://` 不加查询串，行为与静态标签一致）
  - `files=[config,levels,sprites,math,garrison,technology,ui]`：**严格加载顺序**
  - `window.APP_VERSION` / `window.APP_SCRIPTS`：供发布自检读取（切片16 新增）
- 自检用例：`tests/ie001/run.js` 的 `P01`（读 `index.html` 断言锚点、顺序、协议感知）
- 浏览器侧自检：`tests/ie001/browser_smoke.js` 断言 `window.APP_VERSION` 与 `APP_SCRIPTS` 顺序

## 2. 每次上线必做（顺序不可调）
1. **改代码**：只改 `config.js`/逻辑文件；不新增运行时依赖
2. **跑基线回归**：`node tests/ie001/run.js` + `browser_smoke.js` + `browser_interact.js` 全绿（命令与退出码贴进交付报告）
3. **自检**：`node tools/verify/equiv.js`（全开关关闭 ⇒ 与上一可用快照逐字节一致）
4. **把 `V` 数字 +1**（`index.html`）——**忘记 +1 的后果**：CDN 可能继续回旧 JS（历史事故：线上"科技树只有兵谱"）
5. **部署到 Pages（master 根）**，随后**刷新页面并核对**：脚本 URL 含新 `?v=`、页面零异常
6. **留存证据**：截图 + 控制台无异常 + 关键版本标记（如新增字段/开关）

## 3. 反例（纪律的意义）
| 反例 | 现象 | 处理 |
|---|---|---|
| 忘记 `V+1` | 源站已新、页面执行旧 JS（CDN 缓存命中旧 URL） | 立即 `V+1` 重新发布；必要时提示用户 Ctrl+F5 |
| 用 `?v=` 静态标签而非加载器 | `file://` 本地打开间歇加载失败（`addLog is not defined`） | 保持 `document.write` 同步加载器（已实现） |
| 回滚代码但 `V` 同步回退 | 用户拿到的又是旧 URL 缓存，可能看到"回滚后的旧代码 + 更旧缓存"混杂 | 回滚时 `V` **只增不减**（新 URL 指向回滚后的代码） |

## 4. 与回滚演练的关系
- 代码回滚（`git checkout`）与"关闭开关"是**两种操作**：前者丢 v3 字段语义（见 `slice-9` 报告），后者保留字段但停止行为
- 演练记录见 `reports/slice-12-offline-advance-and-rollback.md`；`V` 纪律在回滚场景同样成立（**只增不减**）
