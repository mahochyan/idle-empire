# 实机验证标准 v1（阶段 2 追加产出 · 强制）

- 目的：所有改造**不得只以单测/代码 diff 作为验收**；必须按本标准的**分层实机验证**给出可观测证据
- 适用范围：阶段 4 每个切片、阶段 5 迁移与回滚演练；阶段 3 的分期计划须为每片指明"实机验证归属层"与通过阈值

---

## 1. 环境分层（不得混淆层级，不得跨层冒充）
| 层 | 环境 | 能证明什么 | 不能证明什么 |
|---|---|---|---|
| **L1** | `node tests/ie001/run.js`（vm 装载真实实现 + 存储替身） | 逻辑正确性、存档迁移/校验/幂等分支、边界与失败路径 | 真实 DOM、真实定时器、真实 localStorage 配额、移动端行为 |
| **L2** | 真实浏览器（Edge headless=new + CDP）：`browser_smoke.js`(33) / `browser_interact.js`(28，360×800 视口) | 真实 DOM/事件/定时器/localStorage/重载、窄屏布局、真实点击与输入 | 实体设备 WebView 差异、真机触屏、后台/杀进程行为 |
| **L3** | **实体 Android 设备 WebView**（游戏目标平台） | 目标平台真实行为：杀进程、后台挂起、触屏、字体与布局 | —（当前**无设备**，见 §6 规则） |
| **L4** | GitHub Pages 线上（`?v=N` 部署后） | 缓存版本化、线上旧档兼容、真实 CDN 行为 | 逻辑分支覆盖（需 L1/L2 配合） |

**基线回归（每次改动必跑，缺一即不予验收）**：L1 全绿 + L2 两套件全绿（当前基线：L1 32 例、L2 smoke 33 例 / interact 28 例）；命令、退出码、完整输出必须贴出。

## 2. 证据归档规范（缺证据=未验证）
| 证据 | 形式 | 归档位置 |
|---|---|---|
| 命令与输出 | 完整 stdout/stderr 落盘 | `docs/codex/reports/logs/<切片>-<套件>.log` |
| 界面状态 | PNG 截图（含关键状态：报告卡/幂等提示/停产标识/窄屏） | `docs/codex/reports/assets/<切片>-<场景>-<视口>.png` |
| 存档前后对比 | 关键字段 JSON diff（res/merit/sciences/ops/ts/tick…） | 切片报告中内联贴出 |
| 失败与回退 | 失败日志 + 回退前后 `git rev-parse` 与状态 | 切片报告中内联贴出 |
| 层级声明 | 每片必须写明"已验证层级 / 未运行层级及原因" | 切片报告固定小节 |

## 3. 各能力的实机验证用例与通过阈值

### V-S2 离线结算
| 场景 | 层 | 步骤 | 通过阈值 |
|---|---|---|---|
| 正常离线 | L2 | 注入合成档（`ts = now − 3600s`）→ 加载 → 观察报告卡与资源 | 报告卡出现 ≤1s；各资源增量 = `净速率×3600×0.6`，**容差 ±2%**；`ts` 更新 |
| 不重复结算 | L2 | 结算后立即 `Page.reload` 两次 | 第二次及以后**增量为 0**（仅有在线时长对应的正常增长）；`ops`/`offline.pendingReport` 已清空 |
| 前跳截断 | L2 | 注入 `ts = now + 86400s` | 结算量 ≤ `24h×净速率×0.6`（截断证据）；诊断日志含"前跳截断" |
| 回拨（负 delta） | L2 | 注入 `ts = now`（或超前存档后回退系统时间不可行时用注入） | 结算 0；**不产生负资源**；诊断日志含"时钟回拨" |
| 断粮截断 | L1+L2 | 食物净速率为负 + 库存有限 | `实际结算秒数 = min(delta, 库存/|负速率|)`；食物不为负；其余资源按实际秒数 |
| 起结线 | L1 | `delta = 119s / 120s` 两档 | 119s → 不结；120s → 结 |
| 真机杀进程 | **L3** | Android WebView 打开 → 杀进程 → 10min 后重开 | 报告卡时长与实际相符（**无设备则标未运行**） |

### V-S4 幂等与防重复发奖
| 场景 | 层 | 步骤 | 通过阈值 |
|---|---|---|---|
| 连点研究 | L2 | 同一 tick 内连发 5 次研究调用 | 科技点**只扣 1 次**、`sciences` 只加 1 项、`ops` 新增 1 条 |
| 重复导入 | L2 | 同一文本连续导入确认 2 次 | 只结算 1 次；主档 hash 第二次不变（或仅 ts 变化）；备份轮转次数=1 |
| 重复建造/升级 | L2 | 对 `state!=='idle'` 的建筑连点 | 第二次返回"建造中"，资源不再扣（复用既有互斥屏障证据） |
| 窗口边界 | L1 | 同键间隔 4.9s / 5.1s | 4.9s → 拒绝重复；5.1s → 允许新操作 |

### V-S3 存档 v3 与迁移
| 场景 | 层 | 步骤 | 通过阈值 |
|---|---|---|---|
| v2→v3 迁移 | L1 | v2 合成档（含真实字段）加载 | 迁移成功；16+sciences 字段无损；新增 `ops`/`offline` 默认值；幂等（二次加载 `ok`） |
| 坏 v3 字段 | L1 | 注入非法 `ops`/`offline` 结构 | 进保护模式；原文保留；不被自动保存覆盖 |
| 线上旧档 | **L4** | 部署后用 v2 合成档在线上加载 | 正常迁移；无报错；进度无损（截图+控制台零异常） |
| v3 档向后读（回滚情形） | L1 | 用回退后代码读 v3 档 | **明确记录**：进度字段无损、`ops`/`offline` 丢失；不得声称"完全兼容" |

### V-S6b 开关与回滚
| 场景 | 层 | 步骤 | 通过阈值 |
|---|---|---|---|
| 功能级开关 | L2 | `CFG.offline.enabled=false` → 加载旧档 | 无报告卡、无结算；`ts` 仍写（不破坏后续） |
| 参数级调整 | L2 | 改 `CFG.offline.ratio=0` → 结算量为 0 | 参数即时生效、无需改代码 |
| **回滚演练** | L2+L4 | 实际执行回滚（切回上一提交/关闭开关）→ 跑基线回归 | 回滚后 L1+L2 全绿；线上可正常打开；记录 `git rev-parse` 前后值（**阶段 5 必须实际演练一次**） |

### V-C2/C5 科技与人口模型回改（对齐竞品）
| 场景 | 层 | 步骤 | 通过阈值 |
|---|---|---|---|
| 学者占人口 | L2 | 分配学者 → 观察村民占用与知识产出 | `popAllocTotal` 增加对应人数；**空闲村民减少**；知识增量 = 学者数×速率（容差 ±2%）；超上限分配被拒 |
| 被动建筑人口约束 | L2 | 无空闲人口时尝试新增产出轨/建造 | 按最终设计拒绝或降产；UI 给出原因；不出现"无人口仍满产" |
| 停产可见 | L2 | 原料不足（如铜耗尽） | 建筑卡出现"原料不足已停产"标识（对齐竞品"工人罢工清零"文案语义） |

### V-S6.2 / V-S7 版本化与诊断
| 场景 | 层 | 步骤 | 通过阈值 |
|---|---|---|---|
| 版本号生效 | **L4** | 部署后刷新：脚本 URL 带 `?v=N` | URL 含新版本号且内容为新；页面零异常 |
| 忘记 bump（反例） | L4 | 部署但 `V` 未变 | 记录为反例：CDN 可能回旧内容（用于纪律说明，不作为通过项） |
| 环形日志 | L2 | 触发一次失败（如断粮截断/回拨） | 日志含该事件（≤50 条）；**刷新后清空**（未入存档） |

## 4. 通过/失败判定
- **通过**：该片所有 L1 用例绿 ＋ 归属层实机用例达阈值 ＋ 证据齐全（日志/截图/diff）＋ 基线回归全绿
- **失败**：任一阈值未达即失败 → **立即回退上一可用提交**，保留失败日志，定位最小失败用例；**不得在失败状态上叠加改动**
- **部分**：L3 未运行等环境受限情形，只能标"部分通过（L3 未运行）"，**不得**写成通过

## 5. 每片报告固定结构（阶段 4 起）
1. 切片名与范围（含回滚开关）
2. L1 命令+输出+退出码
3. L2 命令+输出+退出码+截图清单
4. L3/L4 状态（已运行/未运行+原因）
5. 存档前后关键字段 diff
6. 阈值达成情况（逐条对照本文件）
7. 回退验证（本片开关关闭后行为）
8. 结论：通过 / 部分通过 / 失败

## 6. 无真机（L3）规则
- 仓库当前**无 Android 设备/模拟器**：L3 用例一律标 **"未运行（无设备）"**，并列出阻塞原因
- **禁止**用 L2 的 360×800 视口模拟冒充 L3；禁止把"Edge 无异常"表述为"真机通过"
- 若你提供真机或模拟器（adb 可用），L3 用例按 §3 逐条补跑，并在报告中回填

## 7. 与本项目既有测试资产的关系

- 新增测试只在**必须观测实机行为**时添加（如离线报告卡、幂等连点、v3 线上迁移），并纳入上述分层与归档规范
