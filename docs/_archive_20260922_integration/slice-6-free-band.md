# 切片 6 报告 · S4 免维护带 + 分段斜率（骨架拟合）

## 1. 切片名与范围
- 切片：**S4 免维护带**（`分期计划.md` 切片 6；对齐竞品军粮四段原文 @1315400 区）
- 语义（重要）：**小编制免费、超编后分段递增罚息** —— 不是"永远更便宜"
  - 竞品原文：≤200 免维护；200<n≤300 →`1×(n−200)`；300<n≤500 →`100+2×(n−300)`；500<n≤1000 →`500+4×(n−500)`；n>1000 →`2500+8×(n−500)`
  - 我方（按尺度缩放）：免维护带 `free = freeBase(10) + freePerBarracksLv(2)×营帐等级`；超出后按段宽 `[20,80,200]`、斜率 `[1,2,4,8]` **边际计费**；`total = 逐兵 upkeep 之和 × 平均倍率`
- 改动（3 个文件）：
  - `config.js`：`CFG.upkeep = { freeBand:true, freeBase:10, freePerBarracksLv:2, segWidths:[20,80,200], segSlopes:[1,2,4,8] }`（**原始逐兵 upkeep 0.03~0.32 全部未改**）
  - `math.js`：新增 `armyCount()/freeBandSize()/upkeepBandFactor()`；`totalUpkeep()` 按开关乘倍率（关闭＝完全原样）
  - 测试/工具：新增 B01-B03；`curve-sim` 新增"带兵均衡"策略与 `--nofreeband` 对照；修 2 处脚本自身缺陷（见 §7）
- 回滚：`CFG.upkeep.freeBand=false`（B01/B03 证明回到逐兵原样且可逆）
