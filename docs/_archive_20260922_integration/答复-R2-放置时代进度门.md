# 答复 R2：《放置时代》的进度门是怎么做的（实证）

- 方法：只读提取解包文本（`tools/verify/era_progression_gates.js`；日志 `logs/era-progression-gates.log`）
- 结论先行：**竞品没有"击杀 Boss 才能升城镇/提上限"这种硬门**。它是**三轨分离**：科技（知识）＋ 资源成本 ＋ 自身等级上限；战斗只是**奖励线**（掉落/属性点/战力墙），不是内容解锁的钥匙。

## 3. 建筑等级上限 = **自身的 LvMax**，不是"城镇等级×k"
- 工坊 `LvMax=50`、仓库 `LvMax=1000`（已实测 @1086878+ / @1088772+）
- 其他建筑同样：如 @1062113「军旗」`LvMax:3, Need=[[木材,200]], LimitID=0x72bf2`（研发链节点）
- 建造/升级条件 = **资源成本 + 科技 LimitID + 自身 LvMax** —— **不存在"城镇等级"乘数门**

## 4. 关卡/进度**不作为**建筑或科技的门
- 搜索 `GuanQia / PassLevel / LevelID / clearLevel / UnlockLevel / needLevel` → **全部 0 命中**
- 发展科技条目的字段形态只有 `[Name, Need, LimitID, Unlocked]`（Need 全是粮/木/知识）→ **无击杀/关卡字段**
- 关卡的作用是：掉落（地契/勋章）、属性点（`freshResourceMax` 里 `×(1+属性点/100)`）、战力墙难度

## 5. 对照我方（代码事实）
| 轴 | 放置时代 | 我方现状 |
|---|---|---|
| 科技 | 知识阶梯（无战功） | 已对齐（切片3/5：去战功 + 6 节点阶梯） |
| 建筑上限 | 资源 + 科技 + **自身 LvMax** | **城镇等级 × buildingCaps**（Boss 门） |
| 单位上限 | 受建筑/兵营线与 LvMax | **城镇等级 × training**（Boss 门） |
| 人口上限 | 城镇建筑（地契+科技） | 城镇等级 maxPop（Boss 门） |

| 战斗 | 奖励线（掉落/属性/难度） | **唯一进度硬门**（实测 `需升级城镇到Lv.2` 拒绝 7200 次） |
