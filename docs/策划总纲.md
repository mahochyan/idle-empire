## 三、三条线骨架（目标形态 · 竞品实证对照）
| 线 | 竞品实证 | 我方目标（骨架） |
|---|---|---|
| **资源** | 每人每秒：粮 5 / 木 3 / 矿 2；工坊每级 +10%（LvMax 50）；仓库 LvMax 1000（每级 +1000 粮/+600 木/+200 知识）；军粮 ≤200 兵免维护后 1/2/4/8 分段；成本**分段线性斜率跳变 ×1/5/10/20/40**；离线 0.6×/24h | 产出一律占人口；免维护带 10+2×营帐；分段斜率成本（待 S9）；上限扩容 + 自身 LvMax；离线 0.6/24h |
| **人口** | 基础 4；增长 `2+5×城镇 /10s`；粮尽 5s 死 3 人；上限=城镇建筑累加（地契+科技） | 派生式增长（已实施，不需新存档字段）；上限=城镇 maxPop；城镇升级改**地契+科技**（已实施） |
| **科技** | 知识阶梯 40+ 节点、200→1e13（11 个数量级）；每步一门槛；来源=占人口学者 1/s/人 | 6 节点长阶梯（已实施，跨度 2.1 个数量级）；去战功依赖（已实施）；占人口学者制（待切片 14） |

**成本曲线形态差异（重要）**：竞品是**分段线性 + 斜率跳变**（前 9 级 ×1 → ×5/×10/×20/×40），我方现为**指数** `upBase×upCostLv^lv` → 待 S9 裁决切换。

## 六、纪律（强制）
1. **数值配置化**：一切可调数值进 `config.js`（或本即配置层的 `levels.js`/`technology.js`）；逻辑层只留公式结构常量。历史越界项 V1-V5（哨兵 999、告警节流 30000、保存周期 60、入侵模板数值）**只登记不改**。
2. **实机验证分层**：L1 node / L2 真实浏览器 / L3 实体 Android（未运行）/ L4 线上；**不得跨层冒充**；每片必跑基线回归。
3. **等价性守护**：所有改造走开关；**全开关关闭 ⇒ 存档与 HEAD 逐字节相同**（`tools/verify/equiv.js`）。
4. **发布纪律**：每次上线 `V` +1（**只增不减**，回滚也不回退）；忘记 +1 = CDN 继续回旧 JS（历史事故）。
5. **存档底线**：不静默裁剪历史数据；迁移/导入前先留可恢复副本；坏档进保护模式。
6. **不新增依赖/服务**；不删老接口；不提交密钥。
